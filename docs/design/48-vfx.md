# 48. 特效規範

## 48.1 定位

本文件規範**表現層特效**：什麼時候演、演多久、用什麼技術演。

**特效不得改變任何規則。** 成功率、安定值、掉率、傷害一律以各自的設計文件為準
（強化見 `06-equipment.md` § 6.9~6.10，印記見 `46-sigil.md`）——
本文件只描述「結果已經算出來之後，畫面怎麼呈現」。

特效分兩條技術路線，依**該畫面是什麼**決定，不可混用：

| 路線 | 適用 | 技術 |
|---|---|---|
| **DOM 特效** | 城鎮面板、背包、任務等 React 面板 | 純 CSS `@keyframes`，不加依賴 |
| **Pixi 特效** | 戰鬥畫面（`EffectLayer`，`40-pixijs-migration.md`） | Graphics／粒子／filter |

強化在鐵匠鋪面板裡，屬於 DOM 側；受擊、投射物、死亡在 Pixi 側。

---

## 48.2 效能預算

渲染上限見 `34-ui-guidelines.md` § 34.9（幀率 60、桌機解析度上限 1.5）。
特效設計必須守住這個預算，衍生兩條硬規則：

1. **filter 只給少數常駐對象**。每個掛了 filter 的容器都是一個額外 render pass；
   掛在每隻怪身上就是 N 個 pass，掛在 stage 上是每幀全畫面重繪，兩者都不可以
2. **一次性演出用 Graphics 或粒子，不用 filter**

DOM 側對應的規則是 `34-ui-guidelines.md` § 34.9.1（狀態沒變就不重建幾何）：
CSS 動畫一律只動 `transform`、`opacity`、`box-shadow`，
不animate 會觸發 layout 的屬性（`width`／`top`／`left`）。

---

## 48.3 共通參數

DOM 特效的時間與強度一律走 CSS 變數，不在各條 `@keyframes` 內寫死：

| 變數 | 預設 | 意義 |
|---|---|---|
| `--enh-fx-speed` | `1` | 整體時間倍率。1 ＝ 正式速度，調大＝慢動作 |
| `--enh-fx-scale` | `1` | 光暈與位移的強度倍率 |
| `--enh-fx-stagger` | `0.32s` | 白閃與後段之間的間隔（§ 48.4.3） |

**無障礙**：`prefers-reduced-motion: reduce` 時所有演出動畫一律關閉，只顯示結果。

## 48.4 裝備強化（鐵匠鋪）

對應規則：`06-equipment.md` § 6.9（武器）／§ 6.10（防具）。
安定值內必定成功；超過安定值後有失敗率，**失敗即裝備消失**。

### 48.4.1 待命狀態

- 安定值內與超過安定值**共用同一種藍白呼吸**（`3s` 循環）
- 風險由既有的成功率數字與「失敗消失」紅字表達，**不另外用顏色區分待命動畫**

### 48.4.2 安定值內的結算

必定成功，是每天按幾十次的日常操作，只給**一下白閃**（`0.35s`）。
不放光環、不放碎裂，避免重複觀看疲乏。

### 48.4.3 超過安定值的結算

這是賭博時刻，成功與失敗都是**兩拍**，且**前一拍完全相同**：

| 拍 | 時間 | 成功 | 失敗 |
|---|---|---|---|
| 第一拍 | `0` ~ `0.35s` | 白閃 | 白閃（與成功完全相同） |
| 第二拍 | `--enh-fx-stagger` 之後 | 金色爆閃 `0.56s`、兩圈外擴光環（第二圈再延 `0.15s`）、裝備名彈跳、`+N` 上飄 | 紅閃 `0.44s`＋卡片震動 `0.5s`，再 `0.38s` 後碎成六片飛散、本體淡出 `0.88s` |

**前 0.32 秒兩者不可有任何差異** —— 結果在白閃退掉的那一刻才揭曉，懸念由這個間隔製造。
要拉長或縮短懸念，只調 `--enh-fx-stagger`。

兩段必須**真正錯開**，不是疊在一起靠透明度分先後：
第二拍的元素基礎 `opacity: 0` 且不使用 `backwards` 填充，
延遲期間套用的是元素自己的樣式（不可見），時間到才由動畫接手。

### 48.4.4 實作對應

| 項目 | 位置 |
|---|---|
| 預覽頁 | `client/demo/enhance-fx.html`（Vite dev server 下開 `/MayanaIdle/demo/enhance-fx.html`） |
| 正式樣式 | `client/src/App.css` 的強化演出區塊 |
| 觸發點 | `TownBlacksmith.tsx` 的強化結算（已有 `isSafe` 與 `success`，不需另算） |

預覽頁不進 bundle，改動 CSS 時先在該頁確認再搬進 `App.css`；
預覽頁另附速度、強度與**逐格**控制，演出只有幾百毫秒，設計階段要能停下來比對。
