# 44. 平衡模擬：死神實戰、競技場、TTK 校準

> **性質**：數值健檢報告，不定義任何遊戲規則。結論見 § 44.8。
>
> 三種模擬都直接呼叫遊戲本身的程式（`combat.ts`、`tickWorld()`），數字一律由 § 44.7 的腳本產生，手抄或估算的數字不得寫入。
> § 44.9 列出的任一文件改動數值後，本報告的數字即失效，需重跑。
>
> 本版為詞綴分類（`07-affix.md` § 7.5／§ 7.6）、元素下降、法杖魔攻與魔攻匯率 2.5%（`21-combat-formula.md` § 21.4）上線後的全面重跑。
> 舊版的死神木樁（不還手）已移除。

## 44.1 共通前提

| 項目 | 設定 |
|---|---|
| 角色 | 建角 80 點（單項上限 18），Lv.51 起每級 1 點；主攻屬性先頂 18、升級點投到 35（`ATTRIBUTE_CAP`），裝備額外屬性與 buff 疊在 35 之上（`20-attributes.md` § 20.10） |
| 主攻屬性 | 騎士、盜賊 STR；妖精 AGI；元素師、牧師 INT |
| 品質 | 20%（死神、競技場）；TTK 校準為 0% |
| 攻擊節奏 | 攻擊計時器到期產生一次攻擊事件，由戰鬥天賦決定放技能或普攻 —— **技能取代一次普攻，不是額外傷害**；`interval = max(300, floor(1200 / (1 + 攻速%/100)))` |
| 素質需求 | 一律經 `getEffectiveGear()`／`getFrozenGear()`：素質不足的件詞綴凍結、同類 T7 獨有詞綴去重 |

## 44.2 配裝規則

所有裝備由腳本從 `equipmentSeeds.ts` 自動選出，**沒有寫死的裝備名單**。詞綴規則集中在 `client/scripts/affixLoadout.mts`，三種模擬共用。

### 部位與路線

| 規則 | 內容 |
|---|---|
| 防具路線 | 依主攻屬性：STR → 重、AGI → 輕、INT → 布（`06-equipment-armor.md`）；沒有路線的模板（飾品、腰帶）不受限 |
| 素質不足 | 被凍結的件排除後重選，直到整套都生效（死神、競技場）。副手只挑單獨穿上時素質滿足者 |
| 手部 | 雙手武器與「單手武器 ＋ 最佳副手」全部列為候選，以粗排 DPS 比較 |
| 部位 | 頭盔、胸甲、上衣、斗篷（T4 起）、手套、鞋子、腰帶、項鍊、戒指 ×2、副手 |

### 詞綴

| 部位 | 規則 |
|---|---|
| 武器 | 從武器池的攻擊詞綴（命中下降、普攻回血、技能回血除外，8 種）窮舉 4 條；T7 配裝另加第 5 條封印詞綴 → C(8,5) = 56 組 |
| 其他部位 | **固定 2 條攻擊 ＋ 2 條生存**：所屬分類池內排名前 2 的攻擊詞綴，其餘依職業的生存順序補滿 4 條；池內攻擊詞綴不足時以生存補滿 |
| 數值 | 所屬分類階級表在該 Tier 的上限 × 品質（`07-affix.md` § 7.3／§ 7.6） |
| 元素 | 元素刻印、元素侵蝕、元素下降一律取克制目標的元素（死神為暗 → 光） |

**攻擊詞綴排名**：在生存配裝的第一名手部上，多掛一條該詞綴（取非武器部位能拿到的最高 T7 值），量粗排 DPS 的增量，不增加輸出的不列入。
普攻擴散不能在單一目標上量，以「只普攻時的 DPS × X% × 額外目標數」估計（死神 0、競技場 1）。

**生存順序**：

| 職業 | 順序 |
|---|---|
| 騎士 | 防禦力 → 藥水效果 → 回魔 → 受擊回血 → 最大 HP → 格擋率 → 魔法抗性 → 迴避 → 回血 → 荊棘傷害 → 最大 MP |
| 妖精、盜賊 | 迴避 → 藥水效果 → 受擊回血 → 防禦力 → 最大 HP → 魔法抗性 → 回血 → 格擋率 → 荊棘傷害 → 最大 MP |
| 元素師 | 最大 HP → 防禦力 → 魔法抗性 → 最大 MP → 藥水效果 → 迴避 → 受擊回血 → 回魔 → 回血 → 格擋率 |
| 牧師 | 最大 HP → 最大 MP → 藥水效果 → 補血效果 → 防禦力 → 魔法抗性 → 迴避 → 受擊回血 → 回魔 → 回血 → 格擋率 |

### T7 獨有詞綴

| 部位 | 選法 |
|---|---|
| 武器 | 武器池的常駐三種（爆擊傷害、爆擊率、攻擊速度）逐一試 |
| 手套 | 手套池三種逐一試，在武器選定之後（同類只有一件生效，§ 7T.3） |
| 頭盔／胸甲 | 額外防禦 |
| 上衣／斗篷、鞋子 | 迴避 |
| 項鍊、戒指 | 全屬性 |
| 數值 | 死神取區間上限；競技場取中間值 |

### 搜尋流程（死神、競技場）

1. 防具只帶生存詞綴，以起始武器詞綴排手部，取第一名當基準量攻擊詞綴排名
2. 依排名組出 2 攻 2 守的防具，再排一次手部（T7 武器試遍獨有詞綴）
3. 前 N 名窮舉武器詞綴組合；再換獨有詞綴、武器隨機技能、手套獨有詞綴重排

**粗排**：輪替加權的每次行動期望傷害 ÷ 攻擊間隔。普攻為底，每招技能依 `攻擊間隔 ÷ 冷卻（含冷卻縮減）` 的比例取代普攻；
防禦下降與元素下降以穩態佔用率 `1 − 0.9^(3 秒內判定次數)` 加權，元素侵蝕以 DoT 佔用率估算。所有候選共用同一顆種子。

## 44.3 技能與 buff 規則

技能一律從 `skill.ts`／`classSkills.ts` 讀取，可學範圍讀 `skillRestrictions.ts`，不手寫名單或數值。

| 規則 | 值 |
|---|---|
| 職業魔法 | 該等級學得到的全部（`requiredLevel`） |
| 基礎魔法 | `getLearnableMaxLevel(職業, 等級)` 以內、學習數 `maxSkills` 以內，超出時依「加速 → 戰前 buff → 降防 → 技能攻擊力」保留 |
| 戰鬥天賦 | 最多 `TALENT_INSTALL_MAX`（20）招，回魔技保留一格 |
| 戰前 | 持續 ≥ 300s 且影響輸出的 buff；同 category 只留等級最高者 |
| 加速 | `buffCategory: 'speed'` 取攻速最高者；學不到加速術時用綠色藥水（四者互斥，`30-items.md` § 30.4） |
| 輪替 | 短效 buff 與攻擊技能；校準期望值不勝過普攻者剔除 |
| 附帶效果 | DoT（快照、不吃防禦、存續期間不重複）、技能降防（不同 category 加總、同 category 覆蓋刷新）、自身增益（傷害後施加）全部照實模擬 |

## 44.4 死神實戰

> `client/scripts/simulateReaperFight.mts`，預設參數（每職業 600 場、粗排取樣 200）。

### 模擬方式

直接驅動 `tickWorld()`（server 同一套，每 tick 300ms），傷害、迴避、護盾、反擊、位移、負面狀態全走遊戲程式。

| 項目 | 設定 |
|---|---|
| 角色 | Lv.75 |
| 場地 | 24×24 空地；角色在 (6,12)，死神在 6 格外，開場先走過來 |
| 目標 | 百柱死神（Lv.80、HP 3,500、攻擊 200～250、防禦 65、暗屬性），含詠唱攻擊、詛咒／虛弱／暈眩，照遊戲生成強化詞綴 |
| 裝備 | 不預設階級；武器、防具 +9，飾品 +8，腰帶 +0；詞綴 T7 |
| 藥水 | 橙色藥水 20 瓶（回復 40～55，`30-items.md`）；騎士 HP 低於 50% 才喝，其他職業缺血量 ≥ 一瓶補量就喝 |
| 技能補血 | HP 低於 50% 才放，只放每點 MP 補最多血的那一招 |
| 防守 buff | 便宜、長效的到期就重放；絕對屏障、聖域、神聖領域只在 HP 低於 50% 時放 |
| 魔力護盾 | 「常駐」與「HP 低於 50% 才開」各跑一組 |
| 騎士 | HP 維持 50% 上下：血濺咒殺只在 HP 高於 50% 時放 |
| 牧師 | 血魔轉換在 MP 低於 80% 且 HP 高於 50% 時放 |
| 死亡 | 算失敗；擊殺時間只計存活場次 |

### 結果

|---|---|---|---|---|---|---|---|---|
| 盜賊 | 100% | **15.90s** | 12.30s | 20.10s | 90.9% | 0.0% | 240 | 2.2 |
| 妖精 | 100% | 18.90s | 14.40s | 20.10s | 95.4% | 0.0% | 76 | 0.5 |
| 牧師 | 100% | 20.10s | 18.00s | 23.40s | 77.8% | 0.0% | 217 | 17.2 |
| 元素師（魔力護盾 HP 低於 50% 才開） | 100% | 21.60s | 18.60s | 24.60s | 90.0% | 49.8% | 420 | 7.2 |
| 騎士 | 100% | 22.50s | 18.60s | 25.80s | 56.8% | 0.0% | 219 | 0.1 |
| 元素師（魔力護盾常駐） | 100% | 22.80s | 18.90s | 26.40s | 90.0% | 56.2% | 352 | 6.4 |

妖精、盜賊為武器與技能調整後以同一套配裝重跑（`--replay`）；騎士因生存順序加入回魔重新搜尋配裝；元素師、牧師未受調整影響。

## 44.5 競技場波次模擬

> 競技場設計未定案（`55-arena.md`），本節驗證「各段位合適角色能掛多久」。
> `client/scripts/simulateArena.mts`，每格 5 場、每場上限 60 分鐘，四個段位平行約 9 分鐘；`--detail` 印裝備明細、實際防禦、行動分佈與補血來源。
> 天賦配置與 § 44.4 共用 `client/scripts/fightSetup.mts`。

### 模擬方式

直接驅動 `tickWorld()`，同 § 44.4。

| 項目 | 設定 |
|---|---|
| 場地 | 30×30 空地；角色在中央，怪物生在角色周圍 6～8 格 |
| 波次 | 一般波 3 隻；第 10 的倍數波只出 2 隻王；上一波清完立刻出下一波 |
| 王 | 段位名單依 Boss 等級低到高（同級依 HP），輪完固定出最強者 |
| 強化詞綴 | 數量 `min(4, floor((波次 − 1) / 10))` |
| 一般怪 | T4 Lv.34～40、T5 Lv.46～52、T6 Lv.56～62、T7 百柱塔 91～100F |
| 角色等級 | T4 Lv.38、T5 Lv.50、T6 Lv.60、T7 Lv.80；配點先補該階防具的素質需求 |
| T4～T6 裝備 | 該階製作品（無製作品取掉落品）；武器 +6、防具 +5、飾品 +0；詞綴 T4 裝 T5、T5／T6 裝 T6 |
| T7 裝備 | T7 武器 +8，其餘 T6：防具 +9、飾品 +8；詞綴 T6，武器含封印詞綴 |
| 詞綴 | 依 § 44.2；普攻擴散的額外目標數取 1 |
| 隨機技能 | 武器帶，依粗排 DPS 選；製作品參數取最低端、T7 取中間值 |
| 藥水 | 橙色藥水 600 瓶（回復 40～55）；缺血量 ≥ 一瓶補量就喝 |
| 走位 | 妖精「保持距離」（弓射程）；法系「保持距離」8 格 |
| 掉落／金幣／經驗 | 倍率 0 |

**時間預算**：實戰預設參數目標 15 分鐘內跑完全五職業；單獨執行實測 1,058 秒（17.6 分），超出預算 —— 配裝搜尋多了攻擊詞綴排名與第二次手部排名。

### 設計原則

- **直接 import `src/systems/combat.ts` 的真實函式與常數**，不重寫任何傷害公式
- 怪物讀 `monsterSeeds.ts`、裝備讀 `equipmentSeeds.ts`、技能讀 `skill.ts`／`classSkills.ts`，**腳本裡不得有手抄數字**
- 詞綴數值一律讀所屬分類的階級表（`getAffixTierTable`），不另寫一份
- maxHp／maxMp 用真實的 `tryLevelUp()` 練上來
- `Math.random` 以 mulberry32 固定種子覆寫，並以 `setRandomSource()` 讓遊戲端亂數走同一條流，結果可重現
- 裝備找不到時輸出缺件報告，不 throw

### 模型與實機的已知差異

| 項目 | 腳本 | 實機 | 影響 |
|---|---|---|---|
| 戰鬥天賦 | 依期望傷害自動排序 | 玩家自訂 | 這裡取最佳解 |
| 詞綴 | 取理論最佳、2 攻 2 守 | 掉落隨機 roll | 實機需刷到對應詞綴 |
| 普攻擴散 | 排名以估計值（額外目標數 × X%）；戰鬥照實計算 | 同左 | 防具是否帶擴散取決於估計 |
| 元素 | 刻印、侵蝕、元素下降一律克制目標 | 隨機 | 實機元素下降常與刻印不同元素 |
| 續戰 | 死神只模擬單場 | 連打多場 | MP 經濟的真實壓力更大 |

## 44.8 結論

**1. 死神實戰全職業 100% 勝利，擊殺 15.9～22.8 秒，職業差距 1.43×**（§ 44.4）。
盜賊 15.90、妖精 18.90、牧師 20.10、元素師 21.60（常駐 22.80）、騎士 22.50 秒。前版為 24.00～36.00 秒、差距 1.40×。

**2. 詞綴分類後，防具的攻擊詞綴成為主要輸出來源之一**：物理職業的手套、腰帶、飾品帶爆擊率、攻速、爆傷、冷卻縮減，
法系帶技能元素傷害與冷卻縮減；全職業快 9～14 秒。

**3. 競技場續航靠藥水，騎士要帶回魔**（§ 44.5）：生存欄位優先藥水效果、藥水回復量提高；騎士帶回魔後鋼鐵護盾才放得起，
T6 50 波（前版 28）、T7 69 波（前版 35）。

**4. 法系的最佳配法是「單手杖 ＋ 魔導書」**：雙手杖魔攻較高（35 vs 24＋8），但魔導書在副手池多一條技能元素傷害。
T7 創世之書需精神 18，Lv.75 預設配點的法系穿不上，實際用的是 T6／T5 魔導書。

**5. 魔攻匯率 2.5% 驗證**：法系實戰擊殺由 31～36 秒縮短為 20～22 秒，但同期還有防具攻擊詞綴與路線修正的影響，
無法單獨拆出匯率的效果；滿裝組成的 2:1:1 屬公式設計（`21-combat-formula.md` § 21.4），與本模擬無關。

**6. 前版的防具選裝有錯**：只看防禦力，除騎士外全職業穿重甲而素質不足，防具詞綴整套凍結。本版已改為依路線選裝並檢查凍結。

**7. TTK 校準 30 組中 7 組偏離**（§ 44.6）：商店高階 Boss（試煉飛龍）五職業全部過快 5～10 秒；
製作入門元素師過快；製作頂級的妖精過慢 2.3 秒；一般怪全部在 7 秒內。

**8. 武器回血詞綴的價值依職業的出手型態**（§ 44.5）：普攻回血讓妖精、盜賊 T4／T7 撐滿 60 分鐘，技能回血讓法系 T6／T7 多 30～60 波；
騎士兩種都只多 0～6 波，續航仍靠藥水。
