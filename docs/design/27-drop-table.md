# 27. 怪物掉落表

## 27.1 掉落系統規則

### 基本公式

```
掉落機率 = 物品掉落值 / 伺服器掉落機率基數（1000）
```

每個物品獨立判定，一次擊殺可同時掉落多個物品。

### 掉落類別總覽

| 類別 | 掉落條件 | 機率範圍 |
|---|---|---|
| 金幣 | 所有怪物 | 100%（數量依等級） |
| 紅色藥水 | 新手區域（Lv.1~30） | 1~10%（等級越高機率越高） |
| 橙色藥水 | Lv.30+ 區域怪物 | 5~10% |

| 防具強化卷軸 | 特定怪物（一般） | 1% |

### 金幣掉落規則

| 區域等級 | 金幣掉落量 |
|---|---|
| Lv.1~5 | 1~5 |
| Lv.6~10 | 3~10 |
| Lv.11~15 | 8~20 |
| Lv.16~20 | 15~35 |
| Lv.21~30 | 30~80 |
| Lv.30~40 | 80~200 |
| Lv.40~50 | 200~350 |
| Lv.50~60 | 350~500 |
| Boss | 上述 ×3 |

- 金幣單次掉落上限：500
- 所有怪物 100% 掉落金幣

### 不存在的物品

- 補魔藥水不存在。MP 回復依靠裝備回魔與回城休息。

### 藥水規格

| 藥水 | 回復量 | 使用冷卻 | 掉落區域 | 備註 |
|---|---|---|---|---|
| 紅色藥水 | 10~15 HP | 600ms | Lv.1~30（新手區） | 可在雜貨店購買 |
| 橙色藥水 | 30~45 HP | 900ms | Lv.30+ 區域 | 可在雜貨店購買 |
| 白色藥水 | 60~90 HP | 1500ms | 待定 | 可在雜貨店購買 |

- 藥水使用冷卻為全域共用（使用任一藥水後，所有藥水進入該藥水的冷卻時間）
- 所有藥水皆可在雜貨店購買（雜貨店系統待定）

## 27.6 Boss 專屬掉落池

### 設計概念

Boss 擊殺時不使用一般區域掉落表，改為查詢獨立的 Boss 專屬掉落表（`bossDropTable`）。目的為提供製作武器/裝備素材的額外取得途徑。

### 機制規則

1. Boss 死亡時**只從 `bossDropTable` roll 掉落**，不走一般區域掉落池
2. 金幣 100% 掉落（數量為該區域金幣的 3 倍）
3. 玩家 `drop_rate` 詞綴加成對 boss 掉落生效
4. 職業技能書掉落保留（boss 5% 機率，依區域等級分池）
5. 每個 Boss 有獨立的掉落表，可包含該 Boss 專屬的裝備或素材

### 資料結構

```
BossDropTableEntry {
  bossName: string      // Boss 名稱（對應 MonsterTemplate.name）
  itemName: string      // 掉落物名稱
  itemType: 'gold' | 'equipment' | 'material' | 'potion' | 'scroll' | 'spellbook'
  dropValue: number     // 掉落值（/1000）
  minAmount?: number    // 最小數量
  maxAmount?: number    // 最大數量
}
```

## 27.7 設計原則

1. 低階裝備不掉落，只能商店購買（引導玩家消費金幣）
2. 中階裝備由野怪低機率掉落（1~5%），提供免費取得途徑
3. 高階裝備僅 Boss 掉落（10%），主要取得途徑仍為鐵匠鋪製作
4. 品質石全域 5% 掉率，確保所有玩家皆可取得
5. 強化卷軸一般怪掉率 1%，Boss 10%，維持稀缺性
6. 素材分布與 `06-equipment-acquire.md` 製作需求對應
7. 紅色藥水全新手區域掉落（Lv.1~30），機率隨區域等級遞增（1%→10%）；橙色藥水於 Lv.30+ 區域掉落。所有藥水皆可在雜貨店購買
8. 金幣上限 500，避免通貨膨脹，僅只有Boss系列掉落金錢為該區域掉落金錢的3倍
9. 東西陣營領地掉落完全對等（妖魔森林 = 明鏡森林，朦朧洞窟 = 水下監獄）
10. 百柱塔卷軸機率隨樓層遞增，高層玩家爬塔節奏更快
11. 職業技能書依區域等級分池掉落：Lv35~43 掉 3 級書、Lv43~46 掉 4 級書、Lv46+ 掉 5 級書。不區分職業，25 本共同池隨機。小怪 0.05%、Boss 5%
