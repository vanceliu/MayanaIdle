# 27. 怪物掉落表

## 27.1 掉落系統規則

### 基本公式

```
基礎掉落機率 = 物品掉落值 / 伺服器掉落機率基數（1000）
掉寶倍率 = (1 + 角色裝備 drop_rate / 100) × 全域掉落倍率 × Pressure 掉落倍率
最終掉落機率 = min(基礎掉落機率 × 掉寶倍率, 100%)
```

**掉落值可為小數**（例：0.01% 對應掉落值 0.1）。基數固定 1000。

Pressure 掉落倍率的定義見 `26-spawn-pressure.md` § 26.3，它同時作用於金幣掉落量。
任務收集物與素材任務判定不受它影響。

每個物品獨立判定，一次擊殺可同時掉落多個物品。一般怪物與 Boss 的主掉落表，以及 3~5 級職業技能書，都套用同一掉寶倍率。職業工會與冒險者工會的任務收集物是獨立任務 roll，維持各自固定機率，不受 `drop_rate` 影響。

### 掉落值的等級縮放

多數掉落物的掉落值是**固定值**。僅以下兩類會在區域內依怪物等級線性遞增
（seed 以 `dropValueMax` 標示上限）：

| 類別 | 範圍 | 說明 |
|---|---|---|
| 橙色藥水 | 50~100（5~10%） | 區域最低等級為 50，最高等級為 100 |
| 百柱塔 11F 以上通行卷軸 | 依樓層 | 越高層機率越高（1F 卷軸不掉落，見 `09-dungeon.md`） |

```
縮放後掉落值 = min(上限, floor(下限 + (上限 - 下限) × 區域等級進度))
區域等級進度 = clamp((怪物等級 - 區域最低等級) / (區域最高等級 - 區域最低等級), 0, 1)
```

素材類一律為固定值，文件表格中不再以範圍標示。

---

### 區域等級的取得（副本樓層）

掉落判定要用的「區域等級」一律以**掉落表的 area 為單位**取得：

| area 形式 | 等級來源 | 例 |
|---|---|---|
| 地表區域（area = region） | 該 region 的 `levelMin`~`levelMax` | 妖魔森林 Lv.30~33 |
| 副本樓層（area = `<region>-<n>f`） | **該樓層**的 `levelMin`~`levelMax` | 象牙塔 1F Lv.33~36（不是整座塔的 33~45） |
| 百柱塔區段（本身就是 region） | 該區段的等級 | 61~70F Lv.57~60 |

樓層 area **不是 region id**，查不到時整座副本的區域等級會退化成 1，
連帶讓詞綴階級權重（`07-affix.md` § 7.7）與特殊詞綴機率（§ 7.10.3）全部算成新手區。
實作一律走 `models/mapData.ts` 的 `resolveArea()`，不可直接 `getRegion(areaId)`。

## 27.6 Boss 專屬掉落池

### 設計概念

Boss 擊殺時不使用一般區域掉落表，改為查詢獨立的 Boss 專屬掉落表（`bossDropTable`）。目的為提供製作武器/裝備素材的額外取得途徑。

### 機制規則

1. Boss 死亡時**只從 `bossDropTable` roll 掉落**，不走一般區域掉落池
2. 金幣 100% 掉落（數量為該區域金幣的 3 倍）
3. 玩家 `drop_rate` 詞綴加成對 Boss 主掉落表與職業技能書生效
4. 職業技能書掉落保留（Boss 基礎 5%，依區域等級分池，套用掉寶倍率後最高 100%）
5. 每個 Boss 有獨立的掉落表，可包含該 Boss 專屬的裝備或素材
6. **高級裝備掉落機制**：掉落表中「高級武器」與「高級防具」為連動項目，僅 roll 一次（1%），命中後以 50/50 機率決定掉落武器或防具，再從該 Boss 對應 tier 的裝備池中隨機抽取一件。
   **旗標是每個 tier 各一份**，不是整張表共用 —— 共用的話 id 較大的高 tier 條目永遠被跳過（T7 掉率會變成 0）

### 資料結構

```
BossDropTableEntry {
  bossName: string          // Boss 名稱（對應 MonsterTemplate.name）
  itemType: 'gold' | 'equipment' | 'item'
  itemTemplateId?: number   // 掉落道具的 id（道具一律用 id 指涉，見 99.1）
  equipmentTemplateId?: number  // 指名掉落的裝備
  equipmentPool?: 'weapon' | 'armor' | 'all'  // 隨機裝備池
  tier?: EquipmentTier      // 裝備池的階級（§ 6A.1）
  dropValue: number         // 掉落值（/1000）
  minAmount?: number        // 最小數量
  maxAmount?: number        // 最大數量
}
```

## 27.7 設計原則

1. T1 新手裝不掉落，只能由創角與新手指導員取得
2. T2~T3 由野怪低機率掉落（0.1~1%），主要取得途徑仍是商店購買
3. T4~T5 由野怪低機率掉落（0.1~1%）與 Boss（3%）、T6 由深層野怪（0.05~0.1%）與 Boss（1%），主要取得途徑仍是鐵匠鋪製作；T7 只有高階 Boss 會掉（0.01%），不開放製作
4. 工藝印記全域 5% 掉率，確保所有玩家皆可取得
5. 強化卷軸一般怪掉率 1%，Boss 10%，維持稀缺性
6. 素材分布與 `06-equipment-acquire.md` 製作需求對應
7. 紅色藥水全新手區域掉落（Lv.1~30），機率隨區域等級遞增（1%→10%）；橙色藥水於 Lv.30+ 區域掉落。所有藥水皆可在雜貨店購買
8. 金幣上限 500，避免通貨膨脹，僅只有Boss系列掉落金錢為該區域掉落金錢的3倍
9. 東西陣營領地掉落對等：地表三段完全相同（妖魔森林 = 明鏡森林、腐葉林道 = 幻光湖畔、妖魔祭壇 = 碎鏡深林）；朦朧洞窟（3 層）與水下監獄（4 層）樓層數不同，改為**兩端對齊** —— 入口層與 Boss 層的裝備掉率相同，中間樓層各自線性內插
10. 百柱塔通行卷軸機率隨樓層遞增，高層玩家爬塔節奏更快；1F 入場券改由雜貨店販售，不進掉落表
11. 職業技能書依區域等級分池掉落：Lv35~43 掉 3 級書、Lv43~46 掉 4 級書、Lv46+ 掉 5 級書。不區分職業，25 本共同池隨機。小怪 0.05%、Boss 5%
12. 區域素材每區 3 種（森林深段 4 種，多的那種為該區限定），掉落率 10~12%，賣價不超過該區域金幣掉落上限。部分素材同時作為鐵匠鋪製作材料
13. Boss 專屬素材掉落率 30%，可賣錢亦可作為頂級/特殊製作配方材料
14. 區域素材賣價設計使前期金幣收入提升約 30~35%，降低各職業早期陣痛期

## 27.9 天賦格掉落（全區域通用）

天賦格（`51-auto-talent.md`）不寫進各區域掉落表，套用同一組全域規則。

**只從 Boss 掉落，一般怪不掉。掉率 1%（掉落值 10）。**

天賦格**有區間下限**（與印記等全域掉落不同）：

| 區域最高等級 | Boss 掉落的天賦格 |
|---|---|
| ~40 | T2 |
| 41~60 | T2~T3 |
| 61+ | T3~T4 |

**T1 天賦格不掉落** —— 只從角色等級取得（`51-auto-talent.md` § 51.3.3）。

**自動天賦的條件與動作不掉落** —— 一律內建、全部可選（`51-auto-talent.md` § 51.4.1）。
一般怪不掉任何自動天賦相關物，這塊回饋不補（`51-auto-talent.md` § 51.6.2）。
