# 27. 怪物掉落表

## 27.1 掉落系統規則

### 基本公式

```
基礎掉落機率 = 物品掉落值 / 伺服器掉落機率基數（1000）
掉寶倍率 = (1 + 角色裝備 drop_rate / 100) × 全域掉落倍率
最終掉落機率 = min(基礎掉落機率 × 掉寶倍率, 100%)
```

每個物品獨立判定，一次擊殺可同時掉落多個物品。一般怪物與 Boss 的主掉落表，以及 3~5 級職業技能書，都套用同一掉寶倍率。職業工會與冒險者工會的任務收集物是獨立任務 roll，維持各自固定機率，不受 `drop_rate` 影響。

### 掉落值的等級縮放

多數掉落物的掉落值是**固定值**。僅以下兩類會在區域內依怪物等級線性遞增
（`seed` 以 `dropValueMax` 標示上限，公式見 `systems/drops.ts`）：

| 類別 | 範圍 | 說明 |
|---|---|---|
| 橙色藥水 | 50~100（5~10%） | 區域最低等級為 50，最高等級為 100 |
| 百柱塔 11F 以上通行卷軸 | 依樓層 | 越高層機率越高（1F 卷軸不掉落，見 `09-dungeon.md`） |

```
縮放後掉落值 = min(上限, floor(下限 + (上限 - 下限) × 區域等級進度))
區域等級進度 = clamp((怪物等級 - 區域最低等級) / (區域最高等級 - 區域最低等級), 0, 1)
```

素材類一律為固定值，文件表格中不再以範圍標示。

## 27.6 Boss 專屬掉落池

### 設計概念

Boss 擊殺時不使用一般區域掉落表，改為查詢獨立的 Boss 專屬掉落表（`bossDropTable`）。目的為提供製作武器/裝備素材的額外取得途徑。

### 機制規則

1. Boss 死亡時**只從 `bossDropTable` roll 掉落**，不走一般區域掉落池
2. 金幣 100% 掉落（數量為該區域金幣的 3 倍）
3. 玩家 `drop_rate` 詞綴加成對 Boss 主掉落表與職業技能書生效
4. 職業技能書掉落保留（Boss 基礎 5%，依區域等級分池，套用掉寶倍率後最高 100%）
5. 每個 Boss 有獨立的掉落表，可包含該 Boss 專屬的裝備或素材
6. **高級裝備掉落機制**：掉落表中「高級武器」與「高級防具」為連動項目，僅 roll 一次（10%），命中後以 50/50 機率決定掉落武器或防具，再從該 Boss 對應 `craftTier` 等級的製作裝備池中隨機抽取一件

### 資料結構

```
BossDropTableEntry {
  bossName: string      // Boss 名稱（對應 MonsterTemplate.name）
  itemName: string      // 掉落物名稱
  itemType: 'gold' | 'equipment' | 'material' | 'potion' | 'scroll' | 'spellbook'
  dropValue: number     // 掉落值（/1000）
  minAmount?: number    // 最小數量
  maxAmount?: number    // 最大數量
  craftTier?: 'entry' | 'mid' | 'top'  // 高級裝備等級（僅 itemName 為高級武器/高級防具時使用）
}
```

## 27.7 設計原則

1. 低階裝備不掉落，只能商店購買（引導玩家消費金幣）
2. 中階裝備由野怪低機率掉落（1~5%），提供免費取得途徑
3. 高級裝備僅 Boss 掉落（10%），主要取得途徑仍為鐵匠鋪製作
4. 品質石全域 5% 掉率，確保所有玩家皆可取得
5. 強化卷軸一般怪掉率 1%，Boss 10%，維持稀缺性
6. 素材分布與 `06-equipment-acquire.md` 製作需求對應
7. 紅色藥水全新手區域掉落（Lv.1~30），機率隨區域等級遞增（1%→10%）；橙色藥水於 Lv.30+ 區域掉落。所有藥水皆可在雜貨店購買
8. 金幣上限 500，避免通貨膨脹，僅只有Boss系列掉落金錢為該區域掉落金錢的3倍
9. 東西陣營領地掉落完全對等（妖魔森林 = 明鏡森林，朦朧洞窟 = 水下監獄）
10. 百柱塔通行卷軸機率隨樓層遞增，高層玩家爬塔節奏更快；1F 入場券改由雜貨店販售，不進掉落表
11. 職業技能書依區域等級分池掉落：Lv35~43 掉 3 級書、Lv43~46 掉 4 級書、Lv46+ 掉 5 級書。不區分職業，25 本共同池隨機。小怪 0.05%、Boss 5%
12. 區域素材每區 3 種，掉落率 10~12%，賣價不超過該區域金幣掉落上限。部分素材同時作為鐵匠鋪製作材料
13. Boss 專屬素材掉落率 30%，可賣錢亦可作為頂級/特殊製作配方材料
14. 區域素材賣價設計使前期金幣收入提升約 30~35%，降低各職業早期陣痛期
