# 14. 長期目標

## 14.1 保留系統

目前可保留：

- 成就系統
- 排行榜

## 14.2 不做系統

目前不做：

- 圖鑑
- 裝備收藏
- 轉生系統
- 離線收益
- 付費系統
- 遺物構築
- 城鎮建設

---

## 14.3 成就系統

## 14.3.1 成就方向

成就系統可作為長期目標。

成就可涵蓋：

- 擊殺怪物
- 角色等級
- 裝備品質
- 詞綴插入
- 副本挑戰
- 陣營貢獻
- 財富累積
- 自動戰鬥時間

## 14.3.2 成就範例

| 成就名稱 | 條件 |
|---|---|
| 初次狩獵 | 擊敗第一隻怪物 |
| 熟練獵手 | 擊敗 100 隻怪物 |
| 戰場倖存者 | 在同一地圖中連續戰鬥 10 分鐘 |
| 壓力承受者 | 在高 Pressure 狀態下存活 |
| 第一件強化裝備 | 將裝備品質提升到 1% |
| 工藝大師 | 將裝備品質提升到 20% |
| 詞綴入門 | 插入第一個詞綴 |
| 副本挑戰者 | 完成第一個副本 |
| 財富累積者 | 持有指定數量金幣 |

---

## 14.4 排行榜

## 14.4.1 排行榜方向

排行榜可用於刺激玩家競爭。

## 14.4.2 排行榜類型

可設計：

- 角色等級排行榜
- 戰力排行榜
- 擊殺數排行榜
- 副本通關排行榜
- 陣營排行榜
- 財富排行榜
- 生存時間排行榜
- 最高 Pressure 排行榜

## 14.4.3 排行榜注意事項

排行榜應支援：

- 全服排行
- 陣營排行
- 職業排行
