# 49. 補給天賦

第三套自動天賦，與戰鬥天賦（`03-combat.md` § 3.12）、常駐天賦（§ 3.13）併列。
有序的天賦格列表，條件槽（AND）＋動作槽。屬於天賦配置（§ 3.14），跟著分頁切換。

> **本文件是補給天賦的條件與動作規格出處。** 條件與動作一律內建、全部可選，
> 天賦格怎麼取得見 `51-auto-talent.md`。

## 49.1 判定

| 項目 | 值 |
|---|---|
| 判定頻率 | **1200ms** —— 掛在常駐的 300ms 迴圈上，`VILLAGE_TICK_MS = 1000` 的下一個倍數 |
| 判定順序 | 常駐天賦 → 緊急撤退 → 補給天賦 |
| 判定地點 | 任何地方（不限城鎮） |
| 選中的天賦格 | 由上往下，第一個「條件全成立且動作可執行」者 |

常駐天賦這一輪有動作時，補給天賦不判定。

## 49.2 條件

| 條件 | 參數 |
|---|---|
| 在城鎮／在野外 | — |
| 背包已用格數 ≥ | N |
| 背包剩餘格數 ≤ | N |
| 道具數量少於 | 道具 / N |
| 金幣少於 | N |
| 金幣多於 | N |
| 有上次掛機點 | — |
| 倉庫金幣 ≥ | 倉庫 / N |
| 倉庫有指定道具 ≥ | 倉庫 / 道具 / N |

條件槽全空等同「永遠」。「道具數量少於」與「所在區域 ＝ 指定區域」
同時適用常駐天賦（`51-auto-talent.md` § 51.2.1）。

## 49.3 動作

| 動作 | 參數 | 可執行條件 |
|---|---|---|
| 回城 | 卷軸城鎮（留空＝任意） | 在野外 ＋ 有對應卷軸 |
| 返回上次掛機點 | — | 在城鎮 ＋ 有掛機點記錄 ＋ 待返回（§ 49.5） |
| 使用旅館 | — | 在城鎮 ＋ 金幣足夠（`13-town.md` § 13.7） |
| 購買道具至 | 道具、目標數量（**最多 3 組**） | 在城鎮 ＋ 未達標 ＋ 買得起至少一個 |
| 販售素材 | 顏色門檻、保留配方素材、素材白名單 | 在城鎮 ＋ 有符合的素材 |
| 販售裝備 | 顏色門檻、保留條件（§ 49.4） | 在城鎮 ＋ 有符合的裝備 |
| 存入素材 | 倉庫、顏色門檻、保留配方素材 | 在城鎮 ＋ 有符合的素材 |
| 存入裝備 | 倉庫、存入條件（§ 49.4） | 在城鎮 ＋ 有符合的裝備 |
| 從倉庫取道具至 | 倉庫、道具、目標數量（**最多 3 組**） | 在城鎮 ＋ 未達標 ＋ 倉庫有貨 ＋ 背包放得下 |
| 存入金幣（身上留下） | 留存金額 | 在城鎮 ＋ 身上金幣超過留存額 |
| 從倉庫領金幣至 | 目標金額 | 在城鎮 ＋ 未達標 ＋ 倉庫有金幣 |

- 可執行條件不成立 → 跳過該天賦格，換下一個
- **道具一律玩家自選，沒有綁定類別的限縮版**（`51-auto-talent.md` § 51.4.1）
- **一「組」＝ 一個道具 ＋ 一個目標數量**，最多 3 組
- **素材白名單**：指定的素材永遠不賣，補 `hasMaterialUsage()` 涵蓋不到的情況
  （例：收集任務的目標素材沒有配方用途）
- **門檻一定要設** —— 沒有門檻會把剛掉的高階裝備一起賣掉
- 購買與取出都是**補到 N 個**（達標即不再觸發），受金幣／倉庫存量限制
- 顏色門檻沿用 `39-batch-sell.md`：素材 `iconTier` 1–7、裝備 1–6
- 新手裝、`drop_only`、已裝備中的裝備一律不賣、不存
- 倉庫預設共用（`13-town.md` § 13.8）；金幣只有共用倉庫有
- 存入素材預設**不**保護配方素材（存倉庫不是丟掉），販售則預設保護
- 存入裝備**沒設條件就不存**，不做「整包倒進倉庫」的預設

## 49.4 裝備篩選條件

販售裝備與存入裝備共用同一份設定，方向相反：
販售時命中＝保留（不賣），存入時命中＝要存。符合**任一**條即命中。

| 條件 | 參數 |
|---|---|
| 詞綴 Tier 高於 | N |
| 帶有指定詞綴 | 詞綴清單 |
| 本角色穿得起的 | — |
| 指定裝備類型 | 類型清單（武器類型或 `armor`） |
| 白名單 | 裝備模板 |

### 本角色穿得起的

命中條件是 `requiredClass` 通過 **AND** `requiredAttributes` 通過。條件內是 AND，
與其他條件之間仍是 OR。無 `requiredClass` 視為全職業，無 `requiredAttributes` 視為無素質門檻。

素質判定的基準是**角色自身屬性（建角配點＋升級配點），不含裝備、不含 buff**。
與 § 6A.8.8 凍結判定的最小固定點**刻意不同**：販售不可逆，基準不能隨當下穿戴集合與 buff 變動。

## 49.5 上次掛機點

位置與返回意圖是兩件事，分開存。

```
HuntLocation = { zoneId, regionId, floor }
```

| 項目 | 規則 |
|---|---|
| 記錄時機 | **進入任何非城鎮區域時**（含手動切換地圖） |
| 不記錄 | 城鎮 |
| 返回方式 | 一般地圖切換（`38-map-control.md`），需通行卷軸的區域照樣要卷軸 |
| 保存 | 角色本機設定，重開仍在 |

**待返回旗標**

| 項目 | 規則 |
|---|---|
| 設起 | 補給天賦「回城」、緊急撤退回城、常駐天賦「使用回城卷軸」 |
| 清除 | 進入任何非城鎮區域時 |
| 用途 | `返回上次掛機點` 的可執行條件之一 |
| 保存 | 角色本機設定，重開仍在 |

玩家自己走回城鎮不設旗標，**不會被自動傳回掛機點**。
條件「有上次掛機點」只看位置紀錄，不看旗標。

## 49.6 預設值

**空（不指派任何天賦格）。** 門檻涉及花錢與販售，一律由玩家自訂。
空的補給天賦＝不自動化，與空的戰鬥天賦（角色不出手）性質不同。

## 49.7 範例

```
#1 如果 背包已用格數 ≥ 38   → 回城
#2 如果 紅色藥水 少於 20    → 回城
#3 空條件                   → 存入裝備（存入條件：詞綴 Tier 高於 5）到共用倉庫
#4 空條件                   → 販售素材（Tier 2 以下，保留配方素材）
#5 空條件                   → 販售裝備（商店中階以下，保留：詞綴 Tier 高於 5、本角色穿得起的）
#6 如果 紅色藥水 少於 100   → 購買紅色藥水至 100
#7 如果 金幣多於 50000      → 存入金幣（身上留下 50000）
#8 空條件                   → 返回上次掛機點
```

存入排在販售前面：由上往下判定，先把要留的搬走，販售就不必倚賴保留條件寫得夠準。

> 這份範例需要 **8 個補給天賦格**。天賦格是通用資源、要跟戰鬥與常駐搶
> （`51-auto-talent.md` § 51.3.2），實務上是逐步長成的目標，不是起手配置。

## 49.8 不做

- 鐵匠鋪自動化（製作）與自動強化
- 賣不掉就丟棄（丟棄一律玩家手動，§ 35.5.3）
