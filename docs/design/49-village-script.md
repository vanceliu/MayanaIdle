# 49. 村莊腳本

第三套自動腳本，與戰鬥腳本（`03-combat.md` § 3.12）、常駐腳本（§ 3.13）併列。
有序規則列表，條件（AND）＋動作。屬於腳本 template（§ 3.14），跟著分頁切換。

## 49.1 判定

| 項目 | 值 |
|---|---|
| 判定頻率 | 1000ms |
| 判定順序 | 常駐腳本 → 緊急撤退 → 村莊腳本 |
| 判定地點 | 任何地方（不限城鎮） |
| 選中規則 | 由上往下，第一個「條件全成立且動作可執行」者 |

常駐腳本這一輪有動作時，村莊腳本不判定。

## 49.2 條件

| 條件 | 參數 |
|---|---|
| 永遠 | — |
| 背包已用格數 ≥ | N |
| 道具數量少於 | 道具 / N |
| 金幣少於 | N |
| 金幣多於 | N |

條件數為 0 等同「永遠」。

## 49.3 動作

| 動作 | 參數 | 可執行條件 |
|---|---|---|
| 回城 | 卷軸城鎮（留空＝任意） | 在野外 ＋ 有對應卷軸 |
| 販售素材 | 顏色門檻、保留配方素材 | 在城鎮 ＋ 有符合的素材 |
| 販售裝備 | 顏色門檻、保留條件 | 在城鎮 ＋ 有符合的裝備 |
| 購買道具至 | 道具、目標數量 | 在城鎮 ＋ 未達標 ＋ 買得起至少一個 |
| 存入素材 | 倉庫、顏色門檻、保留配方素材 | 在城鎮 ＋ 有符合的素材 |
| 存入裝備 | 倉庫、存入條件 | 在城鎮 ＋ 有符合的裝備 |
| 從倉庫取道具至 | 倉庫、道具、目標數量 | 在城鎮 ＋ 未達標 ＋ 倉庫有貨 ＋ 背包放得下 |
| 存入金幣（身上留下） | 留存金額 | 在城鎮 ＋ 身上金幣超過留存額 |
| 從倉庫領金幣至 | 目標金額 | 在城鎮 ＋ 未達標 ＋ 倉庫有金幣 |
| 返回上次掛機點 | — | 在城鎮 ＋ 有掛機點記錄 |

- 可執行條件不成立 → 跳過該規則，換下一條
- 購買與取出都是**補到 N 個**（達標即不再觸發），受金幣／倉庫存量限制
- 顏色門檻沿用 `39-batch-sell.md`：素材 `iconTier` 1–7、裝備 1–6
- 新手裝、`drop_only`、已裝備中的裝備一律不賣、不存
- 倉庫預設共用（`13-town.md` § 13.8）；金幣只有共用倉庫有
- 存入素材預設**不**保護配方素材（存倉庫不是丟掉），販售則預設保護
- 存入裝備**沒設條件就不存**，不做「整包倒進倉庫」的預設

## 49.4 裝備篩選條件

販售裝備與存入裝備共用同一份設定，方向相反：
販售時命中＝保留（不賣），存入時命中＝要存。符合**任一**條即命中。

| 條件 | 參數 |
|---|---|
| 詞綴 Tier 高於 | N |
| 帶有指定詞綴 | 詞綴清單 |
| 本職業可裝備的 | — |
| 指定裝備類型 | 類型清單（武器類型或 `armor`） |
| 白名單 | 裝備模板 |

無 `requiredClass` 的裝備視為全職業可裝備。

## 49.5 上次掛機點

```
HuntLocation = { zoneId, regionId, floor, x, y }
```

| 項目 | 規則 |
|---|---|
| 記錄時機 | 村莊腳本「回城」與緊急撤退回城 |
| 不記錄 | 城鎮 |
| 返回方式 | 一般地圖切換（`38-map-control.md`），需通行卷軸的區域照樣要卷軸 |
| 保存 | 角色本機設定，重開仍在 |

## 49.6 預設值

**空（無任何規則）。** 門檻涉及花錢與販售，一律由玩家自訂。
空腳本＝不自動化，與空的戰鬥腳本（角色不出手）性質不同。

## 49.7 範例

```
#1 如果 背包已用格數 ≥ 38   → 回城
#2 如果 紅色藥水 少於 20    → 回城
#3 永遠                     → 存入裝備（存入條件：詞綴 Tier 高於 5）到共用倉庫
#4 永遠                     → 販售素材（Tier 2 以下，保留配方素材）
#5 永遠                     → 販售裝備（商店中階以下，保留：詞綴 Tier 高於 5、本職業可裝備）
#6 如果 紅色藥水 少於 100   → 購買紅色藥水至 100
#7 如果 金幣多於 50000      → 存入金幣（身上留下 50000）
#8 永遠                     → 返回上次掛機點
```

存入排在販售前面：規則由上往下，先把要留的搬走，販售就不必倚賴保留條件寫得夠準。

## 49.8 不做

- 鐵匠鋪自動化（強化、製作）
- 賣不掉就丟棄（丟棄一律玩家手動，§ 35.5.3）
