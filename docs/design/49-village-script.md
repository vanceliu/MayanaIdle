# 49. 補給天賦

第三套自動天賦，與戰鬥天賦（`03-combat.md` § 3.12）、常駐天賦（§ 3.13）併列。
有序的天賦格列表，條件槽（AND）＋動作槽。屬於天賦配置（§ 3.14），跟著分頁切換。

> **本文件是補給天賦的條件與動作規格出處。** 條件與動作一律內建、全部可選，
> 天賦格怎麼取得見 `51-auto-talent.md`。

## 49.1 判定

| 項目 | 值 |
|---|---|
| 判定頻率 | **1200ms** —— 掛在常駐的 300ms 迴圈上，`VILLAGE_TICK_MS = 1000` 的下一個倍數 |
| 判定順序 | 常駐天賦 → 緊急撤退 → 補給天賦 |
| 判定地點 | 任何地方（不限城鎮） |
| 選中的天賦格 | 由上往下，第一個「條件全成立且動作可執行」者 |

常駐天賦這一輪有動作時，補給天賦不判定。

## 49.2 條件

| 條件 | 參數 |
|---|---|
| 在城鎮／在野外 | — |
| 背包已用格數 ≥ | N |
| 背包剩餘格數 ≤ | N |
| 道具數量少於 | 道具 / N |
| 金幣少於 | N |
| 金幣多於 | N |
| 有上次掛機點 | — |
| 負重超過 X% | X（`20-attributes.md` § 20.7） |
| 倉庫金幣 ≥ | 倉庫 / N |
| 倉庫有指定道具 ≥ | 倉庫 / 道具 / N |

條件槽全空等同「永遠」。「道具數量少於」與「所在區域 ＝ 指定區域」
同時適用常駐天賦（`51-auto-talent.md` § 51.2.1）。「負重超過 X%」三類型共用
（`51-auto-talent.md` § 51.4.5）。

## 49.3 動作

| 動作 | 參數 | 可執行條件 |
|---|---|---|
| 回城 | 卷軸城鎮（留空＝任意） | 在野外 ＋ 有對應卷軸 |
| 返回上次掛機點 | — | 在城鎮 ＋ 有掛機點記錄 ＋ 待返回（§ 49.5） |
| 使用旅館 | — | 在城鎮 ＋ 金幣足夠（`13-town.md` § 13.7） |
| 購買道具至 | 道具、目標數量（**最多 3 組**） | 在城鎮 ＋ 未達標 ＋ 買得起至少一個 |
| 販售素材 | 顏色門檻、保留有用途的素材、素材白名單 | 在城鎮 ＋ 有符合的素材 |
| 販售裝備 | 顏色門檻、保留條件（§ 49.4） | 在城鎮 ＋ 有符合的裝備 |
| 存入素材 | 倉庫（帳號／個人）、顏色門檻、保留有用途的素材 | 在城鎮 ＋ 有符合的素材 |
| 存入裝備 | 倉庫（帳號／個人）、存入條件（§ 49.4） | 在城鎮 ＋ 有符合的裝備 |
| 存入指定道具 | 倉庫、道具、身上留下數量（**最多 3 組**） | 在城鎮 ＋ 任一組身上數量超過留下數量 |
| 拆解裝備 | Tier 門檻、含帶技能的掉落品、會出結晶的處理、含製作品、保留條件（§ 49.4） | 在城鎮 ＋ 有符合的裝備 ＋ 背包放得下（§ 49.4.1） |
| 丟棄裝備 | Tier 門檻、丟哪些、保留條件（§ 49.4） | 有符合的裝備（**不限城鎮**，§ 49.4.2） |
| 從倉庫取道具至 | 倉庫、道具、目標數量（**最多 3 組**） | 在城鎮 ＋ 未達標 ＋ 倉庫有貨 ＋ 背包放得下 |
| 存入金幣（身上留下） | 留存金額 | 在城鎮 ＋ 身上金幣超過留存額 |
| 從倉庫領金幣至 | 目標金額 | 在城鎮 ＋ 未達標 ＋ 倉庫有金幣 |

- 可執行條件不成立 → 跳過該天賦格，換下一個
- **道具一律玩家自選，沒有綁定類別的限縮版**（`51-auto-talent.md` § 51.4.1）
- **一「組」＝ 一個道具 ＋ 一個目標數量**（存入指定道具為留下數量），最多 3 組，第 2、3 組選填
- 多組動作一輪處理全部組，金幣與背包格數依組的順序扣；同一道具重複只算第一組
- **素材白名單**：指定的素材永遠不賣，補 `hasMaterialUsage()` 涵蓋不到的情況
  （例：收集任務的目標素材沒有配方用途）
- **門檻一定要設** —— 沒有門檻會把剛掉的高階裝備一起賣掉
- 購買與取出都是**補到 N 個**（達標即不再觸發），受金幣／倉庫存量限制
- 購買只限所在城鎮雜貨店貨架上的道具（`13-town.md` § 13.4），單價依貨架；貨架以外的道具不成交
- 顏色門檻沿用 `39-batch-sell.md`：素材 `iconTier` 1–7、裝備 1–6
- 新手裝、`drop_only`、已裝備中的裝備一律不賣、不存
- 倉庫預設帳號倉庫（`13-town.md` § 13.8）；金幣動作只走帳號倉庫
- 補給天賦不碰公會倉庫（`11-guild.md` § 11.8），公會倉庫只能手動存取
- 存入素材預設**不**保護有用途的素材（存倉庫不是丟掉），販售則預設保護
- 存入裝備**沒設條件就不存**，不做「整包倒進倉庫」的預設
- 存入指定道具：每組存入「身上數量 − 留下數量」

## 49.4 裝備篩選條件

販售、拆解、丟棄裝備與存入裝備共用同一份設定，方向不同：
販售、拆解、丟棄時命中＝保留（不賣、不拆、不丟），存入時命中＝要存。符合**任一**條即命中。

| 條件 | 參數 |
|---|---|
| 詞綴 Tier 高於 | N |
| 帶有指定詞綴 | 詞綴清單 |
| 本角色穿得起的 | — |
| 指定裝備類型 | 類型清單（武器類型、盾牌、魔法書、臂甲或 `armor`；飾品屬 `armor`） |
| 白名單 | 裝備模板（新手裝以外） |

- 「本角色穿得起的」兼總開關（存入裝備字樣為「存入本角色穿得起的」），預設開啟：
  **未開啟＝沒有篩選條件**（販售與拆解不保留任何裝備、存入裝備不存）；開啟後其餘四種才可設定
- 預設：詞綴 Tier 高於 5，其餘三種未選
- 編輯器：三種清單條件為多選，平時顯示摘要（未選／前兩項名稱／共 N 項），點開勾選；白名單可搜尋名稱

### 本角色穿得起的

命中條件是 `requiredClass` 通過 **AND** `requiredAttributes` 通過。條件內是 AND，
與其他條件之間仍是 OR。無 `requiredClass` 視為全職業，無 `requiredAttributes` 視為無素質門檻。

素質判定的基準是**角色自身屬性（建角配點＋升級配點），不含裝備、不含 buff**。
與 § 6A.8.8 凍結判定的最小固定點**刻意不同**：販售不可逆，基準不能隨當下穿戴集合與 buff 變動。

### 49.4.1 拆解裝備

規則與手動拆解相同（`06-equipment-acquire.md` § 6A.3「拆解」），一輪拆完所有符合者。

| 參數 | 規則 | 預設 |
|---|---|---|
| Tier 以下 | 裝備階級（`tier`）4~7 | 4 |
| 含帶技能的掉落品 | 無配方、只得技能結晶的掉落品，開啟才拆 | 關 |
| 會出結晶的 | 新或更強才拆／照拆／不拆；「新或更強」＝新種類或會變強（§ 7S.8），同一輪依序與最新的結晶清單比 | 新或更強才拆 |
| 含製作品 (鍛) | 開啟才拆 | 關 |
| 保留條件 | § 49.4，命中＝不拆 | 同販售裝備 |

- 已裝備中的、新手裝一律不拆
- 背包放不下該件退還材料的那件跳過，其餘照拆

### 49.4.2 丟棄裝備

一輪丟完所有符合者，**無法復原**；手動丟棄見 `35-inventory-constraints.md` § 35.5.3。

| 參數 | 規則 | 預設 |
|---|---|---|
| Tier 以下 | 裝備階級（`tier`）1~7 | 3 |
| 丟哪些 | 賣不掉的／賣得掉的／都丟；賣得掉＝售價 > 0 | 賣不掉的 |
| 保留條件 | § 49.4，命中＝不丟 | 同販售裝備 |

- 已裝備中的、新手裝一律不丟

## 49.5 上次掛機點

位置與返回意圖是兩件事，分開存。

```
HuntLocation = { zoneId, regionId, floor }
```

| 項目 | 規則 |
|---|---|
| 記錄時機 | **進入任何非城鎮區域時**（含手動切換地圖） |
| 不記錄 | 城鎮 |
| 返回方式 | 一般地圖切換（`38-map-control.md`），需通行卷軸的區域照樣要卷軸 |
| 保存 | 角色本機設定，重開仍在 |

**待返回旗標**

| 項目 | 規則 |
|---|---|
| 設起 | 補給天賦「回城」、緊急撤退回城、常駐天賦「使用回城卷軸」；從競技場回城不設（`55-arena.md` § 55.5） |
| 清除 | 進入任何非城鎮區域時 |
| 用途 | `返回上次掛機點` 的可執行條件之一 |
| 保存 | 角色本機設定，重開仍在 |

玩家自己走回城鎮不設旗標，**不會被自動傳回掛機點**。
條件「有上次掛機點」只看位置紀錄，不看旗標。

## 49.6 預設值

**空（不指派任何天賦格）。** 門檻涉及花錢與販售，一律由玩家自訂。
空的補給天賦＝不自動化，與空的戰鬥天賦（角色不出手）性質不同。

## 49.7 範例

```
#1 如果 背包已用格數 ≥ 38   → 回城
#2 如果 紅色藥水 少於 20    → 回城
#3 空條件                   → 存入裝備（存入條件：詞綴 Tier 高於 5）到帳號倉庫
#4 空條件                   → 販售素材（Tier 2 以下，保留有用途的素材）
#5 空條件                   → 販售裝備（商店中階以下，保留：詞綴 Tier 高於 5、本角色穿得起的）
#6 如果 紅色藥水 少於 100   → 購買紅色藥水至 100
#7 如果 金幣多於 50000      → 存入金幣（身上留下 50000）
#8 空條件                   → 返回上次掛機點
```

存入排在販售前面：由上往下判定，先把要留的搬走，販售就不必倚賴保留條件寫得夠準。

> 這份範例需要 **8 個補給天賦格**。天賦格是通用資源、要跟戰鬥與常駐搶
> （`51-auto-talent.md` § 51.3.2），實務上是逐步長成的目標，不是起手配置。

## 49.8 不做

- 鐵匠鋪自動製作、自動技能更換與自動強化（拆解見 § 49.4.1）
