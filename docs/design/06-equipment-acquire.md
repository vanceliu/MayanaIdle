# 裝備取得系統

## 6A.1 取得方式總覽

裝備依強度分為兩種取得途徑：

| 分級 | 取得方式 | 對應強度 |
|---|---|---|
| 一般級 | 武器店 / 防具店直接購買 | 低階～中階 |
| 高級 | 鐵匠鋪製作（素材 + 金幣） | 高階入門～頂級 |

### 分級判定原則

- 備註標記「共用低階」「共用中階」→ 商店販售
- 鐵材質、無特殊加成、多職業可用的低階裝備 → 商店販售
- 銀 / 米索利 / 奧里哈魯根 / 龍材質 → 鐵匠鋪製作
- 安定值 0 → 鐵匠鋪製作（頂級）
- 標記「專屬」且傷害 / 防禦高於同類商店最高 → 鐵匠鋪製作

## 6A.2 商店購買價格

### 武器商店

| 裝備強度 | 價格範圍 |
|---|---|
| 最低階（共用低階） | 5,000~20,000 |
| 中低階 | 30,000~80,000 |
| 中階（共用中階） | 100,000~250,000 |

### 防具商店

| 裝備強度 | 價格範圍 |
|---|---|
| 最低階（共用低階） | 3,000~15,000 |
| 中低階 | 20,000~60,000 |
| 中階（共用中階） | 80,000~200,000 |

## 6A.3 鐵匠鋪製作規則

### 製作公式

```
製作金幣（武器）= (該武器小怪傷害 - 同類型商店最高傷害) × 100,000
製作金幣（防具）= (該防具防禦力 - 同類型商店最高防禦) × 50,000
上限：單件製作金幣 ≤ 1,000,000
```

### 素材需求

| 製作等級 | 素材種類數 | 每種數量 | 總素材量 |
|---|---|---|---|
| 高階入門 | 3 種 | 各 3~5 個 | 9~15 |
| 高階中段 | 4 種 | 各 5~8 個 | 20~32 |
| 頂級 | 5 種 | 各 8~12 個 | 40~60 |

### 製作等級判定

| 製作等級 | 判定條件 |
|---|---|
| 高階入門 | 銀材質、安定值 6、傷害差 ≤ 4 |
| 高階中段 | 米索利 / 龍材質、安定值 6、傷害差 5~8 |
| 頂級 | 安定值 0、奧里哈魯根、或傷害差 ≥ 9 |

### 素材來源

- 素材由對應區域怪物掉落
- 素材類型與武器材質相關（銀礦、米索利礦、龍骨碎片等）
- 高階區域掉落高階素材，低階區域不掉

## 6A.6 設計原則

1. 武器定價基準：每 +1 傷害 = 100,000 金幣，上限 1,000,000
2. 防具定價基準：每 +1 防禦 = 50,000 金幣，上限 1,000,000
3. 飾品（項鍊、戒指）與魔導書不適用傷害/防禦公式，以效果價值手動定價
4. 腰帶全部商店販售（功能為負重，非戰鬥核心）
5. 傷害差為 0 或負值的製作裝備，因具備特殊附加效果（回血、回魔、額外屬性），仍有製作價值，給予最低製作費
6. 鐵匠鋪製作一律必定成功，無失敗機制（與強化系統區分）
