# 裝備取得系統

## 6A.1 取得方式總覽

裝備依強度分為三種取得途徑：

| 分級 | 取得方式 | 對應強度 |
|---|---|---|
| 一般級 | 武器店 / 防具店直接購買 | 低階～高階 |
| 一般級 | 怪物掉落池（隨機從同級商店裝備池抽取） | 低階～高階 |
| 高級 | 鐵匠鋪製作（素材 + 金幣） | 高級入門～頂級 |

### 掉落池機制

商店裝備依價格分為三個掉落池，怪物擊殺時有機率從對應池中隨機掉落一件：

| 池子 | 對應 shopTier | 價格範圍 | 掉落區域 | 掉率 |
|---|---|---|---|---|
| 低階池 | low | ≤ 20,000 | 曙光草原～風語林地（Lv.1~15） | 1.5% |
| 中階池 | mid | 20,001~80,000 | 迷霧沼澤～試煉高地（Lv.16~25） | 1~1.5% |
| 高階池 | high | > 80,000 | 試煉高地頂部～象牙塔 4F（Lv.26~35） | 1~1.5% |

掉落池從整個 tier 的武器+防具中隨機抽取，不限職業、不限部位。掉落的裝備自帶隨機詞綴。

### 分級判定原則

- 備註標記「共用低階」「共用中階」→ 商店販售
- 鐵材質、無特殊加成、多職業可用的低階裝備 → 商店販售
- 銀 / 米索利 / 奧里哈魯根 / 龍材質 → 鐵匠鋪製作
- 安定值 0 → 鐵匠鋪製作（頂級）
- 標記「專屬」且傷害 / 防禦高於同類商店最高 → 鐵匠鋪製作

## 6A.3 鐵匠鋪製作規則

### 製作公式

```
製作金幣（武器）= (該武器小怪傷害 - 同類型商店最高傷害) × 100,000
製作金幣（防具）= (該防具防禦力 - 同類型商店最高防禦) × 50,000
上限：單件製作金幣 ≤ 1,000,000
```

### 素材需求

| 製作等級 | 素材種類數 | 每種數量 | 總素材量 |
|---|---|---|---|
| 高級入門 | 3 種 | 各 2~5 個 | 8~13 |
| 高級進階 | 4 種 | 各 3~8 個 | 16~26 |
| 頂級 | 5~6 種 | 各 5~18 個 + Boss ×2~3 | 40~59 (+Boss) |

### 製作等級判定

| 製作等級 | 判定條件 |
|---|---|
| 高級入門 | 銀材質、安定值 6、傷害差 ≤ 4 |
| 高級進階 | 米索利 / 龍材質、安定值 6、傷害差 5~8 |
| 頂級 | 安定值 0、奧里哈魯根、或傷害差 ≥ 9 |

### 素材來源

製作配方採用「區域素材 + 通用基底素材」組合模式。每個配方的區域素材集中於同一區域，讓玩家在該區域農怪即可湊齊大部分材料。

| 製作等級 | 區域素材來源 | 通用基底素材 |
|---|---|---|
| 高級入門 | 試煉高地 (Lv.21~30) + 象牙塔 (Lv.30~35) | 銀礦石 ×2~3 |
| 高級進階 | 艾爾薩斯 / 瓦爾登 / 龍之谷 擇一區域 (Lv.30~50) | 米索利碎片 ×3~4 |
| 頂級 | 灰脊山脈 (Lv.40~60) + Boss 專屬素材 | 奧里哈魯根碎片 ×5~8 |

#### 高級進階素材模式（6 種配方組合）

每個配方使用同一區域的 3 種素材 + 米索利碎片：

| 模式 | 區域 | 素材 A | 素材 B | 素材 C |
|---|---|---|---|---|
| 1 | 艾爾薩斯 | 高等妖魔角 | 蟲殼碎片 | 洞窟菌絲 |
| 2 | 艾爾薩斯 | 妖魔鬥士護符 | 幻獸水晶 | 巨人指骨 |
| 3 | 瓦爾登 | 鏡面碎片 | 亡靈碎骨 | 潮汐珠 |
| 4 | 瓦爾登 | 光影狐尾毛 | 深海藻液 | 幻光鱗粉 |
| 5 | 龍之谷 | 飛龍鱗片 | 剝皮蛛牙 | 死亡靈魂殘片 |
| 6 | 龍之谷 | 骷髏兵裝飾 | 大莫蛛眼 | 亞利安結晶 |

- 區域素材由對應區域怪物掉落（10~12%），詳見 `30-items.md` 區域素材表及 `27-drop-table.md`
- 通用基底素材（銀礦石、米索利碎片、奧里哈魯根碎片等）保留原掉落規則
- 入門級素材從 Lv.21 試煉高地即可開始收集，玩家到 Lv.30+ 時自然湊齊
- 頂級製作額外需要 Boss 專屬素材 ×2~3（30% 掉率），為長期收集目標
- 所有區域素材皆可賣給雜貨店，玩家可自行決定賣錢或留存製作

### 前置武器需求

鐵匠鋪製作的高級進階以上武器，除素材與金幣外，需額外提供前置武器作為材料：

| 規則 | 說明 |
|---|---|
| 前置數量 | 一般為 x1；匕首→雙刀/鋼爪為 x2 |
| 素質限制 | 不限（強化值、詞綴、品質皆不影響） |
| 消耗 | 製作後前置武器消失 |
| 前置來源 | 必須為鐵匠製作品（商店品不可作為前置） |
| 升級路線 | 同類型內升級 + 跨類型升級（單手→雙手）皆有 |
| 入門品 | 入門級製作品無前置需求，可直接以素材+金幣製作 |

## 6A.6 設計原則

1. 武器定價基準：每 +1 傷害 = 100,000 金幣，上限 1,000,000
2. 防具定價基準：每 +1 防禦 = 50,000 金幣，上限 1,000,000
3. 飾品（項鍊、戒指）與魔導書不適用傷害/防禦公式，以效果價值手動定價
4. 腰帶低～中階由商店販售，頂級（+5000 附屬性）由鐵匠鋪製作
5. 傷害差為 0 或負值的製作裝備，因具備特殊附加效果（回血、回魔、額外屬性），仍有製作價值，給予最低製作費
6. 鐵匠鋪製作一律必定成功，無失敗機制（與強化系統區分）
