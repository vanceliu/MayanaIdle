# 7T. T7 獨有詞綴

## 7T.1 定位

裝備階級 T7（`06-equipment-acquire.md` § 6A.1）的每一件，在 4 條一般詞綴（`07-affix.md`）之外
另帶 **1 條獨有詞綴**。T7 共 49 件，全部涵蓋。

- 取得當下決定（種類與數值），之後不變
- 只有 T7 裝備會有；一般詞綴池、特殊詞綴池都不含這些詞綴

## 7T.2 通用規則

| 項目 | 規則 |
|---|---|
| 數值 | 區間內整數均等抽；標「固定」者不抽 |
| Tier | 無 Tier，不參與滿值粗體（`07-affix.md` § 7.3.2） |
| 品質 | **不吃品質**（`08-quality.md` 的倍率只作用於 4 條一般詞綴） |
| 印記 | **任何印記都不受理**：混沌重骰的 4 條不含它；刺針／重刻／精鍊／突破不可指定它 |
| 素質需求 | 未滿足時與 4 條一般詞綴一併凍結（`06-equipment.md` § 6A.8.8） |
| 與一般詞綴 | 與同類一般詞綴**共存**，各自生效、加算 |
| 上限 | 照原上限：迴避 35%、格擋 50%、爆擊率 75%、攻擊間隔下限、魔法減傷 75% |
| 舊實例 | 本規則上線前取得的 T7 由 server 遷移補抽一次（`97-selfhosted-server.md` § 97.4） |

## 7T.3 同類去重

同時穿著多件 T7、獨有詞綴**種類相同**時，**只有一件生效**：

1. 數值最高者生效
2. 同值（含無數值的全免疫）依部位順序取第一件：
   右手 → 左手 → 頭盔 → 胸甲 → 上衣 → 斗篷 → 腰帶 → 手套 → 鞋子 → 項鍊 → 戒指 1 → 戒指 2
3. 素質需求未滿足而凍結的件不參與比較

未生效的那條在 tooltip **劃線**顯示（§ 7T.7）。
武器、腰帶、左手各只能穿一件，實際會撞到的只有一般防具六部位之間、飾品三部位之間。

## 7T.4 觸發規則

| 類型 | 規則 |
|---|---|
| 受擊觸發 | **受到傷害**時判定（被迴避不算）；機率 10%；buff 持續 5 秒；存續期間再觸發**刷新時間**（同 `24-buff-debuff.md` § 24.3.1）；顯示於 buff 列 |
| 命中觸發 | 普攻與魔法命中都判定；**每一下命中判定一次**（雙持一次攻擊兩下、多段技能逐發、範圍魔法逐目標） |
| 擊殺觸發 | 擊殺一隻判定一次；攻擊與自己施加的 DoT（中毒、流血、元素侵蝕等）造成的擊殺都算 |
| 命中暈眩 | 5 秒；暈眩中不可再上（`24-buff-debuff.md` § 24.3.3）；Boss 照吃，受 § 24.6 控場免疫冷卻約束 |
| 追加傷害 | 加在該下**最終傷害**（防禦減傷之後），不吃攻擊力%、爆擊與怪物防禦 |

## 7T.6 屬性類的歸屬

- **全屬性**比照額外屬性（`20-attributes.md` § 20.10）：不受 35 點上限、不影響升級 HP/MP 成長，
  計入素質需求最小固定點的裝備加成
- **受擊加屬性**的 buff 屬於角色 buff，計入素質需求的起算值（同其他 buff）

## 7T.7 顯示

- 裝備 tooltip：第一行 `(獨) 名稱 數值`，紫色 `#A855F7`；下方分隔線，再列 4 條一般詞綴
- 同類去重落敗：該行劃線，tooltip「同類獨有詞綴已由其他裝備生效」
- 素質需求凍結：與一般詞綴同一個凍結樣式
- Wiki：詞綴頁列全部；武器頁列武器池；防具頁列防具池、飾品池與指定表（`43-wiki-system.md`）
