# 35. 背包系統限制與規格（Inventory System Constraints）

> 本文件為背包系統的**完整限制清單**，所有實作必須嚴格遵守。  
> AI 實作前必須逐條確認，不可省略或簡化任何規則。

---

## 35.1 容量與格數限制

| 規則 | 說明 |
|------|------|
| 固定格數 | 背包固定 **100 格**（`BAG_MAX_SLOTS = 100`），不可擴充、不可縮減 |
| 格子佈局 | 固定 **5 欄**（`BAG_COLUMNS = 5`），無收合功能 |
| 堆疊規則 | 同名消耗品（藥水/卷軸/素材/魔法書）堆疊在同一格，**不佔新格** |
| 裝備佔格 | 每件裝備實例各佔 **1 格**，不可堆疊 |
| 容量計算 | `usedSlots = bagItems.length + inventory.length`（bagItems 每種佔 1 格） |
| 堆疊上限 | 消耗品/素材**無堆疊數量上限**（僅受負重限制） |

---

## 35.2 負重系統（暫時停用）

> **目前僅透過格子數量上限（100 格）限制背包，負重懲罰暫不實作。**  
> 負重條仍作為 UI 資訊顯示，但不產生任何遊戲懲罰。  
> 未來若需啟用，參考 `20-attributes.md` § 20.7 的公式。

### 35.2.1 負重顯示（僅資訊用途）

- 位置：左側 StatusPanel，HP/MP 條下方
- 格式：`{current}/{max} ({percent}%)`
- 顏色：正常時灰色漸層，超重時紅色（僅視覺提示，無遊戲懲罰）
- 負重條與防禦值**同行顯示**

## 35.3 背包已滿處理規則

### 35.3.1 容量檢查時機（所有入口必查）

| 入口 | 已滿時行為 |
|------|------------|
| 怪物掉落（`gameStore.ts` dropQueue） | 丟棄掉落物，戰鬥日誌顯示「背包已滿」 |
| 武器商店購買（`WeaponShop.tsx` `buyWeapon`） | 禁止購買，顯示提示 |
| 防具商店購買（`ArmorShop.tsx` `buyArmor`） | 禁止購買，顯示提示 |
| 雜貨店購買（`GeneralStore.tsx` `canAddToBag` + `buyBagItem`） | 禁止購買，顯示提示 |
| 鐵匠鋪製作（`TownBlacksmith.tsx` `handleCraft`） | 禁止製作，顯示提示 |
| 魔法學院製作（`MagicAcademy.tsx`） | 禁止製作，顯示提示 |
| 倉庫取出（`Storage.tsx` `withdrawEquip` / `withdrawMaterial`） | 禁止取出，顯示提示 |
| 脫下裝備（`gameStore.ts` `unequipItem`） | 禁止脫下，顯示提示「背包已滿，無法卸除裝備」 |
| 職業工會任務獎勵（`gameStore.ts` `completeQuest`） | 禁止交任務，顯示提示 |

### 35.3.2 堆疊例外

- 若背包已有同名消耗品，即使格數已滿 100，仍可累加數量（因不佔新格）
- 範例：背包已 100 格但有紅色藥水 ×5 → 再獲得紅色藥水 → 數量變 ×6，不占新格

### 35.3.3 顯示格式

- Header 區域顯示：`{usedSlots}/{BAG_MAX_SLOTS}`（如 `87/100`）
- 當 usedSlots >= 90 時，文字顏色改為**警告色**（黃色）
- 當 usedSlots = 100 時，文字顏色改為**危險色**（紅色）

## 35.4 物品分類與佔格規則

| 分類 | type 值 | 堆疊 | 每種佔格 | 範例 |
|------|---------|------|----------|------|
| 藥水 | `potion` | ✅ | 1 格 | 紅色藥水 ×20 佔 1 格 |
| 卷軸 | `scroll` | ✅ | 1 格 | 回城卷軸 ×5 佔 1 格 |
| 素材 | `material` | ✅ | 1 格 | 銀礦石 ×8 佔 1 格 |
| 魔法書 | `spellbook` | ✅ | 1 格 | 魔法書碎片 ×3 佔 1 格 |
| 裝備 | `equipment` | ❌ | 1 格/件 | 每件獨立實例各佔 1 格 |

## 35.5 物品互動方式

### 35.5.1 左鍵點擊（主要操作）

| 物品類型 | 點擊效果 |
|----------|----------|
| 藥水 | 使用藥水（`usePotionByType()`） |
| 裝備 | 穿上裝備（`equipItem()`） |
| 回城卷軸 | 使用傳送（`useTownScroll()`） |
| 素材 | 無操作（素材不可直接使用） |
| 魔法書 | 無操作（需至魔法學院使用） |
| 強化卷軸 | 無操作（需至鐵匠鋪使用） |

### 35.5.2 右鍵選單（Context Menu）

| 物品類型 | 選單選項 |
|----------|----------|
| 藥水 | 「設快捷鍵 1~5」、「丟棄」 |
| 裝備 | 「丟棄」 |
| 卷軸 | 「丟棄」 |
| 素材 | 「丟棄」 |
| 魔法書 | 「丟棄」 |

**丟棄規則：**
- 堆疊物品：每次丟棄 **1 個**（amount - 1，歸零時移除該格）
- 裝備：直接移除該實例（從 inventory 移除 + 刪除 DB 記錄）
- 丟棄**不可撤回**，無確認對話框（Idle 遊戲流暢性優先）

### 35.5.3 Hover 互動（Tooltip）

所有物品 hover 時顯示 tooltip，延遲 200ms 觸發。

## 35.6 Tooltip 顯示規格

### 35.6.1 消耗品 Tooltip

```
┌─────────────────────────┐
│ {物品名稱}               │  ← 名稱
│ {效果描述}               │  ← 如「回復 HP 50~100」
│ 重量：{weight × amount}  │  ← 總重量
│ 數量：×{amount}          │  ← 堆疊數量
│ 「點擊使用」             │  ← 使用提示（僅可使用物品）
└─────────────────────────┘
```

### 35.6.2 素材 Tooltip

```
┌─────────────────────────┐
│ {物品名稱}               │
│ {用途描述}               │  ← 如「鐵匠鋪製作素材」
│ 重量：{weight × amount}  │
│ 數量：×{amount}          │
└─────────────────────────┘
```

### 35.6.3 裝備 Tooltip（使用 `<EquipmentDetail>` 完整模式）

顯示欄位順序（強制）：
1. 裝備名稱 + 強化等級（如 `+7`）
2. 部位
3. 攻擊力（格式：`基礎+強化 / 基礎+強化`，小怪/大怪）
4. 防禦力（格式：`基礎+強化`）
5. 格擋率（盾牌）
6. 攻擊成功（命中加成）
7. 額外攻擊
8. 魔法攻擊
9. HP+
10. MP+
11. 回血+
12. 回魔+
13. 負重+（腰帶）
14. 額外屬性（如力量+1）
15. 材質
16. 重量
17. 品質%（有強化過才顯示）
18. 詞綴列表（Tier 色階）
19. 可用職業

**裝備 Tooltip 規則：**
- 使用 `<EquipmentDetail>` **完整模式**（非 compact）
- 必須顯示重量、部位、材質、可用職業
- 詞綴顏色依 Tier 等級（T1 灰 → T7 紫+光暈）

### 35.6.4 Tooltip 通用規則

| 規則 | 說明 |
|------|------|
| 觸發方式 | Hover（非 click） |
| 延遲時間 | 200ms |
| 渲染方式 | Portal 至 body（避免 overflow 裁切） |
| 定位 | 自動偵測邊界翻轉 |
| 樣式 | 背景 `var(--bg-card)`、邊框 `var(--border)`、陰影 `var(--shadow-card)` |

## 35.7 快捷鍵系統

### 35.7.1 快捷欄規格

| 屬性 | 值 |
|------|-----|
| 格數 | 5 格 |
| 可放物品 | **僅藥水** |
| 儲存位置 | localStorage（`mayana_prefs_${characterId}.quickSlots`） |
| 觸發方式 | 數字鍵 `1` ~ `5` |

### 35.7.2 快捷鍵綁定操作

- **設定**：BagPanel 中藥水右鍵 → 「設快捷鍵 1~5」
- **清除**：QuickSlotBar 上右鍵 → 清除該格綁定
- **使用**：按數字鍵 `1`~`5` → 使用對應快捷欄藥水

### 35.7.3 快捷鍵排除條件

- 當焦點在 `<input>` 或 `<textarea>` 時，**不觸發**快捷鍵
- 藥水數量為 0 時，按快捷鍵**無反應**

### 35.7.4 快捷欄顯示

| 藥水類型 | Icon | 顏色 |
|----------|------|------|
| 紅色藥水 | `standing-potion` | `#DC2626` |
| 橙色藥水 | `bubbling-flask` | `#F59E0B` |
| 白色藥水 | `potion-ball` | `#E2E8F0` |

- 顯示剩餘數量 badge
- 已設定快捷鍵的藥水在 BagPanel 中顯示綁定標記

### 35.7.5 目前無背包面板快捷鍵

以下操作目前**無鍵盤快捷鍵**（僅滑鼠操作）：
- 開關背包面板
- 整理背包
- 丟棄物品
- 裝備穿脫

## 35.8 整理功能

### 35.8.1 排序規則（優先順序）

1. 藥水（potion）
2. 卷軸（scroll）
3. 素材（material）
4. 魔法書（spellbook）
5. 裝備（equipment）

同類內按**名稱字母排列**，空格推到最後方。

### 35.8.2 Toggle 行為

- 按一次「整理」→ 依規則排序
- 再按一次 → 恢復原始順序（排序前的狀態）
- 非永久改變，僅影響顯示順序

---

## 35.9 裝備穿脫規則

### 35.9.1 裝備（Equip）

| 檢查項目 | 失敗行為 |
|----------|----------|
| 職業限制 | 顯示「{職業}無法裝備此物品」 |
| 等級限制 | 顯示「等級不足」 |
| 雙手武器互斥 | 已裝備副手 → 「需先卸除副手裝備」 |
| 副手互斥 | 已裝備雙手武器 → 「無法裝備 XXX，已裝備雙手武器」 |

**成功流程：**
1. 從背包移除該裝備實例
2. 若目標欄位已有裝備 → 舊裝備回到背包（需容量檢查）
3. 新裝備放入目標欄位
4. 觸發持久化存檔

### 35.9.2 卸除（Unequip）

| 檢查項目 | 失敗行為 |
|----------|----------|
| 背包已滿 | 顯示「背包已滿，無法卸除裝備」，**禁止卸除** |

**成功流程：**
1. 從裝備欄移除
2. 放入背包 inventory
3. 觸發持久化存檔

## 35.10 藥水使用限制

| 限制條件 | 行為 |
|----------|------|
| HP 已滿（HP = maxHP） | 禁止使用，顯示「HP 已滿，無法使用藥水」 |
| 藥水冷卻中 | 禁止使用（全域共用冷卻：使用任一藥水 → 所有藥水進入冷卻） |
| 超重 | 禁止使用(暫不實作) |
| 數量為 0 | 無反應 |

**冷卻時間：**
| 藥水 | 冷卻 |
|------|------|
| 紅色藥水 | 600 毫秒 |
| 橙色藥水 | 900 毫秒 |
| 白色藥水 | 1500 毫秒 |

---

## 35.11 回城卷軸使用限制

| 規則 | 說明 |
|------|------|
| 綁定城鎮 | 每種回城卷軸綁定特定城鎮 |
| 消耗 | 使用消耗 1 張 |
| 無卷軸 | 無法回城（不存在免費回城） |
| 使用場景 | 戰鬥中、探索中皆可使用 |
| 效果 | 立即脫離戰鬥並傳送至指定城鎮 |
| 回城後 HP/MP | 維持當前值（**不自動回滿**） |
| 戰鬥腳本 | 「回城」action 需消耗回城卷軸；無卷軸則 action 不可執行 |

## 35.12 與倉庫互動規則

| 規則 | 說明 |
|------|------|
| 倉庫綁定 | 帳號（User）層級，所有角色共用 |
| 可存放物品 | 裝備、素材、消耗品 |
| 金幣存取 | 倉庫有獨立金幣欄位，角色可存入/取出 |
| 跨角色轉移 | 透過倉庫中轉（A 存入 → B 取出） |
| 刪除角色 | 不影響倉庫內物品 |
| 取出限制 | 背包已滿時不可取出（見 § 35.3） |
| 存入限制 | 無特殊限制（倉庫容量待設計文件補充） |

## 35.13 與鐵匠鋪互動規則

| 規則 | 說明 |
|------|------|
| 可見範圍 | 鐵匠鋪**必須能看到**玩家身上裝備與背包裝備 |
| 強化來源 | 可對身上裝備或背包裝備進行強化 |
| 材料消耗 | 從背包消耗對應卷軸/強化石/品質石 + 金幣 |
| 製作產出 | 製作完成的裝備進入背包（需容量檢查） |

## 35.14 與商店互動規則

| 規則 | 說明 |
|------|------|
| 購買 | 消耗金幣 → 物品進入背包（需容量檢查） |
| 販售 | 從背包選擇物品 → 獲得金幣 |
| 批量購買 | 買 1 / 買 10 按鈕（雜貨店） |
| 販售價格 | 由物品 sellPrice 決定 |

## 35.15 背包格子顯示規格

### 35.15.1 格子樣式

| 屬性 | 值 |

### 35.15.2 格子內容

### 35.15.3 數量 Badge

- 位置：格子**右上角**

- 格式：`×{amount}`

### 35.15.4 Header 資訊

- 頂部顯示金幣數量
- 顯示已用格數 `{used}/{max}`

## 35.16 Icon 系統規則

### 35.16.1 Icon 判斷邏輯（BagPanel 渲染）

| 優先序 | 條件 | Icon 來源 |
|--------|------|-----------|
| 1 | `potionType` 存在 | 藥水專用路徑（帶顏色區分） |
| 2 | `type === 'equipment'` | 裝備 icon 路徑 |
| 3 | 其他 | `getItemIcon(getItemIconKey(name, type))` |

### 35.16.2 getItemIconKey 映射

| 條件 | Icon Key |
|------|----------|
| `type === 'spellbook'` | `spellbook` |
| `type === 'scroll'` | `scroll` |
| 名稱含「磨刀石」 | `whetstone` |
| 名稱含其他「石」 | `stone` |
| 其他 material | `material`（預設） |

## 35.17 持久化規則

| 資料 | 儲存位置 | 觸發時機 |
|------|----------|----------|
| bagItems（消耗品） | IndexedDB（characters table） | 物品數量變更時 |
| inventory（裝備） | IndexedDB（equipment_instances） | 裝備穿脫/獲得/丟棄時 |
| quickSlots | localStorage（`mayana_prefs_${characterId}`） | 快捷欄設定變更時 |
| 金幣 | IndexedDB（characters table） | 金幣數量變更時 |

## 35.18 禁止事項（不可實作）

1. ❌ 不可增加背包格數（固定 100 格）
2. ❌ 不可新增背包擴充系統（花金幣買格子等）
3. ❌ 不可新增自動販售/自動丟棄功能
6. ❌ 不可新增物品篩選/搜尋功能（Idle 遊戲保持簡潔）

## 35.19 資料結構規格

### 35.19.1 BagItem（消耗品/素材）

```typescript
interface BagItem {
  name: string;        // 物品名稱（對應 item_definitions）
  type: 'material' | 'potion' | 'scroll' | 'spellbook';
  amount: number;      // 堆疊數量
}
```

### 35.19.2 EquipmentInstance（背包中的裝備）

```typescript
interface EquipmentInstance {
  id: string;                    // 實例唯一 ID
  itemTemplateId: string;        // 引用模板 ID
  ownerCharacterId: string;      // 持有角色
  location: 'bag' | 'warehouse' | 'equipped';
  equippedSlot?: string;         // 裝備欄位（僅 location='equipped' 時有值）
  qualityPercent: number;        // 品質%
  baseSmallMonsterDamage: number;
  baseLargeMonsterDamage: number;
  // ...其他欄位見 18-data-schema.md
}
```

### 35.19.3 Store Actions

| Action | 功能 |
|--------|------|
| `addPotionToBag(type, amount)` | 新增/累加藥水 |
| `consumePotionFromBag(type)` | 消耗 1 瓶藥水 |
| `discardBagItem(name)` | 丟棄消耗品（-1） |
| `discardInventoryItem(id)` | 丟棄裝備實例 |
| `getBagUsedSlots()` | 取得已用格數 |
| `isBagFull()` | 檢查是否已滿 |
| `getPotionCount(type)` | 取得藥水數量 |
