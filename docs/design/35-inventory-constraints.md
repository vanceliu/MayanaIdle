# 35. 背包系統限制與規格（Inventory System Constraints）

> 本文件為背包系統的**完整限制清單**，所有實作必須嚴格遵守。  
> AI 實作前必須逐條確認，不可省略或簡化任何規則。

---

## 35.1 容量與格數限制

| 規則 | 說明 |
|------|------|
| 基礎格數 | 背包基礎 **50 格**（`BAG_BASE_SLOTS = 50`） |
| 腰帶擴充 | **腰帶可擴充格數**（`bonusBagSlots`），最高 +15 → 上限 **65 格** |
| 實際格數 | `getBagMaxSlots(equippedGear) = 50 + 腰帶 bonusBagSlots` |
| 擴充來源 | **只有腰帶**。不可新增其他背包擴充管道（道具、金幣購買、等級成長皆禁止） |
| 格子佈局 | 固定 **5 欄**（`BAG_COLUMNS = 5`），無收合功能 |
| 堆疊規則 | 同名消耗品（藥水/卷軸/素材/魔法書）堆疊在同一格，**不佔新格** |
| 裝備佔格 | 每件裝備實例各佔 **1 格**，不可堆疊 |
| 容量計算 | `usedSlots = bagItems.length + inventory.length`（bagItems 每種佔 1 格） |
| 堆疊上限 | 消耗品/素材**無堆疊數量上限** |

---

### 35.1.1 腰帶格數對照表

| 腰帶 | 取得 | 需求等級 | 擴充格數 | 背包總格數 |
|---|---|---|---|---|
| （無腰帶） | — | — | — | **50** |
| 皮腰帶 | 商店 | Lv.1 | +5 | 55 |
| 鐵扣腰帶 | 商店 | Lv.5 | +7 | 57 |
| 戰士腰帶 | 商店 | Lv.10 | +10 | 60 |
| 龍皮腰帶 | 商店 | Lv.15 | +12 | 62 |
| 力之腰帶（騎士） | 製作頂級 | — | +15 | **65** |
| 暗殺者腰帶（盜賊） | 製作頂級 | — | +15 | **65** |
| 賢者腰帶（元素師／牧師） | 製作頂級 | — | +15 | **65** |

- 腰帶**同時保留原有的負重加成**（`bonusWeight`），兩個效果並存
- 腰帶 `stability: -1`，不可強化（`06-equipment.md` § 6.8）

### 35.1.2 換裝時的溢出保護

卸下腰帶會**同時**造成兩件事：腰帶本身佔 1 格、上限少掉 `bonusBagSlots`。
因此判定必須用「換裝後的狀態」，不能只看目前是否已滿。

```
溢出 = 目前佔格 + 佔格變化 > getBagMaxSlots(換裝後的裝備)
```

| 情境 | 佔格變化 | 阻擋條件 |
|---|---|---|
| 卸下裝備（含腰帶） | **+1**（裝備進背包） | 換裝後會超出上限 → **禁止卸下** |
| 替換同部位裝備 | **0**（舊的進、新的出） | 換成格數較少的腰帶而超出上限 → **禁止換上** |
| 從空手穿上 | **−1**（裝備離開背包） | 不會溢出 |

- **禁止卸下**：例如帶著力之腰帶（上限 65）且背包已 50 格，卸下後會變 51/50 → 阻擋，
  戰鬥日誌顯示「背包空間不足，卸下力之腰帶會少 15 格」
- **禁止換上**：力之腰帶（+15）換成皮腰帶（+5）時，若背包超過 55 格 → 阻擋
- 玩家必須先清空背包到足夠空間才能卸下／換裝，系統**不自動丟棄任何物品**

> 實作對應：`gameStore.ts` 的 `wouldOverflowBag()`，由 `unequipItem` 與 `equipItem` 共用。

### 35.1.3 自由放置（Drag & Drop）

背包格子可用拖曳自由擺放，**但位置不持久化** —— 只存在於當下 session，
重新載入回到預設排列（藥水 → 其他消耗品 → 裝備）。

| 行為 | 規則 |
|---|---|
| 拖到空格 | 單純移動 |
| 拖到有物品的格子 | 兩者**互換** |
| 拖到自己身上 | 不變動 |
| 新獲得物品 | 自動補進**最前面的空格**，不影響已手動擺放的位置 |
| 物品用完／賣掉 | 自動讓出格子，其餘位置不動 |
| 「整理」按鈕 | 依 類型 → 名稱 排序，**同時清空所有手動位置** |
| 格數變少（卸下腰帶） | 越界的手動位置**退回自動填格**，物品不會消失 |

**實作模型**：不引入 `slotIndex` 欄位，改用「例外表」——
`slotMap: Record<itemId, slotIndex>` 只記錄被手動移動過的項目，
其餘項目依預設順序填進剩下的空格。
物品增減時不需要任何狀態調和，也不會有 render 期間 setState 的問題。

> 實作對應：`models/bagLayout.ts` 的 `buildBagLayout()` 與 `moveBagSlot()`（純函式，可單測）；
> `BagPanel` 只持有 `slotMap` state 與 HTML5 D&D 事件。

**不做**：物品篩選／搜尋、多頁分頁（`99-ai-constraints.md` 第 57 條）、位置持久化到 DB。

## 35.3 背包已滿處理規則

### 35.3.1 容量檢查時機（所有入口必查）

| 入口 | 已滿時行為 |
|------|------------|
| 怪物掉落（`gameStore.ts` dropQueue） | 丟棄掉落物，戰鬥日誌顯示「背包已滿」 |
| 武器商店購買（`WeaponShop.tsx` `buyWeapon`） | 禁止購買，顯示提示 |
| 防具商店購買（`ArmorShop.tsx` `buyArmor`） | 禁止購買，顯示提示 |
| 雜貨店購買（`GeneralStore.tsx` `canAddToBag` + `buyBagItem`） | 禁止購買，顯示提示 |
| 鐵匠鋪製作（`TownBlacksmith.tsx` `handleCraft`） | 禁止製作，顯示提示 |
| 魔法學院製作（`MagicAcademy.tsx`） | 禁止製作，顯示提示 |
| 倉庫取出（`Storage.tsx` `withdrawEquip` / `withdrawMaterial`） | 禁止取出，顯示提示 |
| 脫下裝備（`gameStore.ts` `unequipItem`） | 禁止脫下，顯示提示「背包已滿，無法卸除裝備」 |
| 職業工會任務獎勵（`gameStore.ts` `completeQuest`） | 禁止交任務，顯示提示 |

### 35.3.2 堆疊例外

- 若背包已有同名消耗品，即使格數已滿 100，仍可累加數量（因不佔新格）
- 範例：背包已滿但有紅色藥水 ×5 → 再獲得紅色藥水 → 數量變 ×6，不占新格

### 35.3.3 顯示格式

- Header 區域顯示：`{usedSlots}/{getBagMaxSlots(equippedGear)}`（如 `48/55`）
- 當 usedSlots >= 90 時，文字顏色改為**警告色**（黃色）
- 當 usedSlots = 100 時，文字顏色改為**危險色**（紅色）

## 35.4 物品分類與佔格規則

| 分類 | type 值 | 堆疊 | 每種佔格 | 範例 |
|------|---------|------|----------|------|
| 藥水 | `potion` | ✅ | 1 格 | 紅色藥水 ×20 佔 1 格 |
| 卷軸 | `scroll` | ✅ | 1 格 | 回城卷軸 ×5 佔 1 格 |
| 素材 | `material` | ✅ | 1 格 | 銀礦石 ×8 佔 1 格 |
| 魔法書 | `spellbook` | ✅ | 1 格 | 魔法書碎片 ×3 佔 1 格 |
| 裝備 | `equipment` | ❌ | 1 格/件 | 每件獨立實例各佔 1 格 |

物品模板可使用特殊語意分類，但進入背包前必須正規化：`dungeon → scroll`、`other → material`。背包與持久化資料不可儲存 `dungeon` 或 `other` type。

## 35.5 物品互動方式

### 35.5.1 左鍵點擊（主要操作）

| 物品類型 | 點擊效果 |
|----------|----------|
| 藥水 | 使用藥水（`usePotionByType()`） |
| 裝備 | 穿上裝備（`equipItem()`） |
| 回城卷軸 | 使用傳送（`useTownScroll()`） |
| 素材 | 無操作（素材不可直接使用） |
| 魔法書 | 無操作（需至魔法學院使用） |
| 強化卷軸 | 無操作（需至鐵匠鋪使用） |

### 35.5.2 右鍵選單（Context Menu）

| 物品類型 | 選單選項 |
|----------|----------|
| 藥水 | 「設快捷鍵 1~5」、「丟棄」 |
| 裝備 | 「丟棄」 |
| 卷軸 | 「丟棄」 |
| 素材 | 「丟棄」 |
| 魔法書 | 「丟棄」 |

**丟棄規則：**
- 堆疊物品：每次丟棄 **1 個**（amount - 1，歸零時移除該格）
- 裝備：直接移除該實例（從 inventory 移除 + 刪除 DB 記錄）
- 丟棄**不可撤回**，無確認對話框（Idle 遊戲流暢性優先）

### 35.5.3 拖曳（Drag & Drop）

#### 背包內移動

- 有物品的格子 `draggable`，空格不可拖但**可作為放置目標**
- 拖曳中：來源格半透明 + 虛線邊框（`.bag-cell.dragging`）
- 停在目標格：高亮邊框（`.bag-cell.drag-over`）
- 開始拖曳時關閉 tooltip，避免跟著游標殘留
- 詳細規則見 § 35.1.3

#### 拖出背包 = 丟棄

| 放開的位置 | 行為 |
|---|---|
| **地圖上**（`map-canvas-container`） | 視同丟棄，**跳出確認視窗** |
| 其他 UI 介面（面板、城鎮、工具列等） | **不做處理**，物品留在原位 |

- 判定方式：拖曳時寫入 `dataTransfer` 的 `application/x-mayana-bag-item`；
  **只有地圖與快捷鍵會對這個 MIME 呼叫 `preventDefault()`**，其他區域沒有 drop handler，
  因此瀏覽器預設就不會觸發放置 —— 不需要逐一為其他 UI 加防呆
- 從瀏覽器外拖進來的檔案／文字不帶此 MIME，一律忽略

#### 拖放實作的兩個硬性要求

| 要求 | 原因 |
|---|---|
| 來源的 `effectAllowed` 必須是 **`copyMove`** | 快捷鍵綁定用 `dropEffect='copy'`、丟到地圖用 `'move'`。若來源只宣告其中一種，另一種會被瀏覽器判定不相容而**直接取消放置，drop 事件不會觸發** |
| 讀 `dataTransfer.types` 要用 `Array.from()` 包起來 | 部分實作回傳的是 `DOMStringList`，沒有 `includes()` |

#### 丟棄確認視窗

| 情境 | 顯示 |
|---|---|
| 堆疊物品（持有 > 1） | 顯示持有數量 + **數量選擇器**（±、直接輸入、「全部」），預設 1 |
| 單一物品或裝備 | 不顯示數量，固定丟 1 |

- 必須有「取消」與「丟棄」兩顆按鈕，點遮罩等同取消
- 數量會夾在 `1 ~ 持有量`，輸入異常值不會產生 0 或負數
- 確認後寫入戰鬥日誌：`丟棄了 {名稱} ×{數量}`（數量 1 時不加後綴）
- **丟棄後無法復原**，視窗須明示

> 實作對應：`gameStore` 的 `pendingDiscard` / `requestDiscard` / `cancelDiscard` / `confirmDiscard`；
> 視窗為 `DiscardConfirmModal`；拖曳負載編解碼在 `models/bagLayout.ts`。

> **與右鍵選單的差異**：右鍵「丟棄」是既有的快捷路徑，固定丟 1 個且不確認；
> 拖到地圖則走本節的數量 + 確認流程。

### 35.5.4 Hover 互動（Tooltip）

所有物品 hover 時顯示 tooltip，延遲 200ms 觸發。

## 35.6 Tooltip 顯示規格

### 35.6.1 消耗品 Tooltip

```
┌─────────────────────────┐
│ {物品名稱}               │  ← 名稱
│ {效果描述}               │  ← 如「回復 HP 50~100」
│ 重量：{weight × amount}  │  ← 總重量
│ 數量：×{amount}          │  ← 堆疊數量
│ 「點擊使用」             │  ← 使用提示（僅可使用物品）
└─────────────────────────┘
```

### 35.6.2 素材 Tooltip

```
┌─────────────────────────┐
│ {物品名稱}               │
│ {用途描述}               │  ← 如「鐵匠鋪製作素材」
│ 重量：{weight × amount}  │
│ 數量：×{amount}          │
└─────────────────────────┘
```

### 35.6.3 裝備 Tooltip（使用 `<EquipmentDetail>` 完整模式）

顯示欄位順序（強制）：
1. 裝備名稱 + 強化等級（如 `+7`）
2. 部位
3. 攻擊力（格式：`基礎+強化 / 基礎+強化`，小怪/大怪）
4. 防禦力（格式：`基礎+強化`）
5. 格擋率（盾牌）
6. 攻擊成功（命中加成）
7. 額外攻擊
8. 魔法攻擊
9. HP+
10. MP+
11. 回血+
12. 回魔+
13. 負重+（腰帶）
14. 額外屬性（如力量+1）
15. 材質
16. 重量
17. 品質%（有強化過才顯示）
18. 詞綴列表（Tier 色階）
19. 可用職業

**裝備 Tooltip 規則：**
- 使用 `<EquipmentDetail>` **完整模式**（非 compact）
- 必須顯示重量、部位、材質、可用職業
- 詞綴顏色依 Tier 等級（T1 灰 → T7 紫+光暈）

### 35.6.4 Tooltip 通用規則

| 規則 | 說明 |
|------|------|
| 觸發方式 | Hover（非 click） |
| 延遲時間 | 200ms |
| 渲染方式 | Portal 至 body（避免 overflow 裁切） |
| 定位 | 自動偵測邊界翻轉 |
| 樣式 | 背景 `var(--bg-card)`、邊框 `var(--border)`、陰影 `var(--shadow-card)` |

## 35.7 快捷鍵系統

### 35.7.1 快捷欄規格

| 屬性 | 值 |
|------|-----|
| 格數 | **10 格**（`QUICK_SLOT_COUNT`） |
| 觸發鍵 | **`1`~`9` 對應第 1~9 格，`0` 對應第 10 格** |
| 可放物品 | 藥水類、狀態解除道具、回城卷軸、百柱塔通行卷軸、**裝備** |
| 儲存位置 | localStorage（`mayana_prefs_${characterId}.quickSlots`） |

### 35.7.2 可放置的物品與點擊行為

| 類別 | 物品 | 點擊行為 |
|---|---|---|
| 基礎藥水 | 紅／橙／白色藥水 | 使用藥水（`usePotionByType`） |
| 加速藥水 | 綠色／強化綠色藥水 | 使用加速（`useSpeedPotion`） |
| 狀態解除 | 解毒藥水／止血繃帶／淨化藥水 | 解除對應 debuff（`useCureItem`） |
| 回城卷軸 | 三種城鎮回城卷軸 | 傳送回該城鎮（`useTownScroll`） |
| 通行卷軸 | 百柱塔 11F~91F 通行卷軸 | **直飛對應樓層區段**（`changeArea`，會消耗卷軸） |
| 裝備 | 背包中的裝備實例 | 換裝（`equipItem`），換上後該格自動清空 |

**放不進去的物品**：強化卷軸、素材、任務物品 —— 判定與點擊行為共用
`resolveQuickSlotAction()`，因此不會出現「放得進去但點了沒反應」。

#### 通行卷軸直飛

- 目的地由卷軸名反查 `REGIONS` 中 `entryScrollName` 相符的區域，**不維護對應表**，
  改樓層設定時自動跟上
- 走既有的 `changeArea()`，因此**會消耗一張卷軸**（與從地圖走過去一致）
- 已經在該區域時不重複進入，只提示「已經在這個區域了」

### 35.7.3 綁定操作

- **拖放**（主要）：從背包把物品拖到快捷欄格子
- **右鍵選單**（既有）：BagPanel 物品右鍵 → 「快捷鍵 1~10」
- **清除**：QuickSlotBar 上右鍵該格
- 同一個物品拖到新格時，**舊格自動清空**，不會重複佔格

### 35.7.4 排除條件與失效處理

- 焦點在 `<input>` / `<textarea>` 時**不觸發**快捷鍵
- 數量為 0 時該格灰階顯示且不可點
- **不可用 `disabled` 標記不可點的格子** —— 被 `disable` 的按鈕收不到 drag 事件，
  空格會變成永遠放不進東西。改用 `aria-disabled` + 點擊時自行判斷
- **裝備被賣掉／丟棄／已穿上** → 該格失效，點擊時自動清空
- 規則變更後已不可用的物品，載入時由 `normalizeQuickSlots()` 剔除

### 35.7.5 滑鼠兩段確認

滑鼠點擊採**兩段確認**，避免誤點就消耗物品或直接傳送：

| 操作 | 結果 |
|---|---|
| 點擊有內容的格子（未選取） | **只選取**，顯示外框提示，不執行 |
| 再點同一格 | **執行**並解除選取 |
| 點另一格 | 選取移到新格，**不執行**前一格 |
| 點空格／已耗盡的格子 | 不進入選取狀態 |
| 按 `Esc` | 解除選取 |
| 右鍵清除該格 | 一併解除選取 |
| 拖入新物品 | 一併解除選取 |

**鍵盤快捷鍵不受此限** —— 按 `1`~`9` / `0` 一按即發，並清掉滑鼠的選取狀態。
兩段確認是為了防止滑鼠誤點；鍵盤是刻意輸入，再加一段會失去快捷鍵的意義。

選取樣式：`.quick-slot.selected`（外框 + 格號變色）。
Tooltip 會依狀態顯示「點一次選取」或「再點一次使用」。

### 35.7.6 快捷欄顯示

| 類別 | Icon 來源 |
|---|---|
| 基礎藥水 | `getItemIcon('{type}-potion')` + 固定顏色（紅 `#DC2626`／橙 `#F59E0B`／白 `#E2E8F0`） |
| 其他背包物品 | `resolveItemIcon(getItemDefinition(name))` |
| 裝備 | `getEquipIcon()` 依 type／slot，**顏色用 `getEquipmentInstanceTierColor()`（與背包同一套品階配色）** |

- 消耗品顯示剩餘數量 badge；**裝備不顯示數量**
- 拖曳停留時該格虛線高亮（`.quick-slot.drag-over`）
- 10 格在寬度不足時自動換行（`flex-wrap`）

### 35.7.7 舊格式相容

`quickSlots` 從 `(PotionType | null)[]`（5 格）改為結構化的 `QuickSlotEntry`（10 格）。
`normalizeQuickSlots()` 會把舊的 `'red'` 轉成 `{ kind: 'potion', potionType: 'red' }`
並補齊到 10 格；無法辨識的值直接丟棄。

> 實作對應：`models/quickSlot.ts`（純函式，可單測）、`gameStore` 的
> `assignQuickSlot` / `useQuickSlot`、`QuickSlotBar` 元件。

### 35.7.8 目前無背包面板快捷鍵

以下操作目前**無鍵盤快捷鍵**（僅滑鼠操作）：
- 開關背包面板
- 整理背包
- 丟棄物品
- 裝備穿脫

## 35.8 整理功能

### 35.8.1 排序規則（優先順序）

1. 藥水（potion）
2. 卷軸（scroll）
3. 素材（material）
4. 魔法書（spellbook）
5. 裝備（equipment）

同類內按**名稱字母排列**，空格推到最後方。

### 35.8.2 Toggle 行為

- 按一次「整理」→ 依規則排序
- 再按一次 → 恢復原始順序（排序前的狀態）
- 非永久改變，僅影響顯示順序

## 35.9 裝備穿脫規則

### 35.9.1 裝備（Equip）

| 檢查項目 | 失敗行為 |
|----------|----------|
| 職業限制 | 顯示「{職業}無法裝備此物品」 |
| 等級限制 | 顯示「等級不足」 |
| 雙手武器互斥 | 已裝備副手 → 「需先卸除副手裝備」 |
| 副手互斥 | 已裝備雙手武器 → 「無法裝備 XXX，已裝備雙手武器」 |

**成功流程：**
1. 從背包移除該裝備實例
2. 若目標欄位已有裝備 → 舊裝備回到背包（需容量檢查）
3. 新裝備放入目標欄位
4. 觸發持久化存檔

### 35.9.2 卸除（Unequip）

| 檢查項目 | 失敗行為 |
|----------|----------|
| 背包已滿 | 顯示「背包已滿，無法卸除裝備」，**禁止卸除** |

**成功流程：**
1. 從裝備欄移除
2. 放入背包 inventory
3. 觸發持久化存檔

## 35.10 藥水使用限制

| 限制條件 | 行為 |
|----------|------|
| HP 已滿（HP = maxHP） | 禁止使用，顯示「HP 已滿，無法使用藥水」 |
| 藥水冷卻中 | 禁止使用（全域共用冷卻：使用任一藥水 → 所有藥水進入冷卻） |
| 超重 | 禁止使用(暫不實作) |
| 數量為 0 | 無反應 |

**冷卻時間：**
| 藥水 | 冷卻 |
|------|------|
| 紅色藥水 | 600 毫秒 |
| 橙色藥水 | 900 毫秒 |
| 白色藥水 | 1500 毫秒 |

## 35.11 回城卷軸使用限制

| 規則 | 說明 |
|------|------|
| 綁定城鎮 | 每種回城卷軸綁定特定城鎮 |
| 消耗 | 使用消耗 1 張 |
| 無卷軸 | 無法回城（不存在免費回城） |
| 使用場景 | 戰鬥中、探索中皆可使用 |
| 效果 | 立即脫離戰鬥並傳送至指定城鎮 |
| 回城後 HP/MP | 維持當前值（**不自動回滿**） |
| 戰鬥腳本 | 「回城」action 需消耗回城卷軸；無卷軸則 action 不可執行 |

| 刪除角色 | 不影響共用倉庫內物品 |
| 取出限制 | 背包已滿時不可取出（見 § 35.3） |
| 存入限制 | 無特殊限制（倉庫容量待設計文件補充） |

## 35.19 資料結構規格

### 35.19.1 BagItem（消耗品/素材）

```typescript
interface BagItem {
  name: string;        // 物品名稱（對應 item_definitions）
  type: 'material' | 'potion' | 'scroll' | 'spellbook';
  itemTemplateId?: number;
  amount: number;      // 堆疊數量
}
```

`ItemDefinition.category` 的 `dungeon`／`other` 僅供模板與特殊規則使用，建立 `BagItem` 前必須分別轉換為 `scroll`／`material`。

### 35.19.2 EquipmentInstance（背包中的裝備）

```typescript
interface EquipmentInstance {
  id: string;                    // 實例唯一 ID
  itemTemplateId: string;        // 引用模板 ID
  ownerCharacterId: string;      // 持有角色
  location: 'bag' | 'warehouse' | 'equipped';
  equippedSlot?: string;         // 裝備欄位（僅 location='equipped' 時有值）
  qualityPercent: number;        // 品質%
  baseSmallMonsterDamage: number;
  baseLargeMonsterDamage: number;
  // ...其他欄位見 18-data-schema.md
}
```

### 35.19.3 Store Actions

| Action | 功能 |
|--------|------|
| `addPotionToBag(type, amount)` | 新增/累加藥水 |
| `consumePotionFromBag(type)` | 消耗 1 瓶藥水 |
| `discardBagItem(name)` | 丟棄消耗品（-1） |
| `discardInventoryItem(id)` | 丟棄裝備實例 |
| `getBagUsedSlots()` | 取得已用格數 |
| `isBagFull()` | 檢查是否已滿 |
| `getPotionCount(type)` | 取得藥水數量 |
