# 26. 怪物生成與 Pressure 公式

## 26.1 遇敵機率

| 狀態 | 每移動秒遇敵機率 | 說明 |
|---|---|---|
| 探索中（非戰鬥） | 10% | 每移動秒獨立判定 |
| 戰鬥中 | 不判定 | 戰鬥中不會遇到新怪 |

- 每移動秒為獨立事件，互不影響
- 站立不動時不進行遇敵判定
- 戰鬥完成（所有怪物清除）後，恢復探索狀態繼續判定
- 戰鬥中不追加新怪物，一次遇敵打完一批

## 26.2 遇敵隻數

### 基礎遇敵隻數

遇敵隻數 = 隊伍人數 × (1~2)

| 隊伍人數 | 基礎遇敵隻數 |
|---|---|
| 1 人 | 1~2 |
| 2 人 | 2~4 |
| 3 人 | 3~6 |
| 4 人 | 4~8 |

### Pressure 加成

前 30 分鐘內，遇敵隻數維持基礎值。

30 分鐘後，每多停留 10 分鐘，最大遇敵數 +1：

```
最大遇敵數 = 基礎最大值 + max(0, floor((停留時間 - 30) / 10))
```

| 停留時間 | 1 人隊伍遇敵隻數 |
|---|---|
| 0~30 分鐘 | 1~2 |
| 30~40 分鐘 | 1~3 |
| 40~50 分鐘 | 1~4 |
| 50~60 分鐘 | 1~5 |
| 60~70 分鐘 | 1~6 |
| ... | 無上限 |

- Pressure 加成無上限
- 多人隊伍同樣適用（基礎值 × 人數 + Pressure 加成）

## 26.3 Pressure 機制總覽

### 定義

Pressure 為隱藏數值，代表地圖停留時間帶來的怪物壓力。

### 計算方式

```
Pressure = max(0, floor((停留時間(分鐘) - 30) / 10))
```

| 停留時間 | Pressure 值 |
|---|---|
| 0~30 分鐘 | 0 |
| 30~40 分鐘 | 1 |
| 40~50 分鐘 | 2 |
| 50~60 分鐘 | 3 |
| 60~70 分鐘 | 4 |
| ... | 無上限 |

### Pressure 影響

| 影響項目 | 效果 |
|---|---|
| 最大遇敵數 | 基礎最大值 + Pressure |
| 精英怪 | 暫不實作 |
| 掉落倍率 | 待定 |
| 經驗倍率 | 待定 |

### Pressure 重置

- 離開地圖（回城、傳送、死亡）：Pressure 歸零
- 切換地圖：Pressure 歸零
- 停留在同一地圖：Pressure 持續累積

## 26.4 怪物等級

所有遇敵怪物等級 = 所在地圖等級範圍內隨機

怪物目前只有「一般」等級，無精英/稀有分級。

## 26.5 待定項目
