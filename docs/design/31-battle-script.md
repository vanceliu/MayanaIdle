# 31. 戰鬥腳本系統

## 31.1 系統定位

戰鬥腳本是玩家自訂的自動戰鬥 AI 規則。玩家設定一組「條件 → 動作」規則，系統在戰鬥中逐條判定，執行第一個符合的規則。

戰鬥腳本不是被動技能，不提供任何數值加成，只決定自動戰鬥時的行為優先序。

## 31.2 規則結構

每條規則由三部分組成：

| 欄位 | 說明 |
|---|---|
| 啟用/停用 | 可暫時關閉某條規則 |
| 條件 | 觸發判定（HP、MP、怪物狀態、技能冷卻等） |
| 動作 | 條件成立時執行的行為 |

## 31.3 判定邏輯

1. 每個戰鬥回合，從第一條規則開始往下判定
2. 找到第一個「條件成立 且 動作可執行」的規則，執行該動作
3. 該回合只執行一次動作
4. 若無規則符合，不動作（等待下一輪）

### 「動作可執行」條件

| 動作 | 可執行條件 |
|---|---|
| 普通攻擊 | 永遠可執行 |
| 使用藥水 | 對應藥水庫存 > 0 且 HP 未滿 |
| 施放技能 | MP 足夠 且 技能冷卻結束 |

若動作不可執行，該規則視為不符合，繼續往下判定。

> **注意**：回城與瞬移逃跑已從規則列表獨立出來，改由常駐腳本的「緊急撤退設定」處理。詳見 `03-combat.md` §3.13 緊急撤退設定。

## 31.4 可用條件

| 條件類型 | 參數 | 說明 |
|---|---|---|
| 永遠 | — | 無條件成立 |
| HP 低於 | 百分比 | 角色 HP% < 設定值 |
| HP 高於 | 百分比 | 角色 HP% > 設定值 |
| MP 低於 | 百分比 | 角色 MP% < 設定值 |
| MP 高於 | 百分比 | 角色 MP% > 設定值 |
| 怪物數量 ≥ | 數量 | 場上存活怪物數 ≥ 設定值 |
| 怪物 HP 低於 | 百分比 | 任一存活怪物 HP% < 設定值 |
| 怪物 HP 高於 | 百分比 | 任一存活怪物 HP% > 設定值 |
| 技能就緒 | 技能 ID | 指定技能 MP 足夠且冷卻結束 |

## 31.5 可用動作

| 動作類型 | 參數 | 效果 |
|---|---|---|
| 普通攻擊 | — | 對當前目標執行一次普通攻擊 |
| 施放技能 | 技能 ID | 施放指定技能，消耗 MP，進入冷卻 |

> **注意**：回城與瞬移逃跑不再作為腳本規則動作，改由常駐腳本的「緊急撤退設定」獨立判定。詳見 `03-combat.md` §3.13。

## 31.6 藥水使用機制

- 藥水判定獨立於主腳本，以 300ms 間隔檢查
- 各藥水有個別冷卻：紅 600ms、橙 900ms、白 1500ms
- 冷卻為全域共用（使用任一藥水後，所有藥水進入該藥水的冷卻）
- 藥水規則與其他規則分開判定（不互斥）

## 31.7 回城與瞬移逃跑

回城與瞬移逃跑已從腳本規則列表中獨立出來，改為常駐腳本面板中的「緊急撤退設定」。

詳細規則見 `03-combat.md` §3.13 緊急撤退設定。

### 回城動作細節（供參考）

- 玩家可指定使用哪個城鎮的卷軸（薄暮村/艾爾薩斯/瓦爾登），也可選「任意卷軸」
- 若指定特定城鎮，僅當背包有該城鎮卷軸時才執行
- 若選擇「任意卷軸」，搜尋背包中任一回城卷軸（優先序：薄暮村 → 艾爾薩斯 → 瓦爾登）
- 消耗 1 張卷軸
- 立即脫離戰鬥（清除怪物、停止計時器）
- 傳送至卷軸指定城鎮
- HP / MP 維持當前值（不回滿）
- 停留在城鎮，不自動繼續探索
- 手動點地圖移動至城鎮不需卷軸，不受此限制

## 31.8 預設腳本

新角色預設 3 條規則：

| 優先序 | 條件 | 動作 |
|---|---|---|
| 1 | HP 低於 30% | 使用紅色藥水 |
| 2 | 技能就緒（風刃） | 施放風刃 |
| 3 | 永遠 | 普通攻擊 |

> **注意**：緊急撤退（HP 低於 15% 回城）為獨立設定，預設啟用。見 `03-combat.md` §3.13。

## 31.9 UI 操作

- 位於左側面板，可收合
- 玩家可新增/刪除/排序規則
- 每條規則可獨立啟用或停用
- 上下箭頭調整優先序
- 規則數量無硬性上限（建議 10 條以內）

## 31.10 限制

- 戰鬥腳本在自動搜索與手動搜索模式下皆生效（遇敵後自動執行）
- 腳本不能觸發非戰鬥行為（如購買、裝備、移動地圖）
- 腳本不提供任何被動效果或數值加成
