# 57. 拍賣場

本服玩家之間的寄售。賣家上架物品並標價，買家一口價買下，雙方的東西都經系統信箱送達。
**只在開放世界**（`97-selfhosted-server.md` § 97.1）；單機世界不出現 NPC 與快捷列。

## 57.0 開關

| 項目 | 規則 |
|---|---|
| 開關 | `AUCTION_ENABLED`（`client/src/models/auction.ts`），client 與 server 共用；**目前 `false`（暫時關閉），預定下一賽季開放** |
| 關閉時 | 兩種世界都不放拍賣場 NPC（建築保留）、快捷列不列、Wiki 開始頁不列、刪除角色確認不提上架物品；server 拒絕所有拍賣場操作，回「拍賣場暫未開放」 |
| 實作 | 全部保留，`auction_listings` 表照常建立 |

## 57.1 入口

| 項目 | 規則 |
|---|---|
| 設施 | 城鎮「拍賣場」NPC，四個城鎮都有（`13-town.md` § 13.3） |
| 範圍 | 全服一個拍賣場，四鎮看到同一份清單 |
| 視窗分頁 | **搜尋／我的上架／上架**，順序固定；預設搜尋 |

## 57.2 上架

| 項目 | 規則 |
|---|---|
| 上架費 | **5000 金幣**，只扣角色持有金幣；下架、成交都**不退** |
| 數量上限 | 每隻角色同時上架 **20 筆**。一筆＝一件裝備，或一種可堆疊道具的一疊（數量任選 1～持有量） |
| 物品來源 | 背包、個人倉庫、帳號倉庫（同 `06-equipment-acquire.md` § 6A.3「取用來源」）；**公會倉庫不算**；身上裝備中的不算。裝備由玩家指定哪一件；道具依背包 → 個人倉庫 → 帳號倉庫扣 |
| 不可上架 | 新手裝（`13-town.md` § 13.11）、天賦格（`51-auto-talent.md`）、綁角色的道具（`55-arena.md` § 55.8） |
| 標價方式 | **二選一**：金幣，或一種可堆疊道具（`itemId`＋數量，綁角色的道具除外）。不可要求裝備，不可混合。道具用道具選單挑選（`34-ui-guidelines.md` § 34.15） |
| 標價範圍 | 金幣、道具數量皆為正整數 |
| 上架後 | 物品立即離開原處，由拍賣場保管；裝備的強化、品質、詞綴、隨機技能原樣保留 |
| 期限 | **不過期**，直到成交或賣家下架 |
| 上架費不足 | 不可上架 |

## 57.3 下架

| 項目 | 規則 |
|---|---|
| 操作者 | 只有上架的角色本人，在「我的上架」分頁 |
| 物品去處 | 寄回賣家信箱（§ 57.5） |
| 上架費 | 不退 |
| 筆數 | 下架後立即釋出一筆額度 |

## 57.4 購買

| 項目 | 規則 |
|---|---|
| 方式 | **一口價**，按「購買」並確認即成交 |
| 部分購買 | **不做**，一筆整疊買下 |
| 自己的上架 | 不可購買；同帳號其他角色可以買 |
| 金幣標價 | 只扣角色持有金幣，帳號倉庫的金幣不算 |
| 道具標價 | 從背包 → 個人倉庫 → 帳號倉庫依序扣（同 `06-equipment-acquire.md` § 6A.3）；三處合計不足不可購買 |
| 手續費 | 無 |
| 同時購買 | server 依序執行，先到者成交；後到者失敗並提示「已被其他玩家買走」，清單刷新 |
| 成交後 | 買家收到物品信、賣家收到貨款信（§ 57.5），筆數額度釋出 |

## 57.5 信件

所有交付一律走系統信箱（`52-mailbox.md`），不直接入包，背包滿也照常成交。

| 時機 | 收件人 | 內容 | `sourceKey` |
|---|---|---|---|
| 成交 | 買家 | 買到的裝備或道具 | `auction-bought-{listingId}` |
| 成交 | 賣家 | 金幣或標價的道具 | `auction-sold-{listingId}` |
| 下架 | 賣家 | 原物品 | `auction-cancel-{listingId}` |

- 信件標題寫物品名稱與數量；賣家貨款信另寫買家角色名稱
- 收件人在線時立即推送信箱更新（未領取徽章，`52-mailbox.md` § 52.5）
- 領取規則照 `52-mailbox.md` § 52.4：手動領取、背包放不下整封擋下

## 57.6 搜尋

| 條件 | 規則 |
|---|---|
| 類別 | **裝備／道具二選一**（預設裝備），只列該類別。切換時清掉另一類別專用的條件，標價方式、排序、名稱保留 |
| 部位（裝備） | 全部／裝備部位（`06-equipment.md` § 6.2，戒指只有一個選項） |
| 類型（道具） | 全部／道具類型（`35-inventory-constraints.md` § 35.4） |
| 職業（裝備） | 只列該職業可裝備的裝備（`requiredClass`） |
| 階級（裝備） | T1～T7 複選（`06-equipment-acquire.md` § 6A.1），不選＝全部 |
| 詞綴（裝備） | 可選多個詞綴種類（`07-affix.md` § 7.4、`07-affix-tier7.md`），**全部都有**才符合；每個可另填最低值，不填＝有即可 |
| 名稱 | 部分比對，不分大小寫 |
| 標價方式 | 全部／金幣／道具 |
| 排序 | 上架時間（新→舊，預設）、價格（低→高、高→低）。依價格排序時道具標價的排在金幣標價之後，依上架時間 |

- 篩選與排序在 server 執行，一次回傳一頁 **30 筆**
- server 收到的條件：分類不屬於所選類別時視為全部；類別為道具時忽略職業、階級、詞綴
- 版面：第一列類別切換；第二列部位或類型、職業（裝備）、標價、排序、名稱；裝備另有「階級」列（註明「可複選，不選＝全部」）與「詞綴」列
- 詞綴選單用分組選單（`34-ui-guidelines.md` § 34.15），分組依序為：§ 7.4 的攻擊類／防禦類／補給類／掉落類／移動類、特殊詞綴、T7 獨有詞綴依 § 7T.5 部位（標題 `T7 · 部位`）。同一種類只列一次，放在第一次出現的組；與一般詞綴同種類的 T7 詞綴併入一般詞綴。已選的詞綴不再列出
- 清單每列：物品圖示與名稱、數量、價格、賣家角色名稱、上架時間（月/日 時:分）；hover 顯示物品 tooltip（裝備用 `<EquipmentDetail>`，`35-inventory-constraints.md` § 35.6）
- 清單只在打開分頁、換條件、換頁、自己購買或下架之後刷新；其他玩家的上架與成交不推送

## 57.7 我的上架

| 項目 | 規則 |
|---|---|
| 內容 | 本角色上架中的物品、標價、上架時間 |
| 筆數 | 標題顯示 `{上架中}/20` |
| 操作 | 下架（確認後執行） |

## 57.8 角色刪除

上架中的物品隨角色一併消失，同信箱與個人倉庫（`13-town.md` § 13.8）；刪除確認文字註明此事。

## 57.9 資料

| 表／欄位 | 內容 |
|---|---|
| `auction_listings` | `id`、`sellerCharacterId`、`sellerName`、`kind`（`equipment`／`item`）、`equipmentInstanceId`、`itemId`、`amount`、`priceKind`（`gold`／`item`）、`priceGold`、`priceItemId`、`priceAmount`、`createdAt` |
| `equipment_instances` | 上架中：`storageType = 'auction'`、`ownerId` 為賣家角色 id；在信件中：`storageType = 'mail'`、`ownerId` 為收件角色 id |

- 道具一律存 id（`99-ai-constraints.md` § 99.1 第 7 條）
- 上架、下架、成交各自是**單一持久層交易**：扣費／移出物品／寫 listing、刪 listing／寄信、扣買家／寄雙方信，任一步失敗整筆不成立（`97-selfhosted-server.md` § 97.4 強制 flush）
- 已成交、已下架的 listing 直接刪除，不留歷史

## 57.10 不做

| 不做 | 說明 |
|---|---|
| 競標 | 只有一口價 |
| 上架期限 | 不過期 |
| 部分購買 | 整筆成交 |
| 成交手續費 | 無 |
| 成交紀錄／價格歷史 | listing 成交即刪 |
| 單機世界 | `97-selfhosted-server.md` § 97.1 |
