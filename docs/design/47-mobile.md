# 47. 行動裝置適配

手機是主要平台之一。行動版與桌機**共用同一組元件**，由斷點切換行為。

本文件是行動裝置規則的唯一出處。UI 通用規範見 `34-ui-guidelines.md`，
模組邊界見 `16-tech-frontend-architecture.md` § 32.17。

---

## 47.1 原則

- **響應式單一版面**：同一組元件用斷點切換，不另開一套手機版元件。
- **直向優先**，橫向也要能用，不鎖定方向。
- **桌機的外觀與行為不變**，唯一例外是 § 47.6 的右下角整併（刻意兩邊一致）。

---

## 47.2 斷點

「現在算不算手機」一律讀 `hooks/useViewport.ts`，元件不得自行判斷。

| 旗標 | 條件 | 決定 |
|---|---|---|
| `isTouch` | `(hover: none)` | 互動方式（長按、tap tooltip、命中區） |
| `isMobile` | 寬度 < 768px | 版面（sheet／堆疊帶／兩欄狀態列） |
| `orientation` | `(orientation: portrait)` | 直向／橫向 |

`isMobile` 與 `isTouch` **不可合併**：觸控筆電是 `isTouch` 但不是 `isMobile`。

| 斷點 | 生效內容 |
|---|---|
| `(hover: none)` | 命中區 44×44、關閉 hover 樣式 |
| 1200px | 面板按鈕改圖示、底部 HUD 帶改上下堆疊 |
| 768px | 版面全面走行動版 |

斷點值同時定義於 `useViewport.ts` 的 `MOBILE_BREAKPOINT` 與 `App.css` 的 `--bp-mobile`，兩處必須一致。

---

## 47.3 觸控互動

桌機路徑一律保留，手機另加一條。

| 桌機 | 手機 |
|---|---|
| 右鍵選單 | 長按 500ms（位移逾 10px 取消） |
| hover tooltip | 點一下開，再點或點外面關 |
| HTML5 拖放 | 指標拖放（§ 47.4） |
| 快捷鍵 1~0 | 直接點快捷格 |

長按觸發後，同一輪按壓的主要動作（使用／裝備）必須擋掉。

---

## 47.4 指標拖放

拖放一律走 Pointer Events，滑鼠與觸控共用同一套；HTML5 drag-and-drop 不在觸控裝置上運作。

- 落點以 DOM 屬性宣告：`data-drop-kind` + `data-drop-index`。
  目前三種：`bag-slot`／`quick-slot`／`map`（丟棄，見 `35-inventory-constraints.md` § 35.5.3）。
- 落點的語意由**拖曳來源**執行，目標只宣告自己是落點。
- 拖曳中顯示殘影，殘影不吃指標事件。

**觸控不使用拖曳**（長按已是次要選單的入口）。觸控的背包重排改走選單的
「移動到其他格」→ 點目標格，語意與拖放相同（目標有東西則互換）。

## 47.5 版面

```

│ ▓ HP ▓▓▓▓▓▓▓▓▓▓▓  │ 區域名 │   左欄：狀態卡＋BuffBar
│ ▓ MP ▓▓▓▓▓▓▓▓▓▓▓  │     ▼ │   右欄：地圖選擇器
│ ▓ EXP ▓▓  負重 防禦 │      │
│ [buff]                     │
│ [buff]               ┌──┐ │ ← 城鎮：設施列
│       Pixi 地圖      │  │ │   野外：怪物卡
│                      └──┘ │   兩者靠右直排
│ ┌ 戰鬥紀錄            ⚙ ┐ │ ← 全寬抽屜
│ └ …                  ▲ ┘ │

│ [1][2][3]…[0]              │ ← 下方 HUD 帶（不疊在地圖上）
│ 面板圖示 ×6            ⚙  │

```

### 47.5.1 上下兩條 HUD 帶

四座 HUD 島收進 `.hud-topbar` / `.hud-bottombar` 兩個容器。

| 規則 |
|---|
| 上方帶在桌機是 `display: contents`（版面與桌機原本完全相同），手機才成形 |
| 下方帶桌機也成形 —— 快捷格與面板按鈕列必須排在同一列 |
| **上方帶疊在地圖上**：狀態卡是半透明 HUD，佔版面等於再吃掉地圖高度 |
| **下方帶不疊在地圖上**：快捷格與面板列是唯一的觸控入口，地圖讓出這段高度 |
| 上方帶分左右兩欄：左狀態卡（＋BuffBar），右地圖選擇器 |

### 47.5.2 讓位距離一律量測

互相讓位的距離不可寫死，由 `useHudBandBottom()` 量測後寫入 CSS 變數。

| 變數 | 內容 | 讀取者 |
|---|---|---|
| `--hud-band-bottom` | 下方帶高度 | 地圖可視範圍、城鎮設施視窗底部保留區 |
| `--hud-band-top` | 上方帶整條下緣 | 全寬元素 |
| `--hud-card-bottom` | 角色卡下緣 | 怪物卡、城鎮設施列的上緣 |
| `--hud-log-height` | 戰鬥日誌抽屜高度 | 怪物卡、城鎮設施列的下界 |

怪物卡與城鎮設施列夾在角色卡下緣與日誌抽屜之間 —— 上緣不隨 buff 數量浮動，
下界不被日誌蓋住。

### 47.5.3 各元素的行動版行為

| 元素 | 行為 |
|---|---|
| BuffBar | 往下疊，不往右長（桌機亦同，見 `16-tech-frontend-architecture.md` § 32.14） |
| 地圖下拉選單 | 往左展開到滿版，四邊完整的獨立卡片 |
| 快捷格 | 單列橫捲 |
| 城鎮 ExploreBar 佔位 | 不渲染佔位（帶子靠下緣定位，快捷格與畫面底部的距離不變） |
| 城鎮設施列 | 靠右的圖示直排，全部可點，超出可捲；不顯示標題列 |
| 怪物卡 | 靠右直排，縮到七成（規格見 `24-buff-debuff.md` § 24.8.3） |
| 浮動面板 | 全螢幕 sheet：停用拖曳、不套用位置持久化、一次只開一個 |
| 戰鬥日誌 | 貼在下方帶上的全寬抽屜，不可拖曳；預設高度 96px，`▲` 三段照舊 |
| 置中彈窗 | 只有城鎮設施視窗滿版；小對話框只收寬度 |
| 選角頁 | 角色格改 2×2 |

## 47.6 右下角：面板與系統分層

右下角的按鈕分兩類，**不可混在同一層**：

| 類型 | 內容 | 使用頻率 | 位置 |
|---|---|---|---|
| 面板 | 任務／詳細狀態／裝備欄／背包／技能／自動腳本 | 高 | 常駐按鈕列 |
| 系統 | Wiki／匯出／匯入／登出／版本號 | 低（一局按不到一次） | 設定視窗的「帳號」頁 |

右下角一律是「面板按鈕列 ＋ `⚙`」，**桌機與手機同一個排法**：

- `⚙` 是那一列的第七顆，不自成一列
- 設定視窗名為「系統設定」，分「顯示」與「帳號」兩頁（分頁樣式沿用 § 34.1）
- 匯出／匯入的確認流程與文案不因換位置而放寬（`19-account-character.md` § 19.9）

### 47.6.1 按鈕的名字

1200px 以下面板按鈕只顯示圖示，名字由屬性承載：

- `title`（滑鼠 tooltip）與 `aria-label`（觸控／螢幕閱讀器）**兩者都要**
- 圖示對螢幕閱讀器隱藏
- **面板圖示彼此不重複，也不得與城鎮設施圖示相同** ——
  兩者在手機上同時出現在畫面裡，圖示相同等於兩顆都沒有名字

## 47.7 尺寸與單位

| 規則 |
|---|
| 視窗高度一律用 `dvh`（手機網址列會改變可視高度） |
| 縮放層內不可直接寫 `vh` / `vw`（§ 34.6 既有規則），一律 `calc(N * var(--vh-unit))` |
| 四角貼邊距離加 `env(safe-area-inset-*)` |
| 觸控命中區下限 **44×44**（`--tap-target`），只在 `(hover: none)` 生效 |
| `viewport-fit=cover`；另以 `touch-action: manipulation` 關閉雙擊縮放 |
| `overscroll-behavior: none` 擋整頁下拉刷新 |
| 收合一律 `display: none`，不可用 `visibility: hidden`（後者仍會擋住點擊） |

手機**沒有另設 `--ui-scale` 預設值**，範圍仍是 80%~150%（§ 34.6）。

## 47.8 PWA（可安裝／離線）

存檔在 IndexedDB，程式碼與素材進入快取後即為**離線完整可玩**。

| 項目 | 內容 |
|---|---|
| 顯示模式 | `standalone` |
| 方向 | `any`（不鎖定） |
| 底色 | `background_color` / `theme_color` 皆為 `#0A0A1A`（與 `--bg-deepest` 一致） |
| 圖示 | 192／512 PNG，`purpose: "any maskable"`；標誌只佔畫布 60%（maskable 安全區） |
| iOS | 主畫面圖示另掛 `<link rel="apple-touch-icon">`（iOS 不讀 manifest 的 `icons`） |
| 更新時機 | 新版在下一次完全關閉分頁後生效，不做 `skipWaiting()` |

快取策略：

| 請求 | 策略 |
|---|---|
| 導覽（`index.html`） | network-first（沒有 content hash，快取優先會停在舊版） |
| 其餘同源資源 | cache-first（檔名帶 content hash） |
| 跨網域 | 不快取（排行榜資料不可過期） |

Service Worker 註冊網址帶 `?v=<build commit>`，並在開發模式停用。
