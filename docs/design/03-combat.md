# 3. 戰鬥系統

## 3.1 戰鬥定位

戰鬥流程走 ARPG 方向。

不是傳統回合制，也不是一波一波固定關卡。

玩家在地圖中會持續遭遇怪物，並進行即時或半即時戰鬥。

## 3.2 搜尋模式

遊戲支援兩種搜尋模式：

### 自動搜尋

- 持續每秒判定遇敵機率
- 適合掛機放置
- 搭配自動腳本使用

### 手動搜尋

- 玩家點擊「搜尋」按鈕後，系統每秒判定一次遇敵（機率同自動搜尋，10%）
- 持續搜尋直到成功遇敵為止
- 搜尋期間按鈕顯示「搜索中...」狀態，不可重複點擊
- 玩家可點擊「取消」中途停止搜尋
- 適合需要精確控制節奏的場景

玩家可隨時在兩種模式間切換。

## 3.3 戰鬥模式

遊戲同時支援：

- 手動戰鬥
- 自動戰鬥

## 3.4 手動戰鬥

手動戰鬥中，玩家可以操作：

- 普通攻擊
- 使用技能
- 使用補血藥水
- 選擇目標
- 更換目標
- 移動角色，若未來有地圖移動系統
- 決定是否撤退或返回城鎮

## 3.5 自動戰鬥

自動戰鬥行為分為兩套獨立腳本系統：

| 腳本 | 作用時機 | 職責 |
|---|---|---|
| 戰鬥腳本 | 僅戰鬥中 | 攻擊技能施放、普通攻擊 |
| 常駐腳本 | 任何狀態（探索、戰鬥皆生效） | 喝水、buff 技能施放、治癒技能施放 |

另外，常駐腳本面板下方有獨立的「緊急撤退設定」，僅戰鬥中生效，負責回城/瞬移逃跑判定（見 §3.13）。

戰鬥腳本詳見 §3.12，常駐腳本詳見 §3.13。

## 3.6 手動與自動的關係

戰鬥預設為自動進行（自動攻擊、自動喝水、自動換目標）。

手動操作是「介入」而非「暫停」：

- 玩家可隨時點擊怪物切換攻擊目標
- 玩家可選擇技能指定目標施放
- 範圍技能直接施放，不需指定目標
- 若玩家未操作，系統按自動邏輯執行

## 3.7 攻擊速度與技能施放

### 戰鬥計時器架構

戰鬥中有兩個獨立的計時器並行運作：

| 計時器 | 間隔 | 職責 |
|---|---|---|
| 玩家攻擊 | 1200ms（可被加速影響） | 戰鬥腳本判定：施放攻擊技能 / 普攻 |
| 怪物攻擊 | 1200ms（固定） | 隨機一隻存活怪物攻擊玩家 |

另外，常駐腳本有自己的判定計時器（見 §3.13），獨立於上述戰鬥計時器。

注意事項：
- 加速（綠色藥水/加速術）只縮短玩家攻擊間隔
- 技能冷卻獨立計時，不受攻速影響
- 喝水屬於常駐腳本，不佔用攻擊 tick

### 基礎攻擊速度

- 角色攻擊間隔：1200ms（加速後降至 900ms）
- 怪物攻擊間隔：1200ms（固定不變）
- 綠色藥水/加速術：降低玩家攻擊間隔（×0.75）

### 技能施放規則

- 技能施放取代該回合的普通攻擊（不是額外動作）
- 施法時間：0.5 秒（視覺動畫）
- 每個技能有獨立冷卻時間（如風刃 3 秒）
- 冷卻中的技能無法施放，該回合自動執行普通攻擊
- 自動戰鬥邏輯：由腳本引擎按規則順序決定

## 3.8 掉落與經驗結算

每隻怪物死亡時立刻結算，不等整場戰鬥結束：

- 該怪物的經驗值立刻加入角色（可能觸發升級）
- 該怪物的掉落立刻判定並加入背包
- 全部怪物擊敗後直接回到探索狀態

### 設計理由

- 遭遇多隻怪物時，打死第一隻就有回饋
- 避免「打了很久全部打完才結算」的空白感
- 若中途死亡或逃跑，已擊殺的怪物經驗和掉落不會消失

## 3.9 怪物增殖機制

MayanaIdle 的重要戰鬥特色：

玩家在同一張地圖停留越久，每次遇敵的怪物數量上限會逐漸增加。

這代表：

- 停留時間越長，每次遇到的怪物越多
- 玩家越強，能承受越多怪物
- 怪物數量增加會提升收益，但也增加死亡風險
- 戰鬥中不會追加新怪物，一次遇敵打完一批

## 3.10 Pressure 機制

Pressure 為隱藏數值，代表地圖停留時間帶來的怪物壓力。

Pressure 影響每次遇敵的最大怪物數量。

具體公式與遇敵機率規則見 `26-spawn-pressure.md`。

## 3.11 戰鬥流程

```text
玩家選擇地圖
↓
進入探索狀態（移動中每秒 10% 遇敵）
↓
隨機遭遇一批怪物
↓
開始戰鬥（戰鬥中不追加新怪物，打完一批為一場）
↓
戰鬥結束 → 結算掉落與經驗
↓
回到探索狀態，繼續移動遇敵
↓
停留時間越久，單次遇敵數量越多（Pressure 機制）
↓
玩家選擇繼續探索、撤退、或返回城鎮
```

## 3.12 戰鬥腳本

戰鬥腳本僅在 `phase === 'combat'` 時執行。

### 規則結構

```
腳本 = 一組有序規則（由上往下判定）
規則 = 條件 + 動作
```

每次玩家攻擊 tick（1200ms，受加速影響）：從第一條規則開始，找到第一個條件成立且可執行的規則，執行其動作。若無規則匹配，角色該 tick 不動作（等待）。

### 可用條件

| 條件 | 參數 | 說明 |
|---|---|---|
| 永遠 | — | 無條件觸發 |
| 怪物數量 ≥ | N | 場上存活怪物數 |
| 怪物 HP 低於 | X% | 任一怪物 HP 百分比 |
| 技能就緒 | 技能名 | 指定攻擊技能 CD 完成且 MP 足夠 |

### 可用動作

| 動作 | 參數 | 說明 |
|---|---|---|
| 施放攻擊技能 | 技能名 | 對當前目標施放攻擊型技能 |
| 普通攻擊 | — | 物理攻擊當前目標 |
| 不動作 | — | 該 tick 跳過，角色等待 |

### 預設腳本範例

```
#1 如果 技能就緒（風刃）→ 施放風刃
#2 永遠 → 普通攻擊
```

### 設計要點

- 規則可新增、刪除、排序、啟用/停用
- 戰鬥腳本只處理攻擊行為，不包含喝水、回城、buff
- 技能施放取代該 tick 的普通攻擊（不是額外動作）
- 若所有規則都未匹配（包含全部停用），角色不會自動攻擊
- 玩家可使用「不動作」明確讓角色在特定條件下等待

## 3.13 常駐腳本

常駐腳本在任何狀態下持續運作（探索、戰鬥皆生效）。

### 判定頻率

每 300ms 判定一次，從第一條規則開始，找到第一個條件成立且可執行的規則，執行其動作。

### 規則結構

與戰鬥腳本相同：有序規則列表，條件 + 動作。

### 可用條件

| 條件 | 參數 | 說明 |
|---|---|---|
| 永遠 | — | 無條件觸發 |
| HP 低於 | X% | 自身 HP 百分比 |
| HP 高於 | X% | 自身 HP 百分比 |
| MP 低於 | X% | 自身 MP 百分比 |
| MP 高於 | X% | 自身 MP 百分比 |
| Buff 未激活 | buff 名 | 指定 buff 效果不存在時 |
| 技能就緒 | 技能名 | 指定 buff 技能 CD 完成且 MP 足夠 |

### 可用動作

| 動作 | 參數 | 說明 |
|---|---|---|
| 使用藥水 | 藥水類型 | 紅/橙/白，受藥水冷卻限制 |
| 施放 buff 技能 | 技能名 | 施放輔助型技能（如魔法盔甲、祝福武器） |
| 施放治癒技能 | 技能名 | 施放回復型技能（如治癒、中治癒） |

### 藥水冷卻

| 藥水 | 冷卻時間 |
|---|---|
| 紅色藥水 | 600ms |
| 橙色藥水 | 900ms |
| 白色藥水 | 1500ms |
| 綠色藥水 | 使用後攻速+33%，持續 120s，與加速術/強化加速術/強化綠色藥水互斥（category: speed，見 `30-items.md` § 30.3） |
| 強化綠色藥水 | 使用後攻速+33%，持續 600s，與加速術/強化加速術/綠色藥水互斥（category: speed，見 `30-items.md` § 30.3） |

300ms 判定頻率確保藥水冷卻有實際意義。

### 預設常駐腳本範例

```
#1 如果 HP 低於 30% → 使用紅色藥水
#2 如果 HP 低於 50% 且 技能就緒（治癒）→ 施放治癒
#3 如果 Buff 未激活（魔法盔甲）且 技能就緒（魔法盔甲）→ 施放魔法盔甲
```

### 設計要點

- 常駐腳本獨立於戰鬥腳本，兩套規則各自編輯
- 不分狀態常駐生效：探索中喝水回復、戰鬥中自動補血、buff 維持
- 藥水/buff 有各自冷卻，不會每 300ms 都觸發
- UI 上與戰鬥腳本分開顯示（兩個獨立 tab）

### 緊急撤退設定

緊急撤退為獨立於規則列表的固定區塊，位於常駐腳本面板最下方。

#### 設計理由

回城/瞬移逃跑與一般常駐動作（喝藥、治癒、buff）性質不同：撤退僅在戰鬥中有意義，且一旦執行會改變玩家狀態（回到城鎮）。若放在規則列表中，非戰鬥狀態下會持續匹配到撤退規則但無法執行，阻塞後續規則的判定。

#### 設定項

| 欄位 | 說明 |
|---|---|
| 啟用/停用 | 開關緊急撤退功能 |
| 條件 | HP 低於 X%（玩家自訂門檻） |
| 動作 | 回城（指定城鎮）或 瞬移逃跑 |
| 回城城鎮 | 動作為回城時，指定卷軸城鎮或「任意卷軸」 |

#### 判定邏輯

- 在 persistent loop 中獨立判定，不參與規則列表的順序匹配
- 僅在 `phase === 'combat'` 時生效，非戰鬥狀態自動跳過
- 判定頻率與常駐腳本相同（300ms）
- 撤退判定在規則列表判定之後執行（規則列表優先）

#### 動作說明

| 動作 | 效果 |
|---|---|
| 回城 | 消耗回城卷軸，傳送至指定城鎮，脫離戰鬥。詳見 §31.7 |
| 瞬移逃跑 | 不消耗道具，脫離當前戰鬥，重置 Pressure，留在原地繼續探索 |

#### 預設值

- 啟用：是
- 條件：HP 低於 15%
- 動作：回城（任意卷軸）

#### UI 位置

位於常駐腳本面板規則列表下方，以分隔線區隔。不可拖曳排序，不參與規則列表。

### 戰鬥後等待

戰鬥後的 HP/MP 等待回復門檻獨立於腳本系統。當戰鬥結束後，若 HP 或 MP 低於設定門檻，系統會等待自然回復達到門檻後才開始下一次搜尋。此機制作用於探索階段，與常駐腳本互不影響。

## 3.14 不採用的戰鬥設計

AI 生成時應避免：

- 不要做成固定下一關
- 不要做成每關小怪、小怪、Boss、下一關
- 不要加入戰鬥速度 1x、2x、4x
- 目前不設計戰鬥加速功能
- 不要把戰鬥設計成純回合制
