# 8. 裝備品質系統

## 8.1 品質定義

裝備品質是額外 bonus。

品質不是裝備稀有度。

品質不是掉落時的主要強弱來源。

品質代表裝備後續透過鐵匠鋪加工後的工藝提升。

## 8.2 預設品質

所有裝備預設品質為：

```text
0%
```

## 8.3 品質提升

玩家可透過鐵匠鋪提升裝備品質。

### 提升材料

- 品質石 × 1（世界各地怪物掉落）
- 金幣 50,000

### 提升效果

- 每次提升：品質 +1%
- 提升必定成功，無失敗機制
- 從 0% 提升到 20% 需要 20 顆品質石 + 1,000,000 金幣

## 8.4 品質上限

目前預設最高品質為：

```text
20%
```

未來可視系統擴充，但初版以 20% 為上限。

## 8.5 品質影響範圍

品質只影響：

1. 詞綴數值
2. 裝備販售價格

## 8.6 品質不影響範圍

品質不影響：

- 武器基本傷害
- 對小怪基本傷害
- 對大怪基本傷害
- 防具基礎防禦
- 技能倍率
- 角色基礎能力
- 掉落機率

## 8.7 品質計算範例

假設裝備詞綴為：

```text
攻擊力 +10%
```

裝備品質為：

```text
10%
```

則攻擊力100的最終詞綴可計算為：

```text
100 × (1 + 10%) x (1 + 10%) = 121
```

假設裝備品質為：

```text
20%
```

則最終詞綴可計算為：

```text
100 × (1 + 20%) = 120
```

## 8.8 販售價格計算範例

假設裝備基礎售價為：

```text
1000 金幣
```

裝備品質為：

```text
20%
```

則販售價格可為：

```text
1000 × (1 + 20%) = 1200 金幣
```
