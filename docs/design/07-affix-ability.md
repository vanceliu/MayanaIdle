# 7S. 隨機技能

## 7S.1 定位

裝備階級 T3 以上（`06-equipment-acquire.md` § 6A.1）的**武器（右手）、項鍊、戒指**，
在一般詞綴（`07-affix.md`）與 T7 獨有詞綴（`07-affix-tier7.md`）之外，可另帶 **1 條隨機技能**。

- 獨立欄位，不佔詞綴洞
- 取得當下決定（種類與數值），之後只能由鐵匠鋪技能更換改變（§ 7S.8）
- 技能池分兩組（§ 7S.5）：**武器池**（攻擊）與**飾品池**（防禦，項鍊與戒指共用）；兩組的技能種類互不重複
- 一般詞綴池、特殊詞綴池、T7 獨有詞綴池都不含這些技能

## 7S.2 出現機率與抽取

| 取得管道 | 出現機率 | 數值 |
|---|---|---|
| 商店購買（T3） | 30% | 每個參數取**最弱值** |
| 鐵匠製作（T4~T6） | **100%**，種類由玩家指定（§ 7S.6） | 每個參數取**最弱值** |
| 一般怪掉落 | 30% | 每個參數各自在區間內均等抽 |
| Boss 掉落（含 T7） | 30% | 每個參數各自在區間內均等抽 |

- T1／T2 裝備、左手、防具、腰帶不出
- 最弱值＝區間中效果較差的一端，一般為下限；數值越小越好的參數（標 ↓）取上限

### 抽取順序（武器、飾品相同）

1. **選池**：該組的共通池、職業池各 50%
   - 職業池＝**取得的角色**的職業池；該職業不能裝備這件裝備時，一律取共通池
2. **選技能**：池內均等抽一種
3. **抽數值**：依 § 7S.2 管道規則

### 數值單位

- 百分比、秒數以外的參數一律整數；百分比以 1% 為單位（專注打擊以 0.1% 為單位）
- 秒數以 0.1 秒為單位
- **武器值**＝武器平均基傷（`07-affix.md` § 7.9 元素侵蝕：`(小怪傷害 + 大怪傷害) / 2` 四捨五入，不含強化）；
  `武器值×1.5` 四捨五入；區間 `5~武器值`、`5~武器值×1.5` 的上限 ≤ 5 時固定為 5

## 7S.3 通用規則

| 項目 | 規則 |
|---|---|
| Tier | 無 Tier，不參與滿值粗體（`07-affix.md` § 7.3.2） |
| 品質 | **不吃品質**（`08-quality.md`） |
| 印記 | **任何印記都不受理**（鐵匠鋪技能更換見 § 7S.8）：混沌重骰不含它；刺針／重刻／精鍊／突破／封印不可指定它 |
| 素質需求 | 未滿足時與該件的詞綴一併凍結（`06-equipment.md` § 6A.8.8） |
| 與其他詞綴 | 與一般詞綴、封印詞綴、T7 獨有詞綴**共存**，各自生效 |
| 同種類多件 | 項鍊與兩枚戒指帶相同技能時：數值類（低血回復、低魔回復、荊棘反彈）**加總**；怒氣只有一份、衰減取最小；平靜只有一份、累積取最大；職業技能只取**數值較好的一件**（比第一個參數，↓ 取小；同值依部位順序 項鍊 → 戒指 1 → 戒指 2） |
| 職業技能 | 只作用於該職業的對應技能；裝備者未學會該技能或職業不同時無效果 |
| 生效時點 | 以**施放當下**的裝備為準：冷卻、MP 消耗、傷害於施放時決定；buff、護盾、debuff 的數值與持續時間施放時固定，之後換武器不影響 |

## 7S.4 觸發規則

| 用語 | 定義 |
|---|---|
| 命中 | 普攻與技能命中都算；**每一下命中判定一次**（雙持一次攻擊兩下、多段技能逐發、範圍技能逐目標）；未命中不判定 |
| 普攻類 | 走普攻公式的攻擊：普攻（雙持兩下）、三連射、閃避反擊的反擊（含閃避反擊強化追加的普攻）、穿透箭雨強化後的穿透箭雨、血濺斬擊後的血濺咒殺 |
| 技能類 | 其餘造成直接傷害的攻擊技能：§ 21.4a 快照物理技能與 § 21.4 技能公式技能，單體、範圍、多下（血濺咒殺）皆同 |
| 出手 | 普攻類**每一下**計 1（雙持一次攻擊兩下計 2、三連射每箭計 1）；技能類**每施放一次**計 1；該下／該次未命中任何目標不計 |
| 單體技能 | 技能類中，技能表類型為「單體攻擊」開頭者（`22-basic-magic.md`、`23-class-magic.md`）；普攻類一律不算 |
| 3 格內 | 與主目標真實距離 ≤ 3 格的其他活著的怪物，無隻數上限 |
| 被命中 | 受到怪物攻擊的傷害（近戰、遠程、詠唱皆算）；被迴避、被絕對迴避不算 |
| 實際受到的傷害 | 該次攻擊經防禦減傷、buff 減傷、格擋後的傷害，護盾吸收前 |

- 技能自身產生的傷害（追加傷害、擴散）不再觸發命中類技能，也不計入追打的出手次數與專注打擊的層數
- 擴散造成的擊殺照常計為角色擊殺
- 擴散傷害計入原技能的回復（魔力奪取回魔、神聖懲擊回血等）；不觸發怪物荊棘反彈（`25-monster-system.md` § 25.12.3）

## 7S.5 清單

### 武器（右手）—— 共通池

| 名稱 | 效果 | 數值 |
|---|---|---|
| 追加傷害 | 命中 A% 機率追加 B 傷害：加在該下**最終傷害**（防禦減傷之後），不吃攻擊力%、爆擊與怪物防禦 | A 5~15、B 5~武器值×1.5 |
| 單體技能擴散 | 單體技能命中時，3 格內的其他怪受到**主目標該下最終傷害 × X%**；不判定命中、爆擊、防禦 | X 15~25 |
| 追打傷害 | 每第 N 次出手，該次出手（普攻類為該下、技能類為該次施放的全部目標）的直接傷害 ×(1 + M%)；普攻與技能交替照計；觸發後歸零重計；換武器、換地圖、死亡、回城歸零，換目標不歸零 | N 5~10 ↓、M 10~50 |
| 專注打擊 | 對同一隻怪每命中 1 下加 1 層；對該怪的直接傷害 ×(1 + 層數 × X%)，加成上限 +100%；每隻怪各自記層數，換目標不清除；該怪死亡即清，換地圖、死亡、回城、斷線時全部清除 | X 0.5~1.5 |

- 專注打擊：層數於該下傷害結算後才加（第 1 下無加成）；未命中不加層、不歸零；層數每個角色各自記；
  直接傷害＝普攻類與技能類（§ 7S.4）的傷害，追加傷害、擴散、元素侵蝕與流血中毒等持續傷害不吃加成也不加層；
  擴散依主目標該下含加成的最終傷害計算；與追打等其他「傷害 ×(1 + X%)」相乘

## 7S.6 鐵匠鋪指定

| 項目 | 規則 |
|---|---|
| 適用 | 武器、項鍊、戒指（T4／T5 項鍊與戒指可製作，`06-equipment-acquire.md` § 6A.3） |
| 可選範圍 | 該組的共通池 ＋ 製作角色在該組的職業池（該職業可裝備這件時） |
| 指定 | **必須指定**一種；未指定不可製作 |
| 數值 | 每個參數取最弱值（§ 7S.2） |
| 費用 | 不另收費，製作消耗照 `06-equipment-acquire.md` § 6A.3 |
| 預覽 | 配方卡列出所選技能的名稱、效果與數值 |

## 7S.7 顯示

- 裝備 tooltip：**最上面一行** `名稱：效果`（參數代入數值，不加前綴），以淺綠色 `#86EFAC` 區別；其下依序為 T7 獨有詞綴、分隔線、一般詞綴
- 按住 Alt 時各參數後加數值區間（`34-ui-guidelines.md` § 34.2「Alt 顯示區間」）
- 素質需求凍結：與一般詞綴同一個凍結樣式
- 技能面板 tooltip：顯示套用職業池技能後的數值，被改動的數字以黃色 `#FACC15` 標示，同行其他文字不變色；快捷列的 MP 與冷卻判定同樣用改動後的值
- 裝備欄詞綴加總：列在 T7 獨有詞綴之後（只列效果，`34-ui-guidelines.md`）
- 浮動傷害與戰鬥日誌：追加傷害、擴散各自顯示，專注打擊不另外顯示層數；追打觸發的那一下浮動數字淺黃色 `#FEF08A`、一般字級（不加文字）；同時爆擊時照爆擊顯示，日誌記「追打！傷害 +M%」
- 戰鬥日誌另記荊棘反彈、平靜縮短冷卻各一行
- 狀態列：怒氣（category `ability-rage`）、平靜（`ability-calm`，帶平靜技能時常駐）以 buff 圖示顯示，圖示下方顯示當下數值取代倒數；數值由 buff 的開始時間與參數推算，不另外同步
- Wiki：詞綴頁列全部；武器頁列武器池；防具頁列飾品池（`43-wiki-system.md`）；效果欄的數值區間以黃色 `#FACC15` 標示

## 7S.8 技能結晶與技能更換（鐵匠鋪）

### 技能結晶

| 項目 | 規則 |
|---|---|
| 取得 | 鐵匠鋪拆解**掉落品**時，該件的隨機技能存成結晶（`06-equipment-acquire.md` § 6A.3「拆解」）；製作品 (鍛)、商店裝（詞綴上限 T3）不出 |
| 存放 | 角色專屬清單，不佔背包、無上限；每種技能一顆 |
| 內容 | 每個參數在該件區間內的位置：最弱值 0%、最好值 100%（↓ 參數反向）；區間依該件模板，武器值參數依該件武器值 |
| 同種類 | 再拆到同種技能時，每個參數**各自**取位置較高者 |
| 使用 | 套用不消耗，可重複使用 |

### 技能更換

| 項目 | 規則 |
|---|---|
| 對象 | 背包中未裝備、T3 以上的武器（右手）、項鍊、戒指；製作品 (鍛) 不可 |
| 技能組 | 武器組結晶只套武器；飾品組結晶只套項鍊、戒指 |
| 職業技能 | 職業池結晶只能套到該職業可裝備的裝備 |
| 數值 | 每個參數 = 目標區間最弱值 + 位置 × (最好值 − 最弱值)，依參數單位四捨五入（§ 7S.2「數值單位」）；武器值參數用目標的武器值 |
| 費用 | 500,000 × 目標裝備階級（T3 1,500,000～T7 3,500,000） |
| 結果 | 目標原本的隨機技能消失；沒有技能的裝備多一條 |
