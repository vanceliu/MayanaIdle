# 21. 戰鬥公式

## 21.1 通用規則

- 所有計算結果取整方式為**無條件捨去（floor）**
- 所有百分比加成以乘算方式套用於基礎值

---

## 21.2 HP / MP 初始值與成長

| 項目 | 1 級初始值 | 每級成長公式 |
|---|---|---|
| HP | 30 | `random(VIT - 6, VIT - 3)` |
| MP | 10 | `random(SPI - 6, SPI - 3)` |

所有職業 1 級 HP 為 30、MP 為 10。

升級時 HP 與 MP 恢復全滿。

## 21.3 物理攻擊力

屬性換算規則見 `20-attributes.md`。

### 詞綴乘區規則（方案 C：分類加算，類間乘算）

同類型詞綴加算至同一乘區，不同乘區之間相乘：

| 乘區 | 來源詞綴 | 生效時機 |
|---|---|---|
| 攻擊乘區 | 攻擊力% 加總 | 物理普攻（不影響魔法） |
| 普攻元素乘區 | 元素刻印% 加總 | 普攻時（武器攻擊） |
| 技能元素乘區 | 技能元素傷害% 加總 | 施放技能時 |
| 爆傷乘區 | 爆擊傷害% 加總 | 暴擊觸發時 |

元素刻印與技能元素傷害**互不疊加**，依攻擊方式擇一生效。

### 詞綴與 buff 的合流

以下四項可同時由「裝備詞綴」與「技能 buff」提供，計算時**加總為同一個值**：

| 項目 | 詞綴來源 | buff 來源 |
|---|---|---|
| 爆擊率% | 爆擊率詞綴 | 精準打擊（盜賊 4，+10%） |
| 爆擊傷害% | 爆擊傷害詞綴 | 致命一擊（盜賊 2，+50%） |
| 技能元素傷害% | 技能元素傷害詞綴 | 元素增幅（元素師 3，+25%） |
| 減少冷卻時間% | 減少冷卻時間詞綴 | 冷卻縮減（元素師 1，+20%） |
| 攻擊力% | 攻擊力詞綴 | 復仇之刃（騎士 5，依殘血最高 +50%）、背刺（盜賊 5，+50%） |

冷卻縮減上限維持 50%，計算的是**詞綴 + buff + 智力**加總後的值（§ 21.4）。

### 近戰攻擊力（普攻）

```
基礎攻擊力 = 武器基傷 + 額外攻擊 + STR加成
近戰攻擊力 = floor(基礎攻擊力 × (1 + 攻擊力%) × (1 + 元素刻印%))
```

> **雙刀與鋼爪一次攻擊打兩下**。每下獨立判定命中與爆擊，
> 每下都跑完整條公式 —— 額外攻擊、STR 加成、材質克制兩下都算。
> 它們的每下基傷因此只有其他雙手武器的一半。
> 打擊次數的唯一來源是 `getWeaponHitCount()`。

> **虛弱 debuff 不在此公式內**：`攻擊力 -20%` 套用於**所有乘區、爆擊與防禦減傷之後的最終傷害**，
> 即 `最終傷害 = max(1, floor(減傷後傷害 × 0.8))`。見 § 21.11 與 `24-buff-debuff.md` § 24.4.5。

- STR 加成 = 有效力量 / 2（見 `20-attributes.md` § 20.3）
- 武器基傷分 smallMonsterDamage / largeMonsterDamage，分別計算
- 額外攻擊 = 武器的 extraAttack 數值，直接加算至武器基傷上（注意：額外攻擊 ≠ 多段攻擊，本遊戲無多段攻擊機制）
- 攻擊力% = 所有裝備「攻擊力」詞綴的有效數值加總
- 元素刻印% = 武器「元素刻印」詞綴的有效數值
- 沒有刻印的武器是無屬性，不吃這個乘區

### 遠程攻擊力（普攻）

```
基礎攻擊力 = 武器基傷 + 額外攻擊 + 遠程攻擊加成 + STR加成
遠程攻擊力 = floor(基礎攻擊力 × (1 + 攻擊力%) × (1 + 元素刻印%))
```

- STR 加成 = 有效力量 / 2（見 `20-attributes.md` § 20.3）
- 額外攻擊 = 武器的 extraAttack 數值，直接加算至武器基傷上（注意：額外攻擊 ≠ 多段攻擊，本遊戲無多段攻擊機制）
- **遠程攻擊加成** = 生效中 buff 提供的「遠程攻擊」固定值，**僅在裝備弓時生效**（近戰武器不計入）
  - 來源：鷹眼（妖精 4，遠攻 +3）
- 攻擊力% = 所有裝備「攻擊力」詞綴的有效數值加總 —— **與近戰相同，對遠程攻擊同樣生效**
- 元素刻印% = 武器「元素刻印」詞綴的有效數值 —— **與近戰相同，對遠程攻擊同樣生效**
- 沒有刻印的武器是無屬性，不吃這個乘區（火矢附魔生效時視為火屬性，故可吃到）

### 範例

```text
武器 10/10，STR 18，詞綴「攻擊力 +12%」+「元素刻印（火）+10%」：
基礎攻擊力 = 10 + 9 = 19
近戰攻擊力 = floor(19 × 1.12 × 1.10) = floor(23.4) = 23
```

## 21.4 魔法攻擊力

```
基礎魔攻 = floor(技能攻擊力 × (1 + 裝備魔攻 × 6.5 / 100)) + INT加成 + 元素克制
魔法攻擊力 = floor(基礎魔攻 × (1 + 技能元素傷害%))
```

完整結算順序（爆擊、防禦減傷）見 § 21.11。

- INT 加成 = floor(技能攻擊力 × (有效INT / 2 × 0.095))（見 `20-attributes.md` § 20.6.1）
- 元素克制 = 技能元素克制目標元素時 **+3**，加算至基礎魔攻（見 § 21.15）
- **裝備魔攻 = 所有已裝備部位的 `magicAttack` 加總 + 法杖／雙手法杖的強化加成**
  - 強化加成 = floor(強化等級 / 2)，見 `06-equipment.md` § 6.9
  - **魔導書的強化不給魔攻**：它是防具（`06-equipment.md` § 6.5），強化只給防禦；
    它的 `magicAttack` 基底照算 —— 不給的是強化那一份
  - **是乘區不是加項**：**每 1 點魔攻 → +6.5%**，乘在技能攻擊力上（魔攻 15 → ×1.975），
    因此同一件魔攻裝備在高階魔法上給的絕對值比低階魔法大
  - **不進 INT 倍率**：INT 加成那一段不吃這個乘區
- 技能元素傷害% = 所有裝備「技能元素傷害」詞綴的有效數值加總 **＋ 生效中的 buff 提供的技能元素傷害%**
  - 對火、冰、風、地、光、暗魔法皆生效；**無屬性魔法不吃這個乘區**
- 攻擊力%詞綴與元素刻印%詞綴**不影響**魔法攻擊力
- 適用對象：所有基礎魔法、所有職業魔法，**以及復仇之刃與背刺**。
  盾擊／裂傷斬／挑釁怒吼走 § 21.4a，三連射走 § 21.3 的物理普攻公式

> **INT 係數 9.5%、魔攻匯率 6.5%、技能攻擊力表三者是一組的。**
> 它們共同決定下方「三個來源的分工」的比例，改任何一個都會讓比例跑掉，
> 而且必須重新縮技能攻擊力表並重跑 `client/scripts/simulateReaperKill.mts` 驗證。
> 程式端的唯一出處是 `combat.ts` 的 `INT_SKILL_DAMAGE_PERCENT_PER_2`
> 與 `MAGIC_ATTACK_PERCENT_PER_POINT`。

### 與普攻的差異

| 項目 | 技能 |
|---|---|
| 命中判定 | **必定命中**，不 roll 命中率（例外：三連射依普攻命中公式逐箭判定） |
| 迴避判定 | **不可被迴避** |
| 武器材質種族克制 | **不適用**（材質克制僅限物理攻擊） |
| 虛弱 debuff（攻擊力 -20%） | **不影響**（只作用於走物理公式的傷害，§ 21.3）。例外：裂傷斬的流血 DoT 以基礎物理傷害快照，該部分會受影響，見 `24-buff-debuff.md` § 24.4.5 |
| 爆擊 | 適用，與普攻共用爆擊率／爆擊倍率（§ 21.8） |
| 怪物防禦減傷 | 適用，與物理共用 `min(怪物防禦, 75)`（怪物尚無魔抗欄位，見 § 21.16） |

### 三個來源的分工

| 來源 | 作用 | 佔比（元素師滿裝、究極光裂術） |
|---|---|---|
| INT 加成 | 主要傷害來源 | **50%** |
| 技能攻擊力 | 決定階級差，同時是 INT 加成的乘數基底 | **25%** |
| 裝備魔攻 | 乘在技能攻擊力上的加成 | **25%** |

這個 50/25/25 是**設計目標**，由 § 20.6.1 的 INT 係數（9.5%）與本節的魔攻匯率（6.5%）共同決定。

**調降技能攻擊力不會改變比例** —— INT 加成與魔攻乘區都正比於技能攻擊力，三者等比縮放。
要改變組成只能動那兩個係數。

佔比隨智力變動（裝備魔攻固定 15，即滿裝值），50% 是滿裝終盤值：

| 有效智力 | 智力 | 技能攻擊力 | 裝備魔攻 |
|---|---|---|---|
| 18（建角） | 30% | 35% | 34% |
| 28 | 40% | 30% | 30% |
| 42（滿裝） | **50%** | **25%** | **25%** |

> 裝備魔攻佔到 25%，代表**裸裝與滿裝的法系傷害差距接近一倍**。
> 這是刻意的：改動前魔攻只佔 6%，法系幾乎不吃裝備養成。

### 範例

```text
風刃（技能攻擊力 7），有效 INT 18，詞綴「技能元素傷害 +10%」，
手持 +2 白樺杖（T3），無魔導書：
INT 加成 = floor(7 × (18/2 × 0.095)) = 5
裝備魔攻 = 0 + floor(2/2) = 1 → 乘區 1 × 6.5% = +6.5%
基礎魔攻 = floor(7 × 1.065) + 5 = 7 + 5 = 12
魔法攻擊力 = floor(12 × 1.10) = 13
```

```text
滿裝元素師（究極光裂術 57、有效 INT 42、裝備魔攻 15、技能元素 +24%）：
INT 加成 = floor(57 × (42/2 × 0.095)) = 113
裝備魔攻乘區 = 15 × 6.5% = +97.5%
基礎魔攻 = floor(57 × 1.975) + 113 = 112 + 113 = 225
魔法攻擊力 = floor(225 × 1.24) = 279

組成驗算：技能攻擊力 57／225 = 25.3%、裝備魔攻 (112−57)／225 = 24.4%、
INT 113／225 = 50.2% —— 即設計目標的 50:25:25。
```

## 21.4a 物理快照技能

盾擊、裂傷斬、挑釁怒吼（騎士）走這條。

```
傷害 = 基礎魔攻 + 基礎物理傷害
基礎魔攻 = floor(技能攻擊力 × (1 + 裝備魔攻 × 6.5 / 100)) + INT加成 + 元素克制   （§ 21.4，與魔法技能同一段）
基礎物理傷害 = floor(((小怪傷害 + 大怪傷害) / 2 + 強化 + 額外攻擊 + STR加成) × (1 + 攻擊力%))
```

**技能側與 § 21.4 完全相同**，包含 INT 加成與裝備魔攻 —— 日後若有提供魔法攻擊的裝備，
這三招吃得到。兩邊的實作共用 `getBaseMagicAttack()`，不可各算各的。

物理側的規則：

| 項目 | 規則 |
|---|---|
| 取哪個基傷 | **小怪與大怪的平均**。這三招不分怪物體型 |
| 含強化／額外攻擊／STR 加成 | 是 |
| 含攻擊力%（詞綴與 buff） | 是 |
| 含元素刻印% | **否** |
| 含武器材質種族克制 | **否** |
| 虛弱 debuff | 作用於基礎物理傷害那一段，基礎魔攻那一段不受影響 |
| 未裝備武器 | 武器基傷以 1 計（普攻的保底值） |

其餘與 § 21.4 相同：**必定命中**，之後判定爆擊 → 怪物防禦減傷。
技能元素傷害%乘區不適用（這三招是無屬性）。

基礎物理傷害的唯一實作是 `calculateBasePhysicalDamage()`，與流血／毒 DoT 的快照同一顆；
入口是 `calculatePhysicalSnapshotSkill()`，由 `Skill.physicalSnapshot` 標記分流。

各招的技能攻擊力見 `23-class-magic.md` § 23.3。

### 範例

```text
盾擊（技能攻擊力 32），騎士 STR 30、有效 INT 10，
+5 破曉之刃（T6、15/13、額外攻擊 4），攻擊力% 合計 20%，無魔攻裝備：
INT 加成 = floor(32 × (10/2 × 0.095)) = 15
基礎魔攻 = floor(32 × 1.00) + 15 = 47   （騎士無魔攻裝備，乘區為 ×1）
基礎物理傷害 = floor(((15 + 13) / 2 + 5 + 4 + 15) × 1.20) = floor(38 × 1.20) = 45
傷害 = 47 + 45 = 92
```

## 21.4b 冷卻縮減

```
冷卻縮減% = min(50, 「減少冷卻時間」詞綴 + 冷卻縮減 buff + 有效INT / 2 × 1%)
有效冷卻 = floor(技能冷卻 × (1 - 冷卻縮減% / 100))
```

智力的貢獻見 `20-attributes.md` § 20.6.2。

## 21.4c 治癒量

治癒與傷害**走同一段技能側公式**，不另立係數。

```
基礎治癒量 = floor(技能攻擊力 × (1 + 裝備魔攻 × 6.5 / 100)) + INT加成
治癒量     = floor(基礎治癒量 × (1 + 治癒效果%))
```

與 § 21.4 的差別只有兩點：

| 項目 | § 21.4 傷害 | § 21.4c 治癒 |
|---|---|---|
| 元素克制 | 克制目標元素時 +3 | **沒有** —— 對自己施放，沒有目標元素可比 |
| 最後的乘區 | 技能元素傷害% | **治癒效果%** |

> 換乘區不是額外開一個位置：六招治癒全是無屬性，
> 而無屬性魔法本來就不吃技能元素傷害%（§ 21.4），那個乘區對治癒恆為 ×1。

- INT 加成與 § 21.4 完全相同：`floor(技能攻擊力 × (有效INT / 2 × 0.095))`
- 治癒效果% = 所有裝備「治癒效果」詞綴的有效數值加總
- 實際回復量再夾在「有效最大 HP − 目前 HP」之內
- **唯一實作是 `combat.ts` 的 `calculateHealAmount()`**，技能側與 `getBaseMagicAttack()`
  共用同一支 `getSkillSideValue()`。常駐天賦、戰鬥天賦、快捷格手動施放三條路徑
  全部呼叫它 —— 這三條以前各算各的，改一處就會有兩處對不上

### 技能攻擊力

治癒的技能攻擊力見 `22-basic-magic.md`（治癒／中治癒／大治癒／完全治癒）
與 `23-class-magic.md`（高階治癒／群體治癒）。

校準點是**有效 INT 18、裝備魔攻 0**，該條件下的回復量與改版前的固定值相同
（治癒 35／中治癒 70／大治癒 150／完全治癒 500／高階治癒 400／群體治癒 200）。
`healFormula.test.ts` 釘住這六個數字 —— 對不上就代表 INT 係數或魔攻匯率被改過
而沒有重新縮 power 表。

### 範例

```text
完全治癒（技能攻擊力 270），有效 INT 18，無魔攻裝備、無治癒效果詞綴：
INT 加成 = floor(270 × (18/2 × 0.095)) = 230
基礎治癒量 = floor(270 × 1.00) + 230 = 500
```

```text
滿裝牧師（完全治癒 270、有效 INT 42、裝備魔攻 15）：
INT 加成 = floor(270 × (42/2 × 0.095)) = 538
基礎治癒量 = floor(270 × 1.975) + 538 = 533 + 538 = 1071
```

裝備魔攻對治癒同樣生效，因此**滿裝的回復量約為建角期的 2.1 倍**。
這是刻意的：魔攻裝同時是輸出裝與治療裝，與傷害共用同一套養成邏輯。

## 21.5 防禦與減傷

### 防禦值的定義

**1 點防禦 = 少受 1% 傷害**，上限 75%（防禦 75 封頂），超出部分轉迴避。

### 起始防禦

所有職業、不分等級，角色自身防禦為 **-10**。
角色本身不提供正防禦，正防禦全部來自裝備；裝備的前 10 點防禦用於抵銷這個負值。

| 裝備防禦 | 實際減傷 |
|---|---|
| 0（裸裝） | 0% |
| 10 | 0% |
| 25 | 15% |
| 50 | 40% |
| 85 | 75%（封頂） |

最終防禦值夾底於 0，不會出現受到超過 100% 傷害的情況。

### 防禦值來源

| 來源 | 內容 |
|---|---|
| 裝備基礎防禦 | 各防具的 `defense` 欄位（胸甲／頭盔／鞋子／手套／盾牌） |
| 防具強化 | 每 +1 強化 → 防禦 +1（見 `06-equipment.md` § 6.10） |
| buff 固定防禦 | 例：魔法盔甲 +5 防禦 |
| 防禦力% 詞綴 | 乘算於上述合計 |
| 詛咒 debuff | 防禦 -20%，乘算於上述合計 |

### 強化的計入方式

- 只有 `defense > 0` 的裝備才計入 `enhancement`；武器（含法杖、弓）強化不產生防禦
- 1 級 = 1 點防禦，不隨部位或階級變動
- 強化加成計入「裝備基礎防禦」層，會被防禦力%詞綴一併放大

### 最終防禦值

```
裝備防禦合計 = Σ(該裝備基礎防禦 + 該裝備強化等級) + buff固定防禦
最終防禦值   = max(0, floor(裝備防禦合計 × (1 + 防禦力%/100) × (100 + 詛咒%)/100) − 10)
```

計算順序：

1. 逐件加總「基礎防禦 + 強化等級」
2. 加上 buff 固定防禦
3. 乘上防禦力% 詞綴與詛咒，取 floor
4. 最後減 10，夾底於 0

**-10 必須放在百分比之後**：併入括號會讓防禦力%詞綴放大負值（`(40−10)×1.1 = 33`），
現行順序為 `40×1.1 = 44 → 34`。

**範例**：胸甲 12（+3 強化）、頭盔 8、鞋子 7、手套 5、盾牌 10，防禦力詞綴 +10%

```
裝備防禦合計 = (12+3) + 8 + 7 + 5 + 10 = 45
套用詞綴     = floor(45 × 1.1) = 49
減起始防禦   = 49 − 10 = 39
→ 最終防禦 39，承受傷害 61%
```

### 減傷結算

```
防禦減傷率 = min(最終防禦值, 75)%
buff 減傷率 = 所有生效中 buff 的「減傷%」加總（同類加算，上限 100%）
實際傷害 = floor(floor(傷害 × (100 − 防禦減傷率) / 100) × (100 − buff減傷率) / 100)
```

- 防禦減傷上限 **75%**
- **無視防禦**：技能可帶「無視防禦%」，直接扣減目標的減傷率（例：目標減傷 60%、無視 50% → 實際減傷 30%）。來源：穿透箭雨（妖精 5，無視 50%）
- **防禦減傷與 buff 減傷是乘算**，互不排擠：防禦減傷 75% 搭配鋼鐵護盾 20% → 承受 `25% × 80% = 20%`
- 實際傷害最低為 1
- 詛咒作用在「最終防禦值」上，所以同時影響減傷與防禦溢出迴避

#### 傷害結算順序

1. 無敵判定（§ 24.4.8）—— 成立則傷害為 0，跳過後續
2. 迴避判定
3. 防禦減傷（上限 75%，可被「無視防禦%」扣減）
4. buff 減傷（類間乘算）
5. 格擋（有盾時，傷害減半）
6. **護盾吸收**（§ 24.4.9）—— 優先扣除護盾池，溢出部分才扣血

#### buff 減傷來源

| 來源 | 減傷 | 持續 |
|---|---|---|
| 鋼鐵護盾（騎士 3） | 20% | 15s |
| 聖域（基礎 9） | 25% | 10s |
| 神聖領域（牧師 5） | 30% | 10s |

聖域與神聖領域同屬 `sanctuary` category，互相覆蓋不疊加。

### 防禦溢出轉迴避

當最終防禦值超過 75 時，超過部分轉換為迴避率：

```
防禦溢出迴避 = floor((最終防禦值 - 75) / 5)%
```

## 21.6 迴避率

### 迴避率組成

```
迴避率 = 基礎迴避 + AGI迴避 + 防禦溢出迴避
```

- 基礎迴避：一般職業 5%，盜賊 10%
- AGI 迴避：有效敏捷 / 3（見 `20-attributes.md` § 20.3）
- 防禦溢出迴避：見 21.5

### 上限

```
迴避率上限 = 35%
```

三者加總不得超過 35%。

## 21.7 命中率

### 命中率公式

```
命中率 = 基礎命中 + AGI加成 + 武器攻擊成功 + 等級差修正 - 防禦者迴避率
```

- 基礎命中 = 80%（所有職業相同）
- AGI 加成 = 有效敏捷 / 3（見 `20-attributes.md` § 20.3）
- 武器攻擊成功 = 武器強化附帶的命中加成（如 +6 匕首 → 攻擊成功 +3 或是武器基本附帶攻擊成功 +3）
- 等級差修正 = (攻擊者等級 - 防禦者等級) × 1

### 上下限

```
命中率限縮於 5% ~ 95%
```

### 範例

```text
50 級騎士，+6 匕首（攻擊成功 +3），AGI 16，打 60 級怪（迴避 10%）：
命中率 = 80 + 5 + 3 + (50-60)×1 - 10 = 68%

50 級盜賊，+6 匕首（攻擊成功 +3），AGI 18，打 50 級怪（迴避 5%）：
命中率 = 80 + 6 + 3 + 0 - 5 = 84%
```

## 21.8 爆擊

### 爆擊率

```
爆擊率 = 基礎爆擊率 + 爆擊率%
```

- 基礎爆擊率 = 5%（所有職業相同）
- 爆擊率% = 所有裝備「爆擊率」詞綴的有效數值加總 **＋ 生效中的 buff 提供的爆擊率%**（加算）
- 爆擊率上限 = 75%

### 爆擊傷害

```
爆擊倍率 = 基礎爆擊倍率 + 爆擊傷害%
爆擊傷害 = floor(傷害 × 爆擊倍率)
```

- 基礎爆擊倍率 = 2.0（200%）
- 爆擊傷害% = 所有裝備「爆擊傷害」詞綴的有效數值加總 **＋ 生效中的 buff 提供的爆擊傷害%**
- 例：爆擊傷害詞綴 T3(10%) + T2(7%) = 17%，爆擊倍率 = 2.0 + 0.17 = 2.17

## 21.9 格擋

### 觸發條件

- 玩家裝備盾牌時，受到攻擊且未迴避，進入格擋判定
- 未裝備盾牌 → 跳過格擋判定

### 格擋率

```
格擋率 = 盾牌基礎格擋率 + 盾牌格擋率詞綴加總
格擋率上限 = 50%
```

- 盾牌基礎格擋率：見 `06-equipment-weapons.md` 盾牌表（木盾 5%、鐵盾 8%、騎士盾 10%、精鋼塔盾 12%、龍鱗盾 15%、守護者之盾 14%）
- 格擋率詞綴：僅盾牌可出現此詞綴，加算至該盾牌的基礎格擋率

### 格擋效果

```
格擋觸發 → 實際傷害 = floor(實際傷害 / 2)
```

格擋在防禦減傷之後判定，對已扣減傷後的傷害再減半。

### 判定順序

```text
迴避 → 防禦減傷 → 格擋 → 最終傷害
```

- 迴避成功：傷害為 0，不進入後續判定
- 迴避失敗：計算防禦減傷後，判定格擋
- 格擋成功：減傷後的傷害再除以 2
- 格擋失敗：正常受傷

### 備註

- 格擋對物理與魔法攻擊**皆生效**（§ 21.16）
- 迴避同樣對兩者皆生效

## 21.11 最終傷害計算流程

### 普攻（物理/遠程）

```text
1. 計算基礎攻擊力
   - 基礎攻擊力 = 武器基傷 + 額外攻擊 + STR加成 + 材質種族克制 + 元素克制
   - 材質種族克制：若武器材質克制目標種族 → += random(min, max)（見 §21.13）
   - 元素克制：若武器元素克制目標元素 → += 3（見 §21.15）
2. 套用詞綴乘區
   - 攻擊力 = floor(基礎攻擊力 × (1 + 攻擊力%) × (1 + 元素刻印%))
3. 判定命中（命中率 roll）
   - 命中率 = 基礎命中 + AGI加成 + 武器攻擊成功 + 等級差修正 + 種族命中加成(buff) - 防禦者迴避率
   - miss → 傷害 = 0，顯示 log
4. 判定爆擊（爆擊率 roll）
   - 爆擊 → 攻擊力 = floor(攻擊力 × 爆擊倍率)
5. 套用防禦減傷
   - 實際傷害 = max(1, floor(攻擊力 × (100 - 減傷率) / 100))
6. 套用虛弱 debuff（若生效中）
   - 實際傷害 = max(1, floor(實際傷害 × 0.8))
7. 造成最終傷害
```

### 技能攻擊

```text
1. 計算基礎魔攻
   - 基礎魔攻 = floor(技能攻擊力 × (1 + 裝備魔攻/100)) + INT加成 + 元素克制，見 § 21.4
   - 元素克制：若技能元素克制目標元素 → += 3（見 §21.15）
   - 注意：技能攻擊不套用武器材質種族克制（材質克制僅限物理攻擊）
   - 例外：盾擊／裂傷斬／挑釁怒吼改用 `固定值 + 基礎物理傷害`（§ 21.4a），
     其餘步驟（2 跳過、3～7）與本流程相同
2. 套用詞綴乘區
   - 攻擊力 = floor(基礎魔攻 × (1 + 技能元素傷害%))
3. 技能 100% 命中（跳過命中判定）(例外：三連射技能 依普攻命中公式獨立判定)
4. 技能不可被迴避（跳過迴避判定）
5. 判定爆擊（爆擊率 roll）
   - 爆擊 → 攻擊力 = floor(攻擊力 × 爆擊倍率)
6. 套用防禦減傷（最後）
   - 實際傷害 = max(1, floor(攻擊力 × (100 - 減傷率) / 100))
7. 造成最終傷害
```

### 怪物攻擊

```text
1. 判定迴避（玩家迴避率 roll）
   - 迴避成功 → 傷害 = 0，顯示 log
2. 計算怪物傷害：random(attackMin, attackMax)
3. 套用玩家防禦減傷
   - 實際傷害 = floor(傷害 × (100 - 減傷率) / 100)
4. 判定格擋（裝備盾牌時）
   - 格擋率 roll 成功 → 實際傷害 = floor(實際傷害 / 2)
5. 造成最終傷害
```

### 戰鬥 Log 訊息格式

| 情境 | Log 訊息 |
|---|---|
| 玩家普攻未命中 | 「攻擊未命中」 |
| 玩家普攻命中 | 「對 {怪物名} 造成 {傷害} 點傷害」 |
| 玩家普攻暴擊 | 「暴擊！對 {怪物名} 造成 {傷害} 點傷害」 |
| 玩家技能命中 | 「{技能名} 對 {怪物名} 造成 {傷害} 點傷害」 |
| 玩家技能暴擊 | 「{技能名} 暴擊！對 {怪物名} 造成 {傷害} 點傷害」 |
| 玩家迴避怪物攻擊 | 「迴避了 {怪物名} 的攻擊」 |
| 怪物攻擊命中 | 「{怪物名} 對你造成 {傷害} 點傷害」 |

### 詞綴彙總規則

- 同類型詞綴：加算（例如兩條攻擊力 T3 = 9% + 11% = 20%）
- 不同乘區之間：乘算（攻擊 × 元素 × 爆傷）
- 詞綴有效數值 = 詞綴基礎值 × (1 + 品質% / 100)（見 `08-quality.md`）

## 21.12 設計意圖

- 命中率同級普通裝備約 75~80%，堆裝可到 85%+
- 打高 10 級怪命中率約 60~65%，形成自然等級壓力
- 防禦減傷有硬上限（75%），避免高防角色無敵，確保 Pressure 機制有意義
- 溢出防禦轉迴避提供重甲角色額外價值，但迴避同樣有上限（35%）
- 詞綴採分類加算、類間乘算（方案 C），鼓勵多樣化搭配而非無腦堆單一屬性
- 元素刻印與技能元素傷害分離，讓物理系與魔法系有不同的養成路線
- 無屬性武器/技能不受元素詞綴影響，為 endgame 武器附魔系統預留成長空間

## 21.16 怪物魔法攻擊

部分怪物（巫師／魔導系）以遠程魔法攻擊角色，傷害結算與物理攻擊共用同一條流程，
**只有減傷這一步不同**。

### 適用怪物

攻擊型別為魔法的怪物，目前為 6 種（共 9 筆，各樓層獨立）：
象牙巫師、象牙魔導師、暗影巫師、不死巫妖、霜凍女巫、精靈王魔導士。

- 射程 **8 格**，需通過視線判定（與遠程物理相同，見 `41-arpg-combat.md` § 3.1）
- 元素系怪物（潮汐／冰霜／冰晶／岩漿元素）維持近戰

### 減傷公式

```
裝備貢獻   = min(最終防禦值, 75) × 0.5     （等同 min(最終防禦值 / 2, 37.5)）
魔法減傷率 = min( 裝備貢獻 + 魔法抗性, 75 )
```

**裝備防禦對魔法只有一半效力**，因此貢獻上限為物理上限的一半（**37.5%**）。
換句話說：`魔法的防禦減傷 = 物理防禦減傷 ÷ 2`，剩下的 37.5% 缺口一律要靠魔法抗性補。

### 魔法抗性的三個來源

| 來源 | 數值 | 說明 |
|---|---|---|
| 精神（SPI） | `floor(有效SPI / 2)` | 見 `20-attributes.md` § 20.3 |
| 飾品強化 | 每 +1 → **2%** | 項鍊／戒指，見 `06-equipment.md` § 6.10.1 |
| 魔法抗性詞綴 | T1 1~2% ~ T7 16~20%（專屬階級表，受品質放大） | 只出現在項鍊／戒指／盾牌，見 `07-affix.md` § 7.3.1 |

三者**相加**後套入上方公式。

- **裝備防禦對魔法只有一半效力**，貢獻上限 37.5%（= 物理上限 75% 的一半）
- 不足 75% 的部分由魔法抗性補足，總上限與物理相同
- 對照：物理減傷率 = `min(最終防禦值, 75)`

**所有職業都需要魔法抗性** —— 即使把防禦堆到上限，魔法減傷也只有 37.5%，
仍有 37.5% 的缺口必須靠魔抗填補：

| 角色 | 最終防禦 | 裝備貢獻 | SPI 魔抗 | 已有 | 距 75% 的缺口 |
|---|---|---|---|---|---|
| 後期騎士（板甲、SPI 10） | 75 | 37.5 | 5 | 42.5 | **32.5** |
| 後期騎士（板甲、SPI 35） | 75 | 37.5 | 17 | 54.5 | **20.5** |
| 後期元素師（布甲、SPI 35） | 20 | 10 | 17 | 27 | **48** |

高防角色的缺口較小但依然存在，布甲職業則需要大量魔抗。

### 角色 → 怪物：尚未實作

**本節的魔法減傷只涵蓋「怪物 → 角色」方向。** 反方向目前沒有對應機制：

| 方向 | 物理減傷 | 魔法減傷 |
|---|---|---|
| 怪物 → 角色 | `min(最終防禦, 75)` | `min(最終防禦,75) × 0.5 + 魔法抗性`，上限 75 |
| 角色 → 怪物 | `min(怪物防禦, 75)` | **同左，不區分** |

三處傷害結算（普攻、物理技能、魔法技能）都走同一條 `min(怪物防禦, 75)`。
因此「元素師／牧師打高防怪」與「騎士打高防怪」受到的防禦壓制完全相同，
魔法系沒有對應的破防管道（僅穿透箭雨的「無視防禦%」，§ 23.4）。

未來要補上怪物魔抗時，需一併決定與同步：

- `MonsterTemplate` / `MonsterInstance` 新增 `magicResist` 欄位
- 只改 `calculateSkillAttack` 的**魔法技能**路徑；普攻與物理技能維持原樣
- 怪物端的公式形狀 —— 是否比照角色端「防禦半效 + 魔抗」，或另訂
- 「無視防禦%」是否也無視怪物魔抗
- 199 隻怪物的魔抗數值 —— **必須由使用者提供，不可自行填入**
- `25-monster-system.md` § 25.8 屬性表、`28-monster-stats.md` 素質表各新增一欄
- 本節補上「角色 → 怪物」方向的公式

### 結算順序

與物理完全相同（§ 21.5 傷害結算順序）：

1. 無敵判定
2. **迴避判定**（生效）
3. 魔法減傷（本節公式）
4. buff 減傷（類間乘算）
5. **格擋**（生效，傷害減半）
6. 護盾吸收

### 範例

```text
防禦 60、SPI 18（魔抗 9）的角色，被攻擊力 100 的魔法怪命中：
裝備貢獻 = min(60, 75) × 0.5 = 30
魔法減傷率 = min(30 + 9, 75) = 39%
實際傷害 = floor(100 × 61 / 100) = 61

同一角色被攻擊力 100 的物理怪命中：
物理減傷率 = min(60, 75) = 60%
實際傷害 = floor(100 × 40 / 100) = 40

→ 同樣攻擊力下，魔法怪造成的傷害約為物理怪的 1.5 倍
```

## 21.13 武器材質種族克制

武器材質對特定種族怪物造成額外傷害（**加算至基礎攻擊力**，見 § 21.11 步驟 1）：

| 材質 | 克制種族 | 額外傷害 |
|---|---|---|

| 鐵 | — | 無 |
| 銀 | 不死、惡魔 | +random(1, 4) |
| 米索利 | 不死 | +random(1, 6) |
| 奧里哈魯根 | 不死 | +random(1, 10) |
| 龍材質 | 龍 | +random(1, 6) |

- 僅物理普攻適用，技能攻擊不套用材質克制
- 每次攻擊獨立隨機，不累積
- 材質克制與元素克制獨立計算，可疊加
- 無特殊材質的武器對所有種族無額外加成

## 21.15 元素克制傷害

武器/技能的元素屬性對怪物元素屬性造成額外固定傷害（**加算至基礎攻擊力／基礎魔攻**，見 § 21.11 步驟 1）：

### 克制關係

```
火 → 風 → 地 → 冰 → 火
光 ↔ 暗（互克）
無：不克制也不被克制
```

### 克制效果

- 用克制屬性攻擊被克制屬性怪物：額外 +3 傷害
- 其他所有情況：+0（無懲罰）

### 適用範圍

- 普攻：根據武器附魔元素判定
- 技能攻擊：根據技能元素屬性判定
- 無屬性武器/技能不觸發元素克制
