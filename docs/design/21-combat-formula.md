# 21. 戰鬥公式

## 21.1 通用規則

- 所有計算結果取整方式為**無條件捨去（floor）**
- 所有百分比加成以乘算方式套用於基礎值

---

## 21.2 HP / MP 初始值與成長

| 項目 | 1 級初始值 | 每級成長公式 |
|---|---|---|
| HP | 30 | `random(VIT - 6, VIT - 3)` |
| MP | 10 | `random(SPI - 6, SPI - 3)` |

所有職業 1 級 HP 為 30、MP 為 10。

升級時 HP 與 MP 恢復全滿。

## 21.3 物理攻擊力

屬性換算規則見 `20-attributes.md`。

### 詞綴乘區規則（方案 C：分類加算，類間乘算）

同類型詞綴加算至同一乘區，不同乘區之間相乘：

| 乘區 | 來源詞綴 | 生效時機 |
|---|---|---|
| 攻擊乘區 | 攻擊力% 加總 | 物理普攻（不影響魔法） |
| 普攻元素乘區 | 普攻元素傷害% 加總 | 普攻時（武器攻擊） |
| 技能元素乘區 | 技能元素傷害% 加總 | 施放技能時 |
| 爆傷乘區 | 爆擊傷害% 加總 | 暴擊觸發時 |

普攻元素傷害與技能元素傷害**互不疊加**，依攻擊方式擇一生效。

### 詞綴與 buff 的合流

以下四項可同時由「裝備詞綴」與「技能 buff」提供，計算時**加總為同一個值**：

| 項目 | 詞綴來源 | buff 來源 |
|---|---|---|
| 爆擊率% | 爆擊率詞綴 | 精準打擊（盜賊 4，+10%） |
| 爆擊傷害% | 爆擊傷害詞綴 | 致命一擊（盜賊 2，+50%） |
| 技能元素傷害% | 技能元素傷害詞綴 | 元素增幅（元素師 3，+25%） |
| 減少冷卻時間% | 減少冷卻時間詞綴 | 冷卻縮減（元素師 1，+20%） |

冷卻縮減上限維持 50%，計算的是詞綴與 buff 加總後的值。

### 近戰攻擊力（普攻）

```
基礎攻擊力 = 武器基傷 + 額外攻擊 + STR加成
近戰攻擊力 = floor(基礎攻擊力 × (1 + 攻擊力%) × (1 + 普攻元素傷害%))
```

- STR 加成 = 有效力量 / 2（見 `20-attributes.md` § 20.3）
- 武器基傷分 smallMonsterDamage / largeMonsterDamage，分別計算
- 額外攻擊 = 武器的 extraAttack 數值，直接加算至武器基傷上（注意：額外攻擊 ≠ 多段攻擊，本遊戲無多段攻擊機制）
- 攻擊力% = 所有裝備「攻擊力」詞綴的有效數值加總
- 普攻元素傷害% = 所有裝備「普攻元素傷害」詞綴的有效數值加總
- 無屬性武器不受普攻元素傷害詞綴影響

### 遠程攻擊力（普攻）

```
基礎攻擊力 = 武器基傷 + 額外攻擊 + 遠程攻擊加成 + STR加成
遠程攻擊力 = floor(基礎攻擊力 × (1 + 攻擊力%) × (1 + 普攻元素傷害%))
```

- STR 加成 = 有效力量 / 2（見 `20-attributes.md` § 20.3）
- 額外攻擊 = 武器的 extraAttack 數值，直接加算至武器基傷上（注意：額外攻擊 ≠ 多段攻擊，本遊戲無多段攻擊機制）
- **遠程攻擊加成** = 生效中 buff 提供的「遠程攻擊」固定值，**僅在裝備弓時生效**（近戰武器不計入）
  - 來源：鷹眼（妖精 4，遠攻 +3）
- 攻擊力% = 所有裝備「攻擊力」詞綴的有效數值加總 —— **與近戰相同，對遠程攻擊同樣生效**
- 普攻元素傷害% = 所有裝備「普攻元素傷害」詞綴的有效數值加總 —— **與近戰相同，對遠程攻擊同樣生效**
- 無屬性武器不受普攻元素傷害詞綴影響（火矢附魔生效時視為火屬性，故可吃到）

### 範例

```text
武器 10/10，STR 18，詞綴「攻擊力 +12%」+「普攻元素傷害 +10%」：
基礎攻擊力 = 10 + 9 = 19
近戰攻擊力 = floor(19 × 1.12 × 1.10) = floor(23.4) = 23
```

## 21.4 魔法攻擊力

```
基礎魔攻 = 技能攻擊力 + INT加成 + 裝備魔攻
魔法攻擊力 = floor(基礎魔攻 × (1 + 技能元素傷害%))
```

- INT 加成 = 技能攻擊力 × (有效INT / 2 × 10%)
- **裝備魔攻 = 所有已裝備部位的 `magicAttack` 加總 + 法杖／雙手法杖／魔導書的強化加成**
  - 強化加成 = floor(強化等級 / 2)，見 `06-equipment.md` § 6.9
  - **以固定值加算，不進 INT 倍率**：換裝備得到的魔攻不會被 INT 放大
- 技能元素傷害% = 所有裝備「技能元素傷害」詞綴的有效數值加總 **＋ 生效中的 buff 提供的技能元素傷害%**
- 技能元素傷害詞綴對所有元素屬性（火、冰、風、地、光、暗）魔法皆生效
- 無屬性魔法不受技能元素傷害詞綴影響
- 攻擊力%詞綴不影響魔法攻擊力
- **本公式同時適用於標示「物理傷害」的職業技能**（盾擊、裂傷斬、挑釁怒吼、復仇之刃、背刺）——
  它們的「物理」指傷害類型而非公式，見 `23-class-magic.md` § 23.1.1。
  唯一走物理普攻公式的技能是三連射（以 `hits` 標記多段判定）

### 範例

```text
風刃（技能攻擊力 10），INT 18，詞綴「技能元素傷害 +10%」，無魔導書：
INT 加成 = 10 × (18/2 × 10%) = 10 × 90% = 9
基礎魔攻 = 10 + 9 + 0 = 19
魔法攻擊力 = floor(19 × 1.10) = floor(20.9) = 20
```

```text
同上，但副手裝備 +4 強化的魔力魔導書（魔攻 +4）：
裝備魔攻 = 4 + floor(4/2) = 6
基礎魔攻 = 10 + 9 + 6 = 25
魔法攻擊力 = floor(25 × 1.10) = floor(27.5) = 27
```

## 21.5 防禦與減傷

### 防禦值來源

- 所有職業初始防禦值為 0
- 防禦值完全由裝備提供

### 計算公式

```
裝備防禦合計 = Σ(裝備基礎防禦 + 強化等級) + buff固定防禦加成
最終防禦值 = floor(裝備防禦合計 × (1 + 防禦力%))
```

- 裝備基礎防禦：各防具的 defense 欄位
- 強化等級：僅有防禦值的裝備才計入 enhancement
- buff固定防禦加成：如魔法盔甲的 +5 防禦
- 防禦力% = 所有裝備「防禦力」詞綴的有效數值加總

### 減傷公式

```
防禦減傷率 = min(最終防禦值, 75)%
buff 減傷率 = 所有生效中 buff 的「減傷%」加總（同類加算，上限 100%）
實際傷害 = floor(floor(傷害 × (100 - 防禦減傷率) / 100) × (100 - buff減傷率) / 100)
```

- 防禦減傷上限為 75%
- **無視防禦**：技能可帶「無視防禦%」，直接扣減目標的減傷率（例：目標減傷 60%、無視 50% → 實際減傷 30%）。來源：穿透箭雨（妖精 5，無視 50%）
- **防禦減傷與 buff 減傷為類間乘算**，兩者互不排擠：例如防禦減傷 75% 搭配鋼鐵護盾 20%，最終承受 `25% × 80% = 20%` 的傷害
- 實際傷害最低為 1
- 詛咒（防禦 -20%）作用於「最終防禦值」，因此同時影響減傷與防禦溢出迴避

#### 傷害結算順序

1. 無敵判定（§ 24.4.8）—— 成立則傷害為 0，跳過後續
2. 迴避判定
3. 防禦減傷（上限 75%，可被「無視防禦%」扣減）
4. buff 減傷（類間乘算）
5. 格擋（有盾時，傷害減半）
6. **護盾吸收**（§ 24.4.9）—— 優先扣除護盾池，溢出部分才扣血

#### buff 減傷來源

| 來源 | 減傷 | 持續 |
|---|---|---|
| 鋼鐵護盾（騎士 3） | 20% | 15s |
| 聖域（基礎 9） | 25% | 10s |
| 神聖領域（牧師 5） | 30% | 10s |

聖域與神聖領域同屬 `sanctuary` category，互相覆蓋不疊加。

### 防禦溢出轉迴避

當最終防禦值超過 75 時，超過部分轉換為迴避率：

```
防禦溢出迴避 = floor((最終防禦值 - 75) / 5)%
```

## 21.6 迴避率

### 迴避率組成

```
迴避率 = 基礎迴避 + AGI迴避 + 防禦溢出迴避
```

- 基礎迴避：一般職業 5%，盜賊 10%
- AGI 迴避：有效敏捷 / 3（見 `20-attributes.md` § 20.3）
- 防禦溢出迴避：見 21.5

### 上限

```
迴避率上限 = 35%
```

三者加總不得超過 35%。

---

## 21.7 命中率

### 命中率公式

```
命中率 = 基礎命中 + AGI加成 + 武器攻擊成功 + 等級差修正 - 防禦者迴避率
```

- 基礎命中 = 80%（所有職業相同）
- AGI 加成 = 有效敏捷 / 3（見 `20-attributes.md` § 20.3）
- 武器攻擊成功 = 武器強化附帶的命中加成（如 +6 匕首 → 攻擊成功 +3 或是武器基本附帶攻擊成功 +3）
- 等級差修正 = (攻擊者等級 - 防禦者等級) × 1

### 上下限

```
命中率限縮於 5% ~ 95%
```

### 範例

```text
50 級騎士，+6 匕首（攻擊成功 +3），AGI 16，打 60 級怪（迴避 10%）：
命中率 = 80 + 5 + 3 + (50-60)×1 - 10 = 68%

50 級盜賊，+6 匕首（攻擊成功 +3），AGI 18，打 50 級怪（迴避 5%）：
命中率 = 80 + 6 + 3 + 0 - 5 = 84%
```

## 21.8 爆擊

### 爆擊率

```
爆擊率 = 基礎爆擊率 + 爆擊率%
```

- 基礎爆擊率 = 5%（所有職業相同）
- 爆擊率% = 所有裝備「爆擊率」詞綴的有效數值加總 **＋ 生效中的 buff 提供的爆擊率%**（加算）
- 爆擊率上限 = 75%

### 爆擊傷害

```
爆擊倍率 = 基礎爆擊倍率 + 爆擊傷害%
爆擊傷害 = floor(傷害 × 爆擊倍率)
```

- 基礎爆擊倍率 = 2.0（200%）
- 爆擊傷害% = 所有裝備「爆擊傷害」詞綴的有效數值加總 **＋ 生效中的 buff 提供的爆擊傷害%**
- 例：爆擊傷害詞綴 T3(12%) + T2(9%) = 21%，爆擊倍率 = 2.0 + 0.21 = 2.21

## 21.9 格擋

### 觸發條件

- 玩家裝備盾牌時，受到攻擊且未迴避，進入格擋判定
- 未裝備盾牌 → 跳過格擋判定

### 格擋率

```
格擋率 = 盾牌基礎格擋率 + 盾牌格擋率詞綴加總
格擋率上限 = 50%
```

- 盾牌基礎格擋率：見 `06-equipment-weapons.md` 盾牌表（木盾 5%、鐵盾 8%、騎士盾 10%、精鋼塔盾 12%、龍鱗盾 15%、守護者之盾 14%）
- 格擋率詞綴：僅盾牌可出現此詞綴，加算至該盾牌的基礎格擋率

### 格擋效果

```
格擋觸發 → 實際傷害 = floor(實際傷害 / 2)
```

格擋在防禦減傷之後判定，對已扣減傷後的傷害再減半。

### 判定順序

```text
迴避 → 防禦減傷 → 格擋 → 最終傷害
```

- 迴避成功：傷害為 0，不進入後續判定
- 迴避失敗：計算防禦減傷後，判定格擋
- 格擋成功：減傷後的傷害再除以 2
- 格擋失敗：正常受傷

### 備註

- 目前所有怪物攻擊皆為物理攻擊，格擋對所有攻擊生效
- 未來若加入怪物魔法攻擊，再決定格擋是否對魔法生效

## 21.11 最終傷害計算流程

### 普攻（物理/遠程）

```text
1. 計算基礎攻擊力
   - 基礎攻擊力 = 武器基傷 + 額外攻擊 + STR加成 + 材質種族克制 + 元素克制
   - 材質種族克制：若武器材質克制目標種族 → += random(min, max)（見 §21.13）
   - 元素克制：若武器元素克制目標元素 → += 3（見 §21.15）
2. 套用詞綴乘區
   - 攻擊力 = floor(基礎攻擊力 × (1 + 攻擊力%) × (1 + 普攻元素傷害%))
3. 判定命中（命中率 roll）
   - 命中率 = 基礎命中 + AGI加成 + 武器攻擊成功 + 等級差修正 + 種族命中加成(buff) - 防禦者迴避率
   - miss → 傷害 = 0，顯示 log
4. 判定爆擊（爆擊率 roll）
   - 爆擊 → 攻擊力 = floor(攻擊力 × 爆擊倍率)
5. 套用防禦減傷（最後）
   - 實際傷害 = max(1, floor(攻擊力 × (100 - 減傷率) / 100))
6. 造成最終傷害
```

### 技能攻擊

```text
1. 計算基礎魔攻
   - 基礎魔攻 = 技能攻擊力 + INT加成 + 裝備魔攻 + 元素克制
   - 元素克制：若技能元素克制目標元素 → += 3（見 §21.15）
   - 注意：技能攻擊不套用武器材質種族克制（材質克制僅限物理攻擊）
2. 套用詞綴乘區
   - 攻擊力 = floor(基礎魔攻 × (1 + 技能元素傷害%))
3. 技能 100% 命中（跳過命中判定）(例外：三連射技能 依普攻命中公式獨立判定)
4. 技能不可被迴避（跳過迴避判定）
5. 判定爆擊（爆擊率 roll）
   - 爆擊 → 攻擊力 = floor(攻擊力 × 爆擊倍率)
6. 套用防禦減傷（最後）
   - 實際傷害 = max(1, floor(攻擊力 × (100 - 減傷率) / 100))
7. 造成最終傷害
```

### 怪物攻擊

```text
1. 判定迴避（玩家迴避率 roll）
   - 迴避成功 → 傷害 = 0，顯示 log
2. 計算怪物傷害：random(attackMin, attackMax)
3. 套用玩家防禦減傷
   - 實際傷害 = floor(傷害 × (100 - 減傷率) / 100)
4. 判定格擋（裝備盾牌時）
   - 格擋率 roll 成功 → 實際傷害 = floor(實際傷害 / 2)
5. 造成最終傷害
```

### 戰鬥 Log 訊息格式

| 情境 | Log 訊息 |
|---|---|
| 玩家普攻未命中 | 「攻擊未命中」 |
| 玩家普攻命中 | 「對 {怪物名} 造成 {傷害} 點傷害」 |
| 玩家普攻暴擊 | 「暴擊！對 {怪物名} 造成 {傷害} 點傷害」 |
| 玩家技能命中 | 「{技能名} 對 {怪物名} 造成 {傷害} 點傷害」 |
| 玩家技能暴擊 | 「{技能名} 暴擊！對 {怪物名} 造成 {傷害} 點傷害」 |
| 玩家迴避怪物攻擊 | 「迴避了 {怪物名} 的攻擊」 |
| 怪物攻擊命中 | 「{怪物名} 對你造成 {傷害} 點傷害」 |

### 詞綴彙總規則

- 同類型詞綴：加算（例如兩條攻擊力 T3 = 11% + 12% = 23%）
- 不同乘區之間：乘算（攻擊 × 元素 × 爆傷）
- 詞綴有效數值 = 詞綴基礎值 × (1 + 品質% / 100)（見 `08-quality.md`）

## 21.12 設計意圖

- 命中率同級普通裝備約 75~80%，堆裝可到 85%+
- 打高 10 級怪命中率約 60~65%，形成自然等級壓力
- 防禦減傷有硬上限（75%），避免高防角色無敵，確保 Pressure 機制有意義
- 溢出防禦轉迴避提供重甲角色額外價值，但迴避同樣有上限（35%）
- 詞綴採分類加算、類間乘算（方案 C），鼓勵多樣化搭配而非無腦堆單一屬性
- 普攻元素傷害與技能元素傷害分離，讓物理系與魔法系有不同的養成路線
- 無屬性武器/技能不受元素詞綴影響，為 endgame 武器附魔系統預留成長空間

## 21.13 武器材質種族克制

武器材質對特定種族怪物造成額外傷害（加算至減傷後的傷害上）：

| 材質 | 克制種族 | 額外傷害 |
|---|---|---|
| 木 | — | 無 |
| 鐵 | — | 無 |
| 銀 | 不死、惡魔 | +random(1, 4) |
| 米索利 | 不死 | +random(1, 6) |
| 奧里哈魯根 | 不死 | +random(1, 10) |
| 龍材質 | 龍 | +random(1, 6) |

### 規則

- 僅物理普攻適用，技能攻擊不套用材質克制
- 每次攻擊獨立隨機，不累積
- 材質克制與元素克制獨立計算，可疊加
- 無特殊材質的武器對所有種族無額外加成

## 21.14 種族命中加成（Buff）

特定 buff 可提供對指定種族的命中率加成：

| Buff | 效果 | 來源 |
|---|---|---|
| 祝福武器 | 對不死系命中 +5 | 基礎魔法 Lv.1 |

### 規則

- 加算至命中率公式中（§21.7）
- 僅當攻擊目標為指定種族時生效
- 不影響技能攻擊（技能 100% 命中）

## 21.15 元素克制傷害

武器/技能的元素屬性對怪物元素屬性造成額外固定傷害（加算至減傷後的傷害上）：

### 克制關係

```
火 → 風 → 地 → 冰 → 火
光 ↔ 暗（互克）
無：不克制也不被克制
```

### 克制效果

- 用克制屬性攻擊被克制屬性怪物：額外 +3 傷害
- 其他所有情況：+0（無懲罰）

### 適用範圍

- 普攻：根據武器附魔元素判定
- 技能攻擊：根據技能元素屬性判定
- 無屬性武器/技能不觸發元素克制
