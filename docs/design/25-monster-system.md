# 25. 怪物系統

## 25.1 種族分類

所有怪物歸屬於以下四種種族之一：

| 種族 | 說明 |
|---|---|
| 一般 | 不屬於其他三類的所有怪物 |
| 不死 | 骷髏、殭屍、幽魂、亡靈等 |
| 惡魔 | 妖魔、惡魔、夢魘等 |
| 龍 | 幼龍、飛龍、古龍、龍人等 |

## 25.2 體型分類

| 體型 | 說明 |
|---|---|
| 小型 | 一般怪物、部分 Boss |
| 大型 | 大型怪物、多數 Boss |

- 體型影響武器傷害計算（smallMonsterDamage / largeMonsterDamage）
- Boss 不一定是大型，部分 Boss 為小型

## 25.5 武器材質與種族克制

### 材質列表

| 材質 | 說明 |
|---|---|
| 木 | 木質武器，無種族克制 |
| 鐵 | 金屬武器，無種族克制 |
| 銀 | 對不死、惡魔有效 |
| 米索利 | 對不死有效 |
| 龍材質 | 對龍有效 |
| 奧里哈魯根 | 對不死有效，稀有材質 |

- 材質決定種族克制效果，不決定武器強弱
- 武器強弱由傷害數值、攻擊成功、額外攻擊等屬性決定

### 種族克制加成

武器材質對特定種族怪物造成額外傷害：

| 材質 | 克制種族 | 額外傷害 |
|---|---|---|
| 木 | — | 無 |
| 鐵 | — | 無 |
| 銀 | 不死、惡魔 | +1~4 |
| 米索利 | 不死 | +1~6 |
| 奧里哈魯根 | 不死 | +1~10 |
| 龍材質 | 龍 | +1~6 |

- 額外傷害為隨機範圍，每次攻擊獨立計算
- 無特殊材質的武器對所有種族無額外加成也無減傷
- 材質克制與元素克制獨立計算，可疊加

## 25.6 掉落系統

### 掉落機制

採用加權獨立判定機制。每個物品獨立判定是否掉落，一次擊殺可同時掉落多個物品。

### 掉落公式

```
掉落機率 = 物品掉落值 / 伺服器掉落機率基數
```

- 掉落機率基數為全伺服器統一設定值
- 每個物品各自擁有一個掉落值
- 掉落值 ≥ 基數時，該物品 100% 掉落
- 每個物品獨立判定，互不影響

### 範例

伺服器掉落機率基數 = 1000

| 物品 | 掉落值 | 掉落機率 |
|---|---|---|
| 金幣 | 1000 | 100% |
| 肉 | 500 | 50% |
| 鐵礦石 | 100 | 10% |
| 稀有寶石 | 10 | 1% |

### 設計要點

- 掉落機率基數為伺服器全域設定，可統一調整全體掉落率
- 掉落品跟隨地圖等級產生差異（同怪物在高等級區域掉更好的物品）
- 各怪物的具體掉落表待設計

## 25.7 怪物強度規則

- 同名怪物可出現在不同區域或樓層
- 每個怪物有一個基礎獨立模板，會隨著所在地圖等級自動調整血量、傷害、防禦
- 掉落品跟隨地圖等級產生差異
- 不為同一怪物設計多個獨立模板，統一由基礎模板 + 等級公式計算

## 25.7 設計原則

- 每個區域/樓層配置 3~4 種怪物
- 種族、體型、元素屬性三者獨立，自由組合
- 武器材質克制種族，元素克制元素，兩套系統並行
- 無屬性為中立選擇，不享受克制加成也不受克制懲罰

## 25.9 怪物 Debuff 能力

怪物攻擊角色時，依據自身 debuff 能力有機率觸發對角色的負面狀態。

### 25.9.1 Debuff 分配原則

| Debuff | 適合怪物類型 | 觸發率範圍 |
|--------|-------------|-----------|
| 中毒 | 蜘蛛、蛇、毒系怪物 | 15%~20% |
| 流血 | 野獸、爪牙類怪物 | 15%~20% |
| 詛咒 | 不死系、惡魔系怪物 | 10%~15% |
| 虛弱 | 巫師、魔導師類怪物 | 10%~15% |
| 減速 | 冰屬性怪物（每區最多一種） | 固定 10% |
| 暈眩 | Boss、殘影系列、巨獸類 | Boss 15%~22%、巨獸類固定 10% |

> 觸發率範圍為一般怪物的配置基準；Boss 為強度定位可上調至 22%，實際數值以 § 25.8 表格為準。

**巨獸類定義**：名稱含「巨人」「巨獸」「凶獸」的大型力量型怪物。目前為岩石巨人、巨人、霜凍巨人、熔岩巨獸、遠古凶獸。

### 25.9.2 Debuff 觸發規則

1. **單次攻擊單一 debuff**：怪物每次攻擊最多觸發一種 debuff
2. **多 debuff 怪物判定順序**：依表格順序判定，命中即停
3. **觸發率計算**：`最終觸發率 = 基礎觸發率 × (1 - 角色免疫率)`
4. **免疫詞綴**：角色裝備免疫詞綴後，對應 debuff 觸發率歸零
5. **暈眩施加者限制**：僅以下三類可對角色施加暈眩，其餘一般怪物無暈眩能力
   - **Boss**：觸發率依樓層/區域強度，15%~22%
   - **殘影系列**：Boss 殘影，暈眩能力視同其本體 Boss
   - **巨獸類**：非 Boss 巨獸觸發率一律 10%，不隨等級提升
