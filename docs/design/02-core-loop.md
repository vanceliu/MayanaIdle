# 2. 核心循環

MayanaIdle 的核心循環如下：

1. 玩家進入地圖或副本
2. 角色在地圖上自動移動探索
3. 怪物依 Pressure 機制在地圖上持續生成
4. 角色靠近怪物後自動進入即時 ARPG 戰鬥（追蹤 → 攻擊）
5. 玩家可手動操作（選擇目標、施放技能），也可由戰鬥天賦全自動執行
6. 停留時間越長，地圖上同時存在的怪物越多（上限 10 隻）
7. 每隻怪物死亡時立刻結算經驗、金幣、裝備、材料
8. 玩家返回城鎮整理裝備、補給、強化、強化詞綴、提升品質
9. 角色升級後學習或升級主動技能（各職業學習等級不同，見 `05-skill.md`）
10. 玩家前往更高難度區域、副本或挑戰排行榜
11. 不斷重複上述流程

```text
↓

↓
補給與倉庫管理
↓
挑戰更高難度內容
```
