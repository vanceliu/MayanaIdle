# 2. 核心循環

MayanaIdle 的核心循環如下：

1. 玩家進入地圖或副本
2. 在區域內持續探索
3. 隨機遭遇怪物
4. 進入 ARPG 式戰鬥
5. 玩家可手動戰鬥，也可開啟自動戰鬥
6. 怪物隨時間與戰鬥狀態逐漸增加數量
7. 玩家擊敗怪物後取得經驗、金幣、裝備、材料
8. 玩家返回城鎮整理裝備、補給、強化、強化詞綴、提升品質
9. 角色升級後學習或升級主動技能（各職業學習等級不同，見 `05-skill.md`）
10. 玩家前往更高難度區域、副本或挑戰排行榜
11. 不斷重複上述流程
