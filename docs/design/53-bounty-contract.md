# 53. 懸賞契約

冒險者工會的「懸賞」分頁。簽約時付金幣，契約期間指定對象生成時保證帶強化詞綴，
可加購「掉兩次取比較好」。契約**沒有完成獎勵**。

| 項目 | 規則 |
|---|---|
| 入口 | 冒險者工會面板頂層分頁「懸賞」（`13-town.md` § 13.10） |
| 範圍 | 角色獨立 |
| 同時上限 | **3 張**，所有城鎮共用；不佔冒險任務的 4 個名額（`36-quest-system.md` § 36.6.2） |
| 判定 | 全部在 server（`97-selfhosted-server.md` § 97.2） |

## 53.1 契約清單

| 項目 | 規則 |
|---|---|
| 份數 | 每個城鎮分部各一份，每份 **5 張**：普通怪契約 4 張、Boss 契約 1 張 |
| 存檔 | 清單存在角色身上，**登入不重抽**；只在定時更新（§ 53.4）時改變 |
| 區域池 | 該城鎮的冒險任務區域池（`36-quest-system.md` § 36.12.2）中，**區域最低等級 ≥ 30** 的區域 |
| Boss 池 | 該城鎮區域池內、**Boss 等級 ≥ 30** 的 Boss（篩選規則同 `36-quest-system.md` § 36.12.5） |
| 普通怪契約的對象 | **區域＋怪物名稱**：從區域池隨機抽一個區域，再從該區非 Boss 怪物中隨機抽一種 |
| Boss 契約的對象 | 一隻 Boss（以 Boss 名稱指定） |
| 擊殺數 | 普通怪 **50～100**、Boss **20～30**，範圍內整數均等抽 |
| 重複對象 | 生成時不排除；簽約時才檢查（§ 53.3） |

各城鎮的區域池（依 `36-quest-system.md` § 36.12.2 推導，以實際資料為準）：

| 城鎮 | 普通怪區域 | Boss |
|---|---|---|
| 薄暮村 | 雪原地帶、雪原地帶深處、象牙塔 1～5F | 試煉飛龍、雪地之主、象牙塔惡魔 |
| 艾爾薩斯 | 妖魔森林、腐葉林道、妖魔祭壇、遠古戰場、朦朧洞窟 1～3F、遠古地監 1～9F | 朦朧蛇魔、遠古騎士 |
| 瓦爾登 | 明鏡森林、幻光湖畔、碎鏡深林、遠古戰場、水下監獄 1～4F、遠古地監 1～9F | 深海獄王、遠古騎士 |
| 灰脊 | 遠古戰場、龍之谷外圍、龍之谷地表、龍谷地間 1～7F、百柱塔 1～100F、遠古地監 1～9F | 安塔巨龍、百柱塔十隻 Boss、遠古騎士 |

## 53.2 價格

定價等級：普通怪契約取**區域最低等級**，Boss 契約取 **Boss 等級**（`27-drop-table.md` § 27.5）。

| 定價等級 | 契約價格 | 加購「掉兩次取比較好」 |
|---|---|---|
| ≤ 29 | 不產生契約 | — |
| 30～39 | 30,000 | 200,000 |
| 40～49 | 50,000 | 300,000 |
| 50～59 | 60,000 | 400,000 |
| 60～80 | 70,000 | 500,000 |

- 價格由 server 依契約內容決定，client 只送契約 id 與是否加購
- 不套用全域金幣倍率

## 53.3 簽約、放棄、完成

| 項目 | 規則 |
|---|---|
| 簽約 | 在懸賞分頁選一張，勾選是否加購，一次付清 |
| 簽約條件 | 金幣足夠、已簽未滿 3 張、沒有同對象的已簽契約，三者皆須滿足；任一不符時按鈕停用並寫出原因 |
| 同對象 | 普通怪契約：區域與怪物名稱皆相同；Boss 契約：同一隻 Boss |
| 補位 | 簽走的那一格**留空**，到下次更新（§ 53.4）才補 |
| 放棄 | 隨時可放棄，**不退款**；入口在懸賞分頁與任務追蹤視窗 |
| 完成 | 擊殺數達標即移除，無獎勵、無貢獻 |
| 跨城鎮 | 已簽契約在任何城鎮都能查看與放棄（同 `36-quest-system.md` § 36.12.4） |

## 53.4 定時更新

- 每天 **00:00、06:00、12:00、18:00**（server 當地時間）更新，四個城鎮的清單整份重新生成（5 張，含留空的格子）
- 判定：清單的生成時間早於最近一個更新時刻即重新生成；離線期間經過的更新時刻，於下次載入角色時處理，只生成一次
- 沒有手動刷新，不消耗貢獻
- 已簽契約不受影響

## 53.5 契約效果

### 53.5.1 生效條件

- 角色為**一人隊伍**時生效（`97-selfhosted-server.md` § 97.7.1）
- 組隊期間**暫停**：不保證詞綴、不掉兩次、不計擊殺數；離隊後恢復，擊殺數保留

### 53.5.2 對象判定

| 類型 | 判定 |
|---|---|
| 普通怪契約 | 所在區域 = 契約區域，**且**怪物名稱 = 契約怪物 |
| Boss 契約 | Boss 名稱 = 契約 Boss |

### 53.5.3 保證強化詞綴

契約對象於契約生效中生成時，`25-monster-system.md` § 25.12.1 擲到「不強化」者**改為 1 個詞綴**；
2～4 個詞綴的區段與等級開放不變。詞綴從可用池抽取的規則照舊（§ 25.12.2）。

### 53.5.4 擊殺計數

契約生效中擊殺契約對象即 +1，不看該怪物生成時契約是否已生效。

### 53.5.5 掉兩次取比較好（加購）

有加購的契約，生效中擊殺契約對象時，下列掉落各判定兩次：

| 掉落 | 規則 |
|---|---|
| 道具（主掉落表、印記、職業技能書、Boss 共通增益藥水） | 每一條目擲兩次，**任一次命中即掉**；數量照單次判定 |
| 金幣 | 數量擲兩次，**取較高者** |
| 裝備 | 是否掉落同道具規則；命中後模板只抽一次，**實例生成兩次**，依 § 53.6 留一件。Boss 的各階級裝備條目各自套用 |

- 第一次判定與原本擊殺相同（完整掉寶倍率，`27-drop-table.md` § 27.1）；
  **第二次判定不乘 Pressure 掉落倍率**（`26-spawn-pressure.md` § 26.3），其餘因子相同
- **不適用**：天賦格（`27-drop-table.md` § 27.9）、冒險任務與職業任務的任務收集物

## 53.6 裝備比較

### 53.6.1 設定

設定存在角色身上，在懸賞分頁編輯，所有契約共用：

| 設定 | 內容 |
|---|---|
| 偏好詞綴清單 | 玩家勾選的詞綴（一般詞綴與特殊詞綴皆可），存詞綴 id |
| 比較條件 | 下表六條的**順序**與**開關**；預設依下表順序、全部開啟 |

### 53.6.2 比較條件

依設定順序逐條比較，分出勝負即停：

| 條件 | 勝出者 |
|---|---|
| 本角色穿得起的 | 符合者（定義同 `49-village-script.md` § 49.4） |
| 偏好詞綴條數 | 命中偏好詞綴清單的條數較多者；清單為空時視為相同 |
| 最高詞綴階級 | 最高階級較高者；相同時比該階級的條數 |
| 詞綴階級加總 | 加總較高者 |
| 安定值 | 安定值較高者；相同時比隨機額外防禦（`06-equipment.md` § 6.10、§ 6A.8.8） |
| 詞綴區間位置加總 | 各詞綴「(未吃品質的數值 − 該階級下限) ÷ (上限 − 下限)」的加總較高者（同 `13-town.md` § 13.13.1 位置條） |

- 階級計算：特殊詞綴（免疫類）與額外屬性詞綴**視為 T5**；T7 獨有詞綴與隨機技能不計
- 區間位置只算有 Tier 的詞綴
- 開啟的條件全部相同 → 留第一次生成的那件

## 53.7 介面

| 位置 | 內容 |
|---|---|
| 懸賞分頁頂部 | 城鎮分部標籤、「已簽 X/3」、下次更新時刻、比較設定入口 |
| 契約卡片 | 對象（Boss 契約標明 Boss）、區域、擊殺數、價格、加購勾選與合計金額、簽約按鈕 |
| 留空的格子 | 「已簽約，下次更新補上」 |
| 已簽契約 | 列在分頁內，顯示進度與是否加購，有「放棄」按鈕 |
| 任務追蹤視窗 | `[懸賞]` 標籤；對象、區域、進度（高亮）、是否加購；組隊時標示「暫停」；可放棄（`36-quest-system.md` § 36.10.3） |

對象、區域、怪物名稱的高亮規則同 `36-quest-system.md` § 36.10.2。

## 53.8 資料

存於 `character_prefs`（`18-data-schema.md` § 18.6）：

| 欄位 | 內容 |
|---|---|
| `bountyBoards` | 城鎮 id → 5 格（契約或空格）與生成時間 |
| `bountyContracts` | 已簽契約（最多 3 張） |
| `bountyCompare` | 偏好詞綴 id 清單、比較條件順序與開關 |

契約：

| 欄位 | 說明 |
|---|---|
| `id` | 契約 id |
| `kind` | `monster`／`boss` |
| `areaId` | 契約區域（Boss 契約為 Boss 所在區域） |
| `monsterName` | 對象名稱（同 `36-quest-system.md` § 36.11 以名稱判定） |
| `targetKills` | 擊殺數 |
| `kills` | 已擊殺數（已簽契約才有） |
| `priceLevel` | 定價等級 |
| `takeBetter` | 是否加購（已簽契約才有） |

價格不存契約內，由 `priceLevel` 查 § 53.2。
