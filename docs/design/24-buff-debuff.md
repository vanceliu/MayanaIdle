# 24. Buff/Debuff 系統

> 本文件定義角色與怪物共用的狀態效果系統，涵蓋持續時間、疊加規則、控場機制、解除手段與 UI 顯示。

---

## 24.1 系統概述

角色和怪物共用同一套效果（Effect）架構。效果分為：

| 分類 | 目標 | 範例 |
|------|------|------|
| Buff | 角色 | 精準射擊（命中+3）、火矢附魔（火傷害+15）、鋼鐵護盾（減傷20%） |
| Debuff（對怪物） | 怪物 | 暈眩（停止攻擊）、流血（DoT）、毒（DoT） |
| Debuff（對角色） | 角色 | 中毒、流血、詛咒、虛弱、減速、暈眩 |

**重要**：角色與怪物皆可被施加 debuff，系統為雙向設計。

---

## 24.2 效果資料結構

```typescript
interface ActiveEffect {
  id: string;              // 效果實例 ID（UUID）
  sourceSkillId: string;   // 來源技能 ID（用於互蓋判定）
  category: string;        // 分組 key（同 category 互蓋）
  type: 'buff' | 'debuff';
  target: 'player' | 'monster';

  // 效果內容（以下至少一項）
  modifiers?: StatModifier[];    // 數值修正
  dot?: DotEffect;               // 持續傷害
  hot?: HotEffect;               // 持續回復
  stun?: boolean;                // 控場（暫停攻擊）
  invincible?: boolean;          // 無敵（完全免疫傷害）
  shieldRemaining?: number;      // 護盾剩餘可吸收量（受擊遞減）
  special?: string;              // 特殊效果 key

  // 時間
  startTime: number;       // 生效時間戳（ms）
  duration: number;        // 持續時間（ms）

  // 觸發條件標記
  tags: string[];          // e.g. ['stunned', 'bleeding', 'poisoned']
}

interface StatModifier {
  stat: string;            // 'hit' | 'defense' | 'attack' | 'critRate' | 'critDmg' | 'evasion' | 'damageReduction' ...
  value: number;           // 數值
  isPercent: boolean;      // true = 百分比加成, false = 固定值
}

interface DotEffect {
  damage: number;          // 每次傷害
  element: ElementType;    // 傷害屬性
  interval: number;        // 傷害間隔（ms），通常 1000
  totalDuration: number;   // DoT 總持續時間（ms）
}

interface HotEffect {
  amount: number;          // 每次回復量
  interval: number;        // 回復間隔（ms），通常 1000
}
```

## 24.3 疊加與互蓋規則

### 24.3.1 Buff（同 category 互蓋）

同一個 `category` 的 buff，後施放的覆蓋前者（刷新持續時間與效果數值）。

**Category 分組範例：**

| category | 包含技能 |
|----------|----------|
| `accuracy` | 精準射擊、鷹眼、精準打擊 |
| `fire-enchant` | 火矢附魔 |
| `defense-buff` | 鋼鐵護盾、魔法盔甲、高級魔法盔甲 |
| `protect-shield` | 保護罩（獨立 category，可與魔法盔甲並存） |
| `weapon-bless` | 祝福武器、祝福魔法武器 |
| `speed` | 綠色藥水（攻速+33%, 180s）、強化綠色藥水（攻速+33%, 900s）、加速術（攻速+33%, 600s）、強化加速術（攻速+40%, 600s）— 四者互斥，後者覆蓋前者 |
| `sanctuary` | 聖域、神聖領域（同類互蓋，後施放覆蓋前者） |
| `crit-buff` | 致命一擊 |
| `cd-reduction` | 冷卻縮減、強化冷卻縮減（互斥，後施放覆蓋前者） |
| `element-boost` | 元素增幅 |
| `holy-shield` | 聖光護盾 |
| `evasion` | 煙霧彈 |
| `poison-enchant` | 淬毒 |
| `atk-down` | 挑釁怒吼（騎士 4）、詛咒（基礎 7）—— 皆為「目標攻擊力 -20%」，同 category 互蓋 |
| `defense-down` | 護甲崩壞（基礎 7，-15%/15s）、極冰封印（基礎 10，-20%/10s）—— 同 category 互蓋 |
| `vengeance` | 復仇之刃（騎士 5，依殘血給自身攻擊力加成） |
| `backstab` | 背刺（盜賊 5，自身攻擊力 +50%） |
| `invincible` | 絕對屏障（基礎 10，無敵 10s） |
| （無 category） | 敏捷提升（基礎 4）、力量提升（基礎 6）—— 不互斥，可與任何 buff 並存 |

### 24.3.2 DoT（獨立計時，不可刷新）

- **流血**：效果存續期間不可重新施加。流血結束後才能再上流血。
- **毒**：效果存續期間不可重新施加。毒結束後才能再上毒。
- 不同類型的 DoT 可以同時存在（流血 + 毒 同時生效）。

### 24.3.3 控場（暈眩）

- 暈眩期間不可重複暈眩（效果未結束前不可刷新）。
- Boss 特殊規則見 § 24.5。
- 角色暈眩抵抗見 § 24.10.3。

## 24.4 角色 Debuff 系統

怪物攻擊角色時，有機率觸發對角色的 debuff。

### 24.4.1 Debuff 類型定義

| Debuff | 類型 | 效果 | 持續時間 | 疊加規則 | tag |
|--------|------|------|----------|----------|-----|
| 中毒 | DoT | 每秒造成 `怪物攻擊力 × 5%` 傷害 | 10s | 不可刷新，結束後才能再上 | `poisoned` |
| 流血 | DoT | 每秒造成 `怪物攻擊力 × 8%` 傷害 | 10s | 不可刷新，結束後才能再上 | `bleeding` |
| 詛咒 | 減益 | 防禦力 -20% | 8s | 後施放覆蓋（刷新時間） | `cursed` |
| 虛弱 | 減益 | 攻擊力 -20% | 8s | 後施放覆蓋（刷新時間） | `weakened` |
| 減速 | 減益 | 攻擊速度 -30% | 6s | 後施放覆蓋；與加速互相抵銷（§ 24.4.6） | `slowed` |
| 暈眩 | 控場 | 無法行動（攻擊計時器暫停） | 1.5s | 不可刷新，結束後才能再上 | `stunned` |

### 24.4.2 觸發機制

怪物普攻命中角色時，依據怪物的 debuff 能力判定是否觸發：

```
步驟 1：觸發判定
  觸發機率 = 怪物基礎觸發率 × (1 - 免疫率)

步驟 2：魔法抗性抵抗（僅 詛咒／虛弱／減速）
  抵抗機率 = min(魔法抗性, 100)%
  抵抗成功 → 該 debuff 不施加
```

- 怪物基礎觸發率：依怪物類型，10%~25%
- 免疫率：來自免疫詞綴（100% 免疫該類型 debuff）或神聖領域 buff
- 每次攻擊僅觸發一種 debuff（若怪物有多種 debuff 能力，依序判定，命中即停）

### 魔法抗性抵抗

| 項目 | 規則 |
|---|---|
| 適用 debuff | **詛咒、虛弱、減速** 三種 |
| 不適用 | 中毒、流血（物理 DoT）、暈眩 —— 只能靠免疫／抵抗詞綴 |
| 抵抗機率 | `min(魔法抗性, 100)%`。0% 必中，100% 完全免疫 |
| 判定時機 | 在基礎觸發率**命中之後**才判定 |
| 是否消耗判定 | **會**。被抵抗仍視為該次攻擊的 debuff 判定已用掉（§ 25.9.2 命中即停） |

> **與免疫詞綴的分工**：兩套機制**不重疊**，各自負責不同的 debuff。
> 魔抗可抵抗的三種（詛咒／虛弱／減速）**沒有**免疫詞綴；
> 魔抗擋不住的三種（中毒／流血／暈眩）才由詞綴處理。
> 兩者的判定時機也不同：免疫詞綴讓觸發率**直接歸零**，判定會繼續往下一種 debuff；
> 魔法抗性則是在命中後才擋下，**會消耗該次判定**。

魔法抗性的來源與數值見 `21-combat-formula.md` § 21.16。

### 24.4.3 Debuff Category 分組

| category | 包含效果 | 說明 |
|----------|----------|------|
| `dot-poison` | 中毒 | 獨立計時，不可刷新 |
| `dot-bleed` | 流血 | 獨立計時，不可刷新 |
| `curse` | 詛咒 | 後者覆蓋前者 |
| `weaken` | 虛弱 | 後者覆蓋前者 |
| `slow` | 減速 | 後者覆蓋前者 |
| `stun` | 暈眩 | 獨立計時，不可刷新 |

- 不同 category 的 debuff 可同時存在（例：中毒 + 詛咒 + 減速 同時生效）
- 同 category 的 debuff 依疊加規則處理

### 24.4.4 DoT 傷害計算

```typescript
interface PlayerDotEffect {
  damage: number;          // 每秒傷害 = 怪物攻擊力 × 係數
  element: 'poison' | 'physical';  // 中毒=poison, 流血=physical
  interval: 1000;          // 每 1000ms 結算一次
  totalTicks: number;      // 總跳數（中毒 10 跳、流血 10 跳）
  sourceMonster: string;   // 來源怪物 ID（用於傷害數值計算）
}
```

- DoT 傷害無視防禦（直接扣 HP）
- DoT 不會觸發爆擊
- DoT 可以殺死角色（HP 歸零觸發死亡流程）

### 24.4.6 減速與加速互相抵銷

減速（debuff）與加速（`speed` category buff，含綠色藥水、強化綠色藥水、加速術、強化加速術）互為剋制，兩者不會同時存在：

| 情境 | 結果 |
|------|------|
| 施加減速時角色身上有加速 | 消除加速，**減速不生效** |
| 施加加速時角色身上有減速 | 解除減速，**加速不生效** |
| 兩者皆無 | 照常施加 |

- 兩個方向都會消耗來源：怪物的減速觸發被「擋掉」一次、玩家的加速藥水/技能也被「用掉」一次
- 因此**減速不需要淨化藥水**，以加速效果對沖即可（見 § 24.10.1）

### 24.4.5 實作定義補充

以下為文件原本未明確界定、實作時確定的規則：

| 項目 | 定義 |
|------|------|
| 「怪物攻擊力」取值 | `(attackMin + attackMax) / 2`，DoT 傷害於施加當下快照，最低 1 點 |
| 角色施加於怪物的 DoT「物理傷害」取值 | 角色基礎物理傷害（未計技能威力、暴擊與怪物防禦），於施加當下快照，最低 1 點。適用裂傷斬（§ 23.3）與淬毒（§ 23.7） |
| 虛弱套用位置 | 作用於**所有乘區、爆擊與防禦減傷之後的最終傷害**（`最終傷害 × 0.8`），見 `21-combat-formula.md` § 21.11 |
| 虛弱作用範圍 | 僅影響**依物理公式計算**的傷害：普通攻擊、多段物理技能（三連射）、以及以基礎物理傷害快照的 DoT（裂傷斬／淬毒）。走技能公式的傷害一律不受影響，**包含標示「物理傷害」的職業技能**（盾擊／裂傷斬／挑釁怒吼／復仇之刃／背刺，見 `23-class-magic.md` § 23.1.1） |
| 減速與攻速 buff 疊算 | 兩者的 `attack_speed` 百分比相加後再換算攻擊間隔（例：+30% buff 與 -30% 減速互相抵銷） |
| 詛咒作用範圍 | 影響最終防禦力，因此同時降低減傷與「防禦溢出迴避」 |

### 24.4.7 持續回復（HoT）

由 buff 的 `hotAmount` 產生，與 DoT 共用 1000ms 結算 tick。

| 來源 | 每秒回復 | 持續 |
|---|---|---|
| 聖域（基礎 9） | 20 | 10s |

- 回復量不超過有效最大 HP（含 `+最大HP` 詞綴）
- HP 歸零（死亡）時不回復
- 多個 HoT 同時存在時各自加總後一次結算
- 不受「補血效果」詞綴影響（該詞綴僅作用於治癒技能）

---

### 24.4.8 無敵（invincible）

| 來源 | 持續 |
|---|---|
| 絕對屏障（基礎 10） | 10s |

- 無敵期間**完全免疫傷害**：怪物普攻、技能傷害、DoT 皆為 0
- 迴避與格擋判定直接跳過（傷害本來就是 0）
- 不影響 debuff 的施加判定（仍可被上狀態，只是不受傷）

---

### 24.4.9 護盾吸收（shield absorb）

| 來源 | 吸收量 | 持續 |
|---|---|---|
| 聖光護盾（牧師 1） | 100 | 20s |

- 施放時以 `shieldRemaining` 記錄剩餘可吸收量，**受擊時遞減**
- 結算順序：**所有減傷之後、實際扣血之前**（見 `21-combat-formula.md` § 21.5）
- 同時吸收怪物攻擊與 DoT 傷害
- 剩餘量歸零時該 buff **立即消失**（護盾破裂），溢出的傷害照常扣血
- 持續時間到期時即使仍有剩餘量也一併消失

## 24.5 控場機制

### 24.5.1 暈眩效果

暈眩生效時：
1. **暫停目標攻擊計時器** — 暈眩期間不會攻擊
2. **標記 tag `stunned`** — 其他技能可判定「對暈眩目標額外效果」

角色暈眩：攻擊計時器暫停，無法使用技能、藥水、回城卷軸
怪物暈眩：攻擊計時器暫停

### 24.5.2 觸發條件系統

技能可定義觸發條件，根據目標身上的 tags 給予額外效果：

```
例：「對暈眩目標傷害 +50%」→ 檢查目標 tags 包含 'stunned'
例：「對流血目標爆擊率 +20%」→ 檢查目標 tags 包含 'bleeding'
例：「對中毒目標額外傷害」→ 檢查目標 tags 包含 'poisoned'
```

## 24.6 Boss 控場免疫

| 規則 | 說明 |
|------|------|
| Boss 可被控場 | 暈眩等控場效果對 Boss 正常生效 |
| 免疫冷卻 | 被控場後，10 秒內免疫任何控場效果 |
| 小怪 | 無免疫機制，控場正常生效 |

判定流程：
1. 對 Boss 施放控場技能
2. 檢查 `ccImmuneUntil` 是否 > 當前時間
3. 若免疫中 → 控場不生效（傷害照常計算）
4. 若非免疫 → 控場生效，並設定 `ccImmuneUntil = 當前時間 + 10000`

## 24.7 戰鬥迴圈整合

每幀（frame-based）的處理順序：

1. **清除過期效果** — 移除超過 duration 的效果（每幀檢查）
2. **DoT 傷害計時** — 累積 deltaMs，每 1000ms 結算一次 DoT 傷害
3. **玩家 FSM tick** — 狀態機更新（idle/chasing/attacking），攻擊時執行腳本決定技能
4. **怪物 FSM tick** — 每隻怪物獨立更新，檢查 stun debuff，暈眩中跳過攻擊
5. **事件處理** — 收集 ArpgEvent（player_attack, monster_attack, move_to）更新狀態

## 24.8 UI 顯示

### 24.8.1 角色 Buff 顯示

- **位置**：左側面板 `StatusPanel`（HP/MP/EXP bar）正下方，`LeftPanelTabs` 之上
- **組件**：`<BuffBar>`
- **顯示方式**：水平 icon bar（單排）
  - 每個 buff 以 32×32 icon 呈現
  - icon 右下角覆蓋剩餘秒數（≥60s 顯示 `M:SS` 格式，<60s 顯示秒數）
  - 同時顯示上限 8 個，超過顯示 `+N` 提示
  - 剩餘 <5 秒時 icon 閃爍（CSS `blink` animation）
- **Tooltip**：hover icon 顯示浮動面板
  - 效果名稱
  - 效果描述（數值修正、DoT 傷害等）
  - 剩餘時間（精確到秒）
  - 來源技能名稱
- **計時方式**：時間戳制
  - 效果存儲 `startTime`（生效時間戳 ms）+ `duration`（持續時間 ms）
  - UI 層 `<BuffBar>` 內部以 `setInterval(1000)` 每秒刷新剩餘時間顯示
  - 過期清除由戰鬥 tick 負責（§ 24.6 步驟 1），UI 不做清除

### 24.8.2 角色 Debuff 顯示

- **位置**：BuffBar 內，與 Buff 同排但以不同框色區分
- **框色規則**：
  - Buff（正面效果）：藍色外框 `#3B82F6`
  - Debuff（負面效果）：紅色外框 `#EF4444`
- **顯示方式**：同 Buff，32×32 icon
- **Debuff icon**：
  - 中毒：綠色骷髏 / 毒瓶
  - 流血：紅色血滴
  - 詛咒：紫色詛咒符號
  - 虛弱：下降箭頭
  - 減速：蝸牛 / 慢速符號
  - 暈眩：旋轉星星
- **Tooltip**：顯示效果名稱、剩餘時間、傷害/減益數值

### 24.8.3 怪物列表與怪物 Debuff 顯示

怪物 debuff 顯示在**地圖 canvas 上方置中的浮動怪物列表**內，不畫在 Pixi sprite 上。
（原規格為「地圖上怪物 sprite 血量條下方」，因 sprite 尺寸過小無法容納 icon 與秒數而改置於此列表。）

- **位置**：地圖 canvas 內、上方置中浮動（`.monster-list-overlay`）
- **組件**：`<MonsterListOverlay>`
- **顯示範圍**：地圖上現存的怪全部顯示，一隻一張卡片（同時存在上限 10 隻，見 `99-ai-constraints.md` 第 34 條），順序依生成順序
- **卡片內容**（僅這三項，不顯示等級與 HP 數值）：
  - 怪物名稱
  - HP 條（百分比長度）
  - Debuff icon 列
- **Boss 卡片**：使用特殊底色（紫色系）與紫色外框區分
- **攻擊目標**：玩家目前鎖定攻擊的怪（`PlayerCombatContext.targetMonsterId`）卡片加金色外框＋光暈高亮；無目標時不高亮任何卡片
- **Debuff icon 列**：
  - 24×24 icon（紅框，同 § 24.8.2 debuff 框色）＋下方剩餘秒數
  - 同時顯示上限 4 個，超過顯示 `+N`
  - 剩餘 <5 秒時閃爍（同 § 24.8.1）
  - **Tooltip**：hover 顯示效果名稱、描述、剩餘時間、來源技能名稱
- **資料流**：怪物實體數值由 Pixi ticker 持有，每 100ms 節流發佈唯讀快照至 `monsterHudStore`（`entries` + `targetId`）供 UI 訂閱；內容未變則不寫入 store
- **滑鼠事件**：列表本身不吃滑鼠事件（不擋地圖點擊移動），僅 debuff icon 區域開啟 hover

### 24.8.4 Icon 資源

- **主力素材**：[Game-icons.net](https://game-icons.net)（CC BY 3.0，4180+ 遊戲專用 SVG）
- **UI 補充**：Lucide Icons（ISC License，通用 UI icon）
- **整合方式**：下載 SVG 至 `client/src/assets/icons/`，透過 `<GameIcon>` 統一元件渲染
- **顏色控制**：SVG fill 以 CSS currentColor 驅動，適配 dark fantasy 主題

### 24.8.5 戰鬥日誌整合

- buff 施加時：`「施放 精準射擊（命中+3, 300s）」`
- debuff 施加時：`「盾擊命中！目標暈眩 2s」`
- debuff 被免疫時：`「目標免疫控場！」`
- DoT 傷害時：`「流血傷害 10」`（不需每秒都顯示，可改為首次 + 結束提示）

## 24.10 角色 Debuff 解除手段

### 24.10.1 解除道具

| 道具 | 效果 | 價格 | 取得方式 | 重量 |
|------|------|------|----------|------|
| 解毒藥水 | 立即解除中毒 | 50G | 雜貨店 | 2 |
| 止血繃帶 | 立即解除流血 | 50G | 雜貨店 | 2 |
| 淨化藥水 | 解除詛咒/虛弱（全解） | 500G | 雜貨店 | 3 |

**使用規則：**
- 戰鬥中、探索中皆可使用
- 無冷卻時間
- 若角色無對應 debuff，不可使用（顯示「沒有需要解除的狀態」）
- 暈眩狀態下無法使用任何道具
- **減速無解除道具**：以加速效果對沖（§ 24.4.6）

### 24.10.2 自然消退

所有 debuff 皆有持續時間，時間到自動消失：

| Debuff | 持續時間 |
|--------|----------|
| 中毒 | 10 秒 |
| 流血 | 10 秒 |
| 詛咒 | 8 秒 |
| 虛弱 | 8 秒 |
| 減速 | 6 秒 |
| 暈眩 | 1.5 秒 |

### 24.10.3 免疫詞綴

防具可獲得免疫詞綴，完全免疫特定類型的 debuff：

| 詞綴名 | 效果 | 適用部位 | 取得方式 |
|--------|------|----------|----------|
| 毒免疫 | 免疫中毒 | 防具 | Lv.31+ 區域掉落 |
| 流血免疫 | 免疫流血 | 防具 | Lv.31+ 區域掉落 |
| 暈眩抵抗 | 暈眩時間 -50% | 防具 | Lv.41+ 區域掉落 |

- 免疫詞綴為**特殊詞綴**，無 Tier 分級（固定效果）
- **詛咒／虛弱／減速無免疫詞綴**，改由魔法抗性抵抗（§ 24.4.2）
- 詳見 `07-affix.md` § 7.10

### 24.10.4 旅館解除

回到城鎮旅館時：
- 選擇「休息」可解除所有 debuff
- 同時恢復 HP/MP

## 24.11 擴充預留

以下機制目前不實作，但架構需支援未來擴充：

- **驅散/淨化**：移除目標身上特定 buff/debuff
- **免疫負面狀態**：神聖領域（牧師 5 級技能）免疫負面狀態
- **嘲諷**：改變怪物攻擊目標（多人場景），單人場景下為「確保怪物攻擊自己」
