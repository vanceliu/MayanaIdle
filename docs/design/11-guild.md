# 11. 公會系統

> 只存在於開放世界；單機世界不畫公會 UI、不放公會 NPC（`97-selfhosted-server.md` § 97.1）。
> 判定一律在 server，資料存 SQLite（`18-data-schema.md` § 18.12）。

## 11.1 功能範圍

- 建立／解散（公會 NPC）
- 邀請、加入、踢人、退出
- 成員名單（在線／離線）
- 公會聊天（`97-selfhosted-server.md` § 97.7.2）
- 公會倉庫（§ 11.8）
- 公會名稱顯示（§ 11.7）

## 11.2 暫不製作的公會功能

目前不要設計：

- 公會 Boss
- 公會科技
- 公會商店
- 公會戰
- 公會副本

除非使用者之後要求。

公會徽章是否製作未定案（`97-selfhosted-server.md` § 97.10），定案前不實作。

## 11.3 建立

| 項目 | 規則 |
|---|---|
| 地點 | 公會 NPC（`13-town.md` § 13.2.1），四座城鎮皆有 |
| 等級 | 角色 Lv10 以上 |
| 身分 | **必須無公會** |
| 費用 | 免費 |
| 建立者 | 成為盟主 |

## 11.4 名稱

| 項目 | 規則 |
|---|---|
| 允許字元 | 同角色名稱（`19-account-character.md` § 19.4） |
| 禁止 | 同角色名稱 |
| 長度 | 同角色名稱：寬 2 ~ 12（中文佔 2、其餘佔 1），最多 6 個中文或 12 個半形字 |
| 唯一性 | 本服唯一；比對鍵同角色名稱（NFC 正規化後轉小寫），由 SQLite `guilds.name_key` 唯一索引把關 |
| 改名 | 不可 |
| 解散後 | 名稱立即釋放 |

## 11.5 成員與人數上限

| 項目 | 規則 |
|---|---|
| 公會數 | **每個角色最多屬於一個公會**，盟主也是；已有公會者不可建立、不可被邀請、不可接受邀請 |
| 盟主 | 固定為建立者，**不可轉讓** |
| 人數上限 | 盟主魅力（含裝備）× 2，人數含盟主 |
| 上限檢查時機 | 只在邀請送出與接受邀請當下；上限因盟主換裝而低於現有人數時，現有成員保留，只是不能再邀人 |

## 11.6 邀請、退出、踢人、解散

| 項目 | 規則 |
|---|---|
| 邀請者 | 只有盟主 |
| 邀請入口 | 社群視窗「在線」分頁的在線名單（`97-selfhosted-server.md` § 97.7.5）；「公會」分頁的**角色名稱輸入格**（大小寫不分） |
| 邀請對象 | 在線、無公會；無等級限制 |
| 加入 | 對方確認後加入；邀請 60 秒逾期（同組隊） |
| 退出 | 成員可隨時退出，立即生效；**盟主不可退出**，只能解散 |
| 踢人 | 只有盟主，需二次確認（該成員那一列換成「確定踢除／取消」），確認後立即生效 |
| 重新加入 | 退出或被踢後無冷卻 |
| 解散 | 只有盟主，在公會 NPC 操作，需二次確認；全體成員立即變為無公會，公會倉庫一併消失（§ 11.8） |
| 刪除角色 | 成員：自動移出；盟主：公會解散 |
| 結果通知 | 加入、退出、被踢、解散寫進當事人的系統紀錄 |

## 11.7 顯示

| 位置 | 內容 |
|---|---|
| 懸停名稱（地圖） | 滑鼠移到角色上才顯示，不常駐。兩行：上行金色、小一號的《公會名》，下行角色名；無公會只有角色名（`16-tech-frontend-architecture.md` § 32.3.2）。地圖只渲染自己與隊友（`97-selfhosted-server.md` § 97.7.1），因此只看得到這些人的；手機無懸停，改由社群視窗查看 |
| 社群視窗「在線」分頁 | 在線名單每列附公會名稱；無公會不顯示 |
| 社群視窗「公會」分頁 | 公會名稱、人數／上限、成員名單（每人一行：名稱、職業、等級；離線不寫字，整列變暗）、以名稱邀請（盟主）、踢人（盟主）、退出（成員）；無公會時顯示「尚未加入公會」 |
| 公會分頁的成員列動作 | 對自己以外的成員：密語、交易、組隊邀請，只對在線成員可按；已是同隊伍的不顯示組隊邀請，組隊資格同 `97-selfhosted-server.md` § 97.7.3 |

社群視窗規格見 `97-selfhosted-server.md` § 97.7.5。

### 盟主標示（公會分頁）

| 項目 | 規則 |
|---|---|
| 位置 | 固定排第一列 |
| 標記 | 名稱前金色 `♛`（隊長是 `★`，兩者不可共用） |
| 名稱 | 金色 |
| 其餘成員排序 | 在線優先，再依加入時間 |

## 11.8 公會倉庫

城鎮倉庫面板的第三個分頁，排在帳號倉庫、個人倉庫之後（`13-town.md` § 13.8）。

| 項目 | 規則 |
|---|---|
| 存取權限 | 公會全體成員可存可取，物品與金幣相同 |
| 可存放 | 同帳號倉庫：裝備、素材、消耗品、印記；新手裝與天賦格不收 |
| 容量 | **200 格**。一件裝備 1 格；同種可堆疊道具合計 1 格；金幣不佔格 |
| 金幣 | 獨立金幣欄，無上限 |
| 存入超過容量 | 放得下的依序存入，放不下的留在背包，提示「公會倉庫已滿（200/200）」 |
| 取出 | 背包放不下不可取出（`35-inventory-constraints.md` § 35.3） |
| 同時存取 | server 依序執行；畫面上的東西已被其他成員取走時，取出失敗並提示「已被其他成員取走」，畫面刷新為最新內容 |
| 內容同步 | **只在需要時送出**：打開公會倉庫分頁時、自己存取之後。其他成員的存取不推送；切離分頁或關閉倉庫即釋放 |
| 存取後存檔 | 背包與倉庫兩邊立即落地（同交易，`97-selfhosted-server.md` § 97.4 強制 flush） |
| 無公會 | 分頁顯示但變暗，點擊無作用 |
| 單機世界 | 不顯示分頁（`97-selfhosted-server.md` § 97.1） |
| 解散 | 倉庫內物品與金幣隨公會一併消失（含盟主刪除角色）；公會 NPC 的解散確認文字註明此事 |
| 補給天賦 | 不碰公會倉庫，只能手動存取（`49-village-script.md` § 49.3） |
