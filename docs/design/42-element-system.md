## 42.2 元素克制（環狀）

```
火 → 風 → 地 → 冰 → 火
      光 ↔ 暗（互克）
      無：不克制也不被克制
```

| 攻擊屬性 | 克制對象 |
|---|---|
| 火 | 風 |
| 風 | 地 |
| 地 | 冰 |
| 冰 | 火 |
| 光 | 暗 |
| 暗 | 光 |
| 無 | 無克制 |

### 克制效果

**環狀克制（火→風→地→冰→火）：**
- 用克制屬性武器攻擊被克制屬性怪物：額外 +3 傷害
- 其他情況：+0

**光暗互克：**
- 光屬性武器打暗屬性怪物：額外 +3 傷害
- 暗屬性武器打光屬性怪物：額外 +3 傷害

**其他情況：**
- 屬性武器打無屬性怪物：+0
- 無屬性武器攻擊任何怪物：+0
- 屬性武器打非克制屬性怪物：+0
- 被克制屬性武器攻擊：+0

例：
- 火屬性武器打風屬性怪物 → 傷害 +3（克制）
- 風屬性武器打火屬性怪物 → +0（被克制，無懲罰）
- 光屬性武器打暗屬性怪物 → 傷害 +3（光暗互克）
- 火屬性武器打無屬性怪物 → +0
- 火屬性武器打冰屬性怪物 → +0（無克制關係）

## 42.3 傷害數字顏色規則

戰鬥中傷害數字飄動時，依據傷害類型顯示不同顏色：

| 類型 | 顏色 | 說明 |
|------|------|------|
| 治癒（角色/怪物） | 綠色 | 所有補血效果 |
| 一般傷害 | 白色 | 普通攻擊傷害 |
| 暴擊 | 亮黃色 + 加粗 | 暴擊傷害，加粗強調 |
| 屬性傷害 | 亮藍色 | **帶元素屬性的技能傷害**（不論是否觸發克制） |
| 物理技能傷害 | 淺灰色 | 無屬性技能造成的傷害 |
| 毒傷害 | 粉紅色 | 中毒持續傷害（DoT 共用此色） |
| 未命中 | 灰色 | 顯示 `Miss`，不顯示數值 |

## 42.4 投射物顏色規則

投射物顏色**只看攻擊的元素，不分敵我** —— 玩家與怪物的同元素攻擊是同一個顏色。
實作見 `client/src/pixi/ui/projectileStyle.ts`（顏色表與判定都在此，不可再散落到各組件）。

| 元素 | 顏色 |
|---|---|
| 火 | `0xff6600` 橙 |
| 冰 | `0x66ccff` 淺藍 |
| 風 | `0x66ff66` 綠 |
| 地 | `0xcc9933` 土黃 |
| 光 | `0xffffaa` 淡黃 |
| 暗 | `0x9933ff` 紫 |
| 無 | `0xffffff` 白 |

### 元素的判定來源

| 攻擊 | 取哪個元素 | 外型 |
|---|---|---|
| 玩家物理普攻（弓） | 附魔 buff 的元素；無附魔 → 無元素（白） | 箭矢 |
| 玩家弓技 | 附魔 buff 的元素；無附魔 → 技能元素 | 箭矢 |
| 玩家其他遠程技能 | 技能元素 | 彈丸 |
| 怪物遠程物理（弓箭手系） | **無元素 → 一律白色** | 箭矢 |
| 怪物遠程魔法（巫師／魔導系） | 該怪的 `element` | 彈丸 |

- **物理普攻沒有元素，所以是白色**：弓箭手是風屬性怪不代表箭矢是風屬性攻擊，
  元素只參與克制計算（§ 42.2），不會讓一發物理箭變成元素傷害
- 未定義或未知的元素一律退回白色，不會畫出無色投射物

## 42.5 設計原則

- 元素屬性與種族、體型三者獨立，自由組合
- 武器材質克制種族，元素克制元素，兩套系統並行
- 無屬性為中立選擇，不享受克制加成也不受克制懲罰
- 克制系統僅提供固定額外傷害（+3），不使用百分比加成
