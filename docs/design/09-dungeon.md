# 9. 副本與區域系統

## 9.1 副本設計原則

副本可以存在，但不要分類成金幣副本、經驗副本、裝備副本、材料副本。

副本應該像 ARPG 地城一樣，每個副本都有自己的主題、怪物、掉落與挑戰。

每個副本應包含：

- 副本名稱
- 進入條件
- 地圖主題
- 怪物池
- Boss，若需要
- 掉落池
- 稀有裝備
- 特殊材料
- 推薦等級
- 推薦戰力

AI 不應生成以下分類：金幣副本、經驗副本、裝備副本、材料副本。除非使用者之後重新要求。

## 9.2 大陸結構

Mayana 大陸以灰脊山脈為中心，東西兩側分屬瓦爾登聯邦與艾爾薩斯王國。

地圖整體劃分為五大區塊：

| 區塊 | 位置 | 陣營歸屬 | 建議等級 | 備註 |
|---|---|---|---|---|
| 新手中立區 | 東陣營西北 + 西陣營東北交會處 | 中立 | 1~30 | |
| 象牙塔 | 新手中立區正北方 | 中立 | 30~45 | 魔法書材料產地 |
| 艾爾薩斯領地 | 大陸西域 | 西陣營 | 30~50 | |
| 瓦爾登領地 | 大陸東域 | 東陣營 | 30~50 | |
| 龍之谷 | 灰脊山南方 | 中立 | 30~50 | |
| 灰脊山脈 | 大陸中央 | 中立 | 45+ | 高層以戰力為門檻 |

### 成長節奏說明

- 等級無硬上限，但經驗曲線設計使大多數玩家自然卡在 61~65 附近（見 `04-character.md` § 4.9）
- 前期（1~45）以等級成長為主要驅動力
- 後期（45+）以裝備詞綴、裝備品質、魔法書為主要成長來源
- 灰脊山脈的高階內容以戰力（裝備 + 魔法配置）為門檻，而非等級限制

### 副本架構

多層副本使用 Region + `floors[]` 結構，seed 的 area 欄位以 `${regionId}-${floor}f` 格式對應各層。百柱塔因每段有獨立通行卷軸機制，維持獨立 Region。

- 象牙塔：Region ID `ivory-tower`，seed area `ivory-tower-1f` ~ `ivory-tower-5f`（5 層）
- 龍谷地間：Region ID `dragon-valley`，seed area `dragon-valley-1f` ~ `dragon-valley-7f`（7 層）
- 遠古地監：Region ID `ancient-dungeon`，seed area `ancient-dungeon-1f` ~ `ancient-dungeon-9f`（9 層）
- 朦朧洞窟：Region ID `misty-cave`，seed area `misty-cave-1f` ~ `misty-cave-3f`（3 層）
- 水下監獄：Region ID `underwater-prison`，seed area `underwater-prison-1f` ~ `underwater-prison-4f`（4 層）
- 百柱塔：獨立 Region `hundred-pillar-1-10f` ~ `hundred-pillar-91-100f`（10 段，每段 10 層）

- 建議入場等級：45+

- 每 10 層設有 1 隻樓層王（10F, 20F, 30F ... 100F）
- 樓層王等級：52~60，依樓層遞增（見 `28-monster-stats.md` § 28.8）

| 樓層區段 | 怪物等級 | 說明 |
|---|---|---|
| 1~30F | 45~52 | 中階，等級成長為主 |
| 31~60F | 52~57 | 中高階，需強化裝備詞綴與魔法書 |

| 91~100F | 60 | 最高階，頂級裝備與完整魔法配置 |
| 樓層王（10F~90F） | 80 | 每 10 層 Boss |
| 100F 王 | 90 | 百柱塔最終 Boss |

#### 樓層通行機制

- 玩家從 1F 開始逐層向上攀爬
- 每 10 層為一個區段（1~10, 11~20, 21~30 ...）
- **入口區段 1~10F 需要「百柱塔 1F 通行卷軸」**，由雜貨店販售（2,000G），不掉落
  —— 爬塔從第一步就有成本，卷軸機制才是完整的節奏控制手段
- 11F 以上的通行卷軸則在前一區段內隨機掉落
  - 1~10F 掉落「百柱塔 11F 通行卷軸」
  - 11~20F 掉落「百柱塔 21F 通行卷軸」
  - 依此類推
- 卷軸為一次性消耗品，使用後傳送至對應樓層起點
- 每次要前往高層區段都需重新取得卷軸
- 玩家需囤積卷軸以維持高層攀爬節奏

## 9.10 設計原則

- 東西陣營區域在怪物強度上完全對等，差異僅在主題與視覺風格
- 所有區域不設陣營進入限制，任何玩家皆可前往
- 百柱塔為長期攻略內容，卷軸機制控制爬塔節奏
- 象牙塔為魔法書製作的專屬材料產地
- 區域等級重疊設計允許玩家依喜好選擇路線
- 同名怪物可出現在不同樓層或區域，強度根據所在地圖等級自動調整
- 掉落品跟隨地圖等級產生差異，高等級區域的同名怪物掉落更高階物品

## 9.11 區域環境主題對應

所有既有 area ID 與樓層數不變，靜態地圖依區域使用草原/高地/雪地/象牙塔/森林/沼澤/洞窟/水牢/戰場/遠古地監/龍谷/百柱塔（含冰塔、熔岩塔）等 theme。Theme 僅決定環境渲染與地形配方，不改變怪物池、掉落、等級或進入限制。

各主題的必用地形、佈局原型與設計約束見 `38-map-control.md` § 38.11、§ 38.12。地圖改版不得新增樓層或改變既有副本結構，也不得變動既有地圖的尺寸。
