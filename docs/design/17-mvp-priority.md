# 17. MVP 優先順序

## 17.1 第一階段：核心可玩（已完成）

優先完成：

- 建立角色
- 選擇職業
- 基礎地圖（PixiJS 渲染、tile-based）
- ARPG 即時戰鬥系統（角色/怪物 FSM、攻擊冷卻、視線判定）
- 怪物地圖生成（Pressure 機制、A* 尋路）
- 手動/自動戰鬥（戰鬥腳本系統）
- 怪物數量隨停留時間增加（上限 10 隻）
- 經驗與金幣掉落（每隻怪物死亡立刻結算）
- 基礎裝備掉落

## 17.2 第二階段：角色與裝備成長（已完成）

接著完成：

- 角色升級
- 職業技能學習規則
- 主動技能系統
- 裝備欄位
- 左手 / 右手規則
- 雙手武器佔用規則
- 詞綴插槽
- 詞綴 Tier
- 裝備品質 0% ~ 20%
- 鐵匠鋪提升品質

## 17.3 第三階段：地圖與城鎮系統（已完成）

完成：

- 地圖系統（完整大陸結構：6 Zone、19 Region、怪物分佈、掉落表）
- 地圖轉移 UI（區域間移動、進入條件檢查、副本層數切換）
- 城鎮 UI 框架（城鎮畫面 + NPC 列表 + 進出流程）
- 魔法學院（花金幣學 1~3 級、提交魔法書學 4~10 級）
- 雜貨店（買賣藥水 / 消耗品 / 回城卷軸 / 強化卷軸，回收 50%）
- 旅館（回復 HP / MP）
- 防具店（購買基礎防具、回收玩家裝備 50%）
- 武器店（購買基礎武器、回收玩家裝備 50%）
- 個人倉庫（存取裝備 / 材料 / 消耗品，持久化）
- 鐵匠鋪擴充（武器強化、防具強化、裝備製作）
- 印記師（詞綴升階、詞綴重骰、品質提升）
- 職業工會（提交技能書學職業魔法）
- 象牙塔掉落表（魔法書製作素材）
- 背包管理（6x34 grid 顯示、排序、丟棄物品）
- 使用者狀態（顯示 DPS、防禦力、技能加成、爆擊率、爆擊傷害、每次回復血量、每次回復魔量）

## 17.4 第四階段：任務系統與單人進階功能

完成：

- NPC 基本對話邏輯（對話樹、條件分支、狀態記憶）
- 任務系統框架（接取、追蹤、完成、獎勵發放）
- 職業任務（1~2 級技能書作為獎勵）
- 主線任務（引導玩家推進地圖）
- 支線任務（重複型 / 一次性）
- 高階技能書（3~5 級）加入特定怪物掉落表
- 任務 NPC 配置於各城鎮
- 選擇陣營（與 NPC、任務綁定）
- 成就系統
- 副本系統（擴充象牙塔、新增更多副本）
- 寵物系統

## 17.5 第五階段：多人與社交系統

完成：

- 帳號系統
- 交易系統 / 拍賣系統
- 公會聊天
- 排行榜
