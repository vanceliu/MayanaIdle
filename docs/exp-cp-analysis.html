MayanaIdle 練等 CP 值分析

以騎士（雙手劍路線）為基準，升級屬性以 STR 為主，裝備在安定值內

前提假設

  • 職業：騎士，STR 優先配點（初始 STR 14，Lv51+ 每級 +1 STR 直到 35）
  • 攻擊間隔：1200ms（無加速）/ 900ms（有綠色藥水）
  • 遇敵：每秒 10% 機率 → 平均 10 秒搜尋一次怪物
  • 武器路線：短劍(4) → 鐵劍(7) → 巨劍(10) → 鋼鐵巨劍(17) → 騎士大劍(20) → 屠魔巨劍(23) → 王者之劍(28)
  • 裝備安定值內：不含強化加成，僅基礎武器傷害
  • 命中率：基礎 80% + AGI/3 + 等級差修正，取 min(95%, max(5%, 計算值))
  • 怪物數量：簡化為平均每次遇到 1~2 隻（低 Pressure）
  • 爆擊：5% 基礎爆擊率 × 2.0 倍率（無爆擊詞綴）
  • CP 值公式：EXP/秒 = (怪物經驗 × 命中率 × 每場殺怪效率) / (搜尋時間 + 戰鬥時間)
