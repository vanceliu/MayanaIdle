武器剪影 Weapon Demo

武器只在攻擊的那 0.3 秒出現，平常不畫 —— 角色沒有手臂，常駐的武器等於黏在身上的一根棒子。
手沿著弧線甩過去，掃過面朝的那一格 —— 不是武器繞固定圓心轉半圈。
武器直接對著目標算角度，不切方向 —— 等距地圖上世界軸的四個方向落在 ±63.4° / ±116.6°， 45 度格線上根本沒有那四個角度。下面八格是遊戲中真正會出現的八個方向。
演出長度會隨攻擊間隔壓縮 —— 設計時長是「常速手感」，攻速堆滿時自動變快，永遠塞得進一次攻擊間隔。
造型只認武器類型（10 種），189 把的個體差異交給材質色 —— 20px 的剪影分不出一把一款。
調到滿意後按「匯出參數」，那份 JSON 就是實作要用的數字。

八個真實方向的演出（站在真實尺寸的等距地磚上）

地磚是 TILE_W=64 / TILE_H=32，與遊戲一致 —— 判斷武器大小的唯一依據。 往上的三個方向武器畫在角色之下 —— 目標格在更遠處，深度上就在角色後面； 其餘方向的目標格比角色近，畫在上層。
角色只有四張圖，連續的揮擊角度會收斂回去（pawnFacingForAim）， 與 facing.ts 同一套規則 —— 兩邊分岔就會出現朝向與揮向對不起來。

「弧線起點／終點」是這把武器自己的揮法，角度相對面朝方向： 0 = 指向面朝方向，正負值分別是弧線的兩端。四十格共用的只有「哪個朝向轉到哪一格」。 「揮舞半徑倍率」決定手甩多遠：1 = 完整揮舞（近戰）、0 = 端在身前不甩（弓）。
